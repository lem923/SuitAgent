## 03 租赁合同

### 2026-05-27 03 租赁合同 — 园区招商合同的预付返还机制是优惠不是负担

- **问题模式**：园区/科创园 B 类入驻租赁合同常用"季度预付 20% / 50% / 100% 三段式"+ 考核返还机制。若仅按"标准租金 × 期限"算总盘，会高估实际成本 1.5-2.5 倍——预付 20% 不是承租人"应付总额的 20%"，而是把剩余 80% 押后通过考核结果决定多退少补
- **采纳方案**：商业影响摘要必须分情景算实际成本（最佳/中等/最差），按"预付额 × (1 - 返还比例) + 后段全额"折算，不要按名义价 100% 算
- **适用场景**：科创园 / 招商性质 / 含考核返还机制的房屋租赁合同
- **备注**：因总盘下修，部分基于"市场通行"的减免建议（如装修期 30 日免租）在预付返还机制下不再合理——应主动撤回，避免谈判桌上显得"得寸进尺"

### 2026-05-27 03 租赁合同 — 园区合同的"考核机制"易被借壳扩为解除权

- **问题模式**：考核机制本意是租金返还，但常被嵌入"单次考核不合格甲方有权解除合同 / 强制调配 / 强制升租"的格式条款。客户视野容易停在"押金 / 违约金"等显性 REDLINE，忽视考核条款的解除权延伸
- **采纳方案**：审查阶段主动扫描考核条款的"后果链"——返还少 vs 解除合同；若发现解除权延伸，独立列为 REDLINE（即便客户初始口径未点到），fallback "可签"档为"考核不合格仅触发返还/调整 + 连续两次方可解除 + 催告整改期"
- **适用场景**：含考核机制的所有 B 类 / C 类 / 招商类入驻合同
- **备注**：同步审查附件解释权条款——若附件含"考核标准由甲方负责解释、修订"会颠覆正文的"附件锁定"条款，需删"修订"二字或加"双方协商修订"

### 2026-05-27 03 租赁合同 — 紧急情况进入与破门窗条款定义化（不删除）

- **问题模式**：商业租赁常约定"紧急情况下甲方可使用暴力和拆除门窗进入"，条款本身不可删（涉公共安全），但"紧急情况"无定义 + 损失复原责任未约定时风险大
- **采纳方案**：保留条款 + 列举 3 类紧急情形（火灾爆炸水管燃气电气 / 公安消防卫生防疫强制 / 危及大厦其他租户）+ 事后通知（4-24 小时书面 + 影像记录）+ 非乙方过错损失由甲方修复
- **适用场景**：商业楼宇 / 园区办公租赁
- **备注**：用户口径明确"可接受不完全反对"时，按 ORANGE 而非 REDLINE 处理
