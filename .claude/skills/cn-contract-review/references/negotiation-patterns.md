## 用法

## 高频谈判模式（跨类型适用）

### 1. 单方解除权 / 任意解除权扩张

- **REDLINE 触发**：对方保留任意解除权 + 我方无对等权
- **目标**：双向对等解除 + 触发条件具体化（违约 / 不可抗力 / 法定情形）
- **可签底线**：单方解除限定为重大违约后催告未改正
- **绝对底线**：保留单方解除但加 30 日预通知 + 已履行部分价款的清算机制

### 2. 单方免责 / 单方限责

- **REDLINE 触发**：单方免除全部责任 / 责任上限 0 元
- **目标**：双向对等限责（如各自合同金额的 100%）
- **可签底线**：故意 / 重大过失情形不限责（民法典第 506 条）
- **绝对底线**：故意 / 重大过失 / 人身损害不限责，其他事项可限责

### 3. 单方任意修改条款

- **REDLINE 触发**：对方保留单方修改合同任何条款的权利
- **目标**：删除单方修改权 / 改为协商一致变更
- **可签底线**：单方修改限定于"非实质性条款"且 30 日通知 + 我方异议权
- **绝对底线**：单方修改不影响我方既得权利

### 4. 通知与送达条款缺失

- **ORANGE 触发**：未约定通知方式、地址、生效时间
- **目标**：明确联系人 / 地址 / 邮箱 / 邮政或电子优先级 / 生效时间 / 地址变更通知义务
- **可签底线**：补充通知地址 + 邮政送达 7 日生效兜底条款
- **绝对底线**：保留两次邮政送达拒收即视为送达的备用机制

### 5. 违约金 / 违约责任不可执行

- **REDLINE 触发**："承担全部责任" / "依法承担违约责任"等空泛措辞
- **目标**：违约金按"基数 × 费率 × 天数"列式计算 + 起算时点 + 上限
- **可签底线**：违约金不超过 30%（民法典第 585 条调整空间）+ 守约方损失证据要求
- **绝对底线**：违约金可调整（接受守约方主张过分高于损失时申请调减）

### 6. 争议解决条款无效或不利

- **REDLINE 触发**：仲裁条款约定不明 / 仲裁机构不存在 / 多重管辖冲突
- **目标**：明确仲裁机构全称 + 仲裁规则 + 仲裁地 + 适用法律
- **可签底线**：选定一家有效仲裁机构 + PRC 仲裁法第 16 条三要素齐备
- **绝对底线**：仲裁条款无效时回退到法定管辖（被告所在地或合同履行地法院）

### 7. 标的不明 / 数量不明 / 质量不明

- **ORANGE 触发**：仅写"按行业标准" / "按双方协商" / 未列明规格
- **目标**：明确标的描述 + 数量 + 质量标准 + 验收方式
- **可签底线**：附件单独列规格清单（约束力等同于主合同）
- **绝对底线**：留空字段在签署前补齐（presign-checklist 强制项）

### 8. 付款条件 / 节点失衡

- **ORANGE 触发**：先全额付款无交付约束 / 先全部交付无付款保障
- **目标**：付款 - 交付 - 验收闭环（按节点比例分期）
- **可签底线**：首期 ≤ 30% + 验收后尾款 ≥ 10%
- **绝对底线**：首期 ≤ 50% + 担保措施补强（保函 / 抵押）

### 9. 知识产权归属严重偏离

- **REDLINE 触发**：服务合同中开发成果全部归对方 / 许可合同未约定再许可
- **目标**：成果归出资方所有 + 履约过程产生的非合同成果归各自
- **可签底线**：成果共有 + 双方均可使用（受合同目的限制）
- **绝对底线**：保留我方背景 IP + 合同结束后我方有有限使用权

### 10. 不可抗力 / 情势变更

- **YELLOW 触发**：不可抗力定义偏窄 / 仅适用于一方
- **目标**：双向适用 + 标准定义（自然灾害 / 政府行为 / 战争 / 罢工 / 流行病）
- **可签底线**：标准定义 + 通知期限 7 日 + 持续超过 30 日双方均可解除
- **绝对底线**：保留通知期限即可

## 谈判顺序建议

1. **REDLINE 优先**：先解决所有 REDLINE，对方不接受任一即停止谈判
2. **ORANGE 分组**：按 fallback 三档逐档退让，记录每档退让换得的对方让步
3. **YELLOW 后置**：仅在 ORANGE 全部解决后讨论 YELLOW；YELLOW 主要作筹码交换
4. **GREEN 提示**：不进入谈判桌，仅作记录

## 信息不足时的处理

- 关键事实未提供（如对方资质 / 历史合作）：列"待确认事项"，不在结论中出
- 当事人立场未明：第一步提问立场，立场未确定不进入审查
- 合同附件缺失：报告中标"未审查附件"，附件 = 主合同的部分必须立即补充

## 与 contract-types/XX-{name}/ 各 *-memory-patterns.md 的关系

各类目下的 `*-memory-patterns.md` 是该类目专属的谈判模式（如 05-ip 下的"无限三要素扫描
处理"等）。本文件是**跨类目通用**的 10 个高频模式。

调取顺序：
1. Stage 1 Step 4 / Stage 2 Discuss：先调本文件（通用层）
2. 如类目专属模式更具体：叠加调取 contract-types/XX/*-memory-patterns.md
3. 两者冲突时：类目专属优先
