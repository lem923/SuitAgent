## 核心哲学

将"描述"转化为"条件"。保护当事人的不是"应当/确保"，而是：
- 材料齐备 → 受理审查
- 条件满足 → 视为通过
- 送达/通知 → 起算时限
- 附件锁定 → 证据就绪

## 高频必防模式

### 1. 送达条款：不是通讯录，是证据链起点

所有"X日内回复/补救/解除/中止/恢复/付款条件通知"都需要送达条款（邮箱+生效时间+变更规则）。
最佳结构：
- 合同联系人（送达/变更/补救/解除）
- 项目联系人（技术/验收操作）

### 2. 保密条款：有限才可执行

永久/长期保密通常增加解释争议。稳定方案：
- "合同终止后X年"（除法定长期保密事项）
- 保密四件套：范围标识 + 例外 + 直接损失+举证 + 上限

### 3. 违约金：统一才不矛盾

违约金必须统一：基数/比例/上限/税务处理。
多处不同计算方式 = 执行时争议 + 可能被法院调整。

### 4. 付款条件：可证明才能触发

"甲方满意后付款""经第三方审计确认"等主观/不确定条件 = 付款无期限。
修正方向：绑定客观文件（验收报告/确认函/竣工证书）+ 逾期未反馈的默认处理。

### 5. 期限一致性：封面为主控

首轮永远检查：封面日期/有效期/联系方式/价格 ↔ 全文搜索比对。
多个终止点（有效期/服务期/质保期）必须统一，否则结算/追偿节点成为攻击面。

### 6. 担保工具：名实必须匹配

- 银行保函走银行索赔流程：有效期、索赔通知、覆盖窗口
- 保证金走现金扣减流程：扣减、补足、退还（计息/不计息）
- 混用 = 可执行性风险

## 谈判管理原则

### 不给"一刀切"答案

对每个问题提供阶梯：
1. 目标版本（第一轮要价）
2. 可签版本（交易底线）
3. 最后防线（无法再让时的替代保护）

### 弱势方策略

即使模板不可修改，仍应：
1. 修复明显矛盾和不可执行条款
2. 记录残余风险和替代保护措施

### 典型交换策略

- 对方要求"付款延迟免责" → 换取"中止+顺延+长期延迟解除权"
- 对方要求"宽泛保密" → 换取"明确例外+有限期限+损害上限"
- 对方要求"低违约金上限" → 换取"更高验收标准+尾款保留+质保金"
- 对方要求"宽泛竞业限制" → 换取"更高补偿+更窄范围+更短期限+明确解除机制"

## 隐藏陷阱清单

- 看似中立的争议解决条款可能实际不对称
- 责任上限绑定错误费用基数，商业上不合理
- 视为验收、酌情验收、未定义标准、未定义数据/安全义务 = 典型执行陷阱
- 交叉引用错误是法律缺陷，不是格式问题
- 框架协议/订单制 vs 一次性合同的模板错配
