## 核心哲学

将"描述"转化为"条件"。保护采购方的不是"应当/确保"，而是：
- 材料齐备 → 受理审查
- 条件满足 → 视为通过
- 送达/通知 → 起算时限
- 附件锁定 → 证据就绪

## 高频必防模式

### 1. 源代码：从"交付物清单"到"验收门槛"

关键词：
- 采购方指定环境
- 可重复构建 / 编译一致性
- 构建环境描述
- 依赖清单 + 许可证明

条款逻辑：
- 材料不全 / 无法编译 → 验收申请视为未提交 / 验收不通过

### 2. 财政拨付：免责必须配套"中止权"

仅写"付款延迟不视为违约"会导致争议和谈判失败。
必须配套：
- ≥180天中止机制
- 工期顺延
- 恢复通知
将行政付款风险转化为供应商时间缓冲，实现结构性平衡。

### 3. 保密：有限才可执行

永久/长期保密通常增加解释争议。
稳定方案："合同终止后X年" +（法定长期保密事项例外）
采购方保密四件套：范围标识 + 例外 + 直接损失+举证 + 上限（通常10%）

### 4. 联合体：对外一个拳头，连带责任

采购方不关心内部分工，需要一个主体追偿全部。
必须包含：
- 联合体对采购方连带责任
- 牵头方为唯一交付/验收/付款材料窗口
- 内部协议不得对抗采购方
- 送达牵头方视为送达全体

### 5. 担保工具：名实必须匹配

- 银行保函：索赔通知、有效期、覆盖窗口
- 保证金：扣减、补足、退还（计息/不计息）
混用 = 可执行性风险

### 6. 送达条款：证据链起点

无送达规则，所有"X日内"条款均为死条款。
最佳结构：合同联系人（送达/变更/补救/解除）+ 项目联系人（技术/验收操作）

### 7. 期限一致性：封面为主控

首轮必查：封面日期/有效期/联系方式/价格 ↔ 全文搜索比对。
多个终止点必须统一，否则结算/追偿节点成为攻击面。

## 谈判策略（避免"一刀切"答案）

- 担保金额不足时，不要只说"提高到10%"。
  提供替代方案：尾款保留、阶段扣减、拒付条件、更高验收标准、代码托管/同步。
- 对方以"公平"为由主张时，交换"中止+顺延"换取采购方"财政延迟免责"。
- 如验收标准争议大：引入第三方检测/鉴定条款作为替代。
- 如对方拒绝编译一致性：替代方案为"采购方指定环境部署+运行测试"作为验收前提。
