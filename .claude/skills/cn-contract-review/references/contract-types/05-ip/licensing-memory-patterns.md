## 核心哲学

将"授权/支持/担保"转化为**可确定的条件**。
许可合同最怕三个"无限"：无限范围、无限支持、无限赔偿。

## 高频必防模式

### 1. 范围：从"行业描述"到可审计边界

必须包含可量化维度：
- 地域、期限
- 实例数/用户数/客户数
- 项目清单、场景定义
- 模糊性确认机制（材料齐备启动时限；逾期未回复视为同意/拒绝——二选一）

### 2. 第三方使用：从绝对禁止到有控制的允许

绝对禁止往往扼杀交付。更好的控制：
- 保密协议 + 最小必要访问
- 不留存
- 名册报备
- 被许可方承担责任

逻辑："不得转许可"，但允许分包商/集成商在项目必要范围内、在控制措施下接触。

### 3. 改进：从"不含算法"到定义+回授+反封锁

"不含算法"模糊不清；需定义"改进"并举例。
关键条款：
- 改进归属于改进方
- 被许可方回授许可方：免费、非独占、不可转让（限于维护/研究/继续许可的必要范围）
- 不得封锁基础知识产权使用
优先选择"优先谈判权"而非"优先购买权/优先受让权"。

### 4. 支持：免费必须计量；"合作意向"不得成为主合同义务

- 免费支持：时限 + 人天 + 范围；超范围另行付费下单
- "派驻人员/提供开发资源/平台/推广"应拆入独立协议，避免构成联合交付/连带责任

### 5. 开票与付款：避免单方税务/坏账风险

将"每次付款前开票"替换为：
- 收到款项后开票，或款项到账后X日内开票
制裁措施：
- 逾期付款 → 中止支持/更新/新增授权；付清后恢复

### 6. 侵权担保：三件套（触发+接管+上限）

- 触发：仅限合规使用；排除超范围、擅自修改、不当组合
- 接管：通知期限；许可方主导抗辩；未经同意不得和解
- 上限：直接损失 + 合理费用；排除间接损失；总额上限 = 已付费用
优先替换/变通方案，然后才是退款/终止。

### 7. 保密：不轻易援引"国家秘密"法

稳定结构：
- 如依法被认定为国家秘密 → 从其规定；否则按商业秘密处理
- 期限：合同终止后X年（法定长期保密除外）

### 8. 到期后逾期使用：按月可计算的罚则

如使用"2倍价格"，需定义：
- 年费 → 月费 × 倍数 × 逾期月数；不足一月按一月计；另加合理维权费用

### 9. 送达：证据链起点

无邮件/送达生效规则，所有"X日内"条款均为死条款。
最佳：合同联系人（送达/终止/付款/确认） + 项目联系人（技术）。

## 谈判管理

- 不要用安全换绝对禁止；用有控制的允许 + 计量支持 + 回授
- 赔偿难谈时：先保程序控制和上限；然后是替换/退款机制
- "先开票再付款"难改时：至少获得"逾期中止支持/新增授权"
- 范围争议大时：引入年度审计权 + 超范围补缴机制作为替代方案
