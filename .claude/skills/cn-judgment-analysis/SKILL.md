# 裁判文书分析技能

## 核心目标

从对方律师的视角审视己方裁判文书，找到裁判逻辑的漏洞与可攻击点；
从上级审查者的视角评估文书质量，识别实体错误与程序瑕疵。

---

## 工作流程

收到裁判文书后，按以下步骤执行：

### Step −1：启动读经验库（v1.12.0 闭环读侧）

文书画像前，先读取本 skill 目录下 `memory.md`。若存在**非"（暂无条目）"的真实条目**，按本案救济路径（上诉/再审/检察监督/执行异议）与裁判文书类型筛选**最相关 top-3** 纳入评审参考；若 `memory.md` 不存在或相关 section 全为"（暂无条目）"，**跳过本步（no-op，不阻断、不污染 context）**。本步**只读不写**；写入由 cn-case-postmortem 结案复盘统一负责。

### Step 0：文书画像

提取并输出以下要素（表格形式）：

| 字段 | 内容 |
|------|------|
| 文书类型 | 判决书 / 裁定书 / 调解书 |
| 案号 | |
| 法院级别 | 基层 / 中级 / 高级 / 最高 |
| 案由 | |
| 审级 | 一审 / 二审 / 再审 |
| 当事人 | 原告 / 被告 / 第三人 |
| 裁判结果摘要 | |
| 我方立场 | （需用户确认） |

---

### Step 1：争议焦点还原

提取法院认定的争议焦点，与当事人主张进行对比：

```
【法院归纳焦点】：...
【原告实际主张】：...
【被告实际抗辩】：...
【焦点遗漏/偏移分析】：法院是否遗漏了重要争议？焦点界定是否对某方不利？
```

---

### Step 2：证据认定分析

逐项梳理法院对证据的处理：

```
证据编号 | 证据名称 | 法院认定 | 认定依据 | 可攻击点
---------|---------|---------|---------|--------
```

重点标注：
- 未经质证即采纳的证据
- 排除合理解释径直认定的证据
- 鉴定意见直接作为裁判依据（"以鉴代审"风险）
- 电子证据认证程序瑕疵

---

### Step 3：裁判逻辑链重建（IRAC反推）

```
I — 法院识别的法律问题是什么？
R — 法院援引了哪些法律条文？援引是否准确？
A — 法院如何将规则适用于本案事实？论证链完整吗？
C — 结论是否必然从以上推导得出？有无跳跃？
```

常见裁判逻辑问题清单（逐项核查）：
- [ ] 认定事实无充分证据支撑
- [ ] 适用法律条文错误（条文选择 / 版本 / 理解）
- [ ] 忽视强制性规定或公序良俗
- [ ] 违反"举证责任分配"规则
- [ ] 未对当事人主要抗辩意见作出回应
- [ ] 超出诉讼请求范围裁判
- [ ] 以鉴定意见代替法律判断
- [ ] 程序违法（送达 / 回避 / 合议庭组成）

---

### Step 4：救济路径评估

根据以上分析，输出救济可行性评估：

#### 上诉（二审）
- 适用条件：一审判决未生效
- 可提交新证据：是/否（说明条件）
- 推荐上诉理由（按权重排序）
- 成功概率评估（高/中/低）+ 简要理由

#### 申请再审
- 法律依据：《民事诉讼法》第211条
- 本案符合哪项再审事由（逐项对应）
- 申请再审期限核查
- 成功概率评估

#### 检察监督（抗诉/检察建议）
- 适用条件核查
- 监督申请侧重点建议
- 成功概率评估

#### 执行异议/复议
- 仅限执行阶段，如适用

---

### Step 5：输出成果

最终输出包含：
1. **文书画像表格**
2. **核心问题清单**（按影响程度排序，RED/ORANGE/YELLOW标注）
3. **救济路径对比表**（含概率评估）
4. **行动建议**（最优路径 + 时限提醒）
5. **局限性说明**（基于现有材料的分析边界）

---

## 引用规范

分析中援引法律依据时，必须使用完整条文引用：

```
《中华人民共和国民事诉讼法》（2023年修正）第XXX条
《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第XXX条
```

如援引指导性案例，注明案例编号与裁判要旨。

---

## 质量红线

- ❌ 不得在事实不清时给出确定性成功率数字
- ❌ 不得忽视对己方不利的裁判逻辑
- ❌ 不得在未核查程序性事项（送达时间、期限）的情况下建议再审
- ✅ 所有结论必须可溯源至具体条文或证据
- ✅ 存在司法分歧时，明确注明"各地法院做法不一"
