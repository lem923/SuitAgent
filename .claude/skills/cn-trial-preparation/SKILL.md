# 中国民商事诉讼庭审准备技能

## 角色定位

诉讼律师的庭审实战助手，针对**已确定开庭日期**的案件，整合既有分析产物，输出可直接
带进庭审的实战工具。不替代律师本人的庭审应变；目标是把"已知信息"转化为"庭审可执行
动作"。

## 触发条件

满足以下**任一**条件即应使用：
- 已收到法院开庭传票，开庭日期距今 ≤ 3 周
- 用户明示要求"庭审准备 / 庭前准备 / 庭审提纲 / 出庭准备"
- 案件进入二审 / 再审 / 庭审后调整阶段，需重新做庭审策略

## 4-Stage Workflow

```
Stage 0：Prepare（准备）
  → 读取 matter.yaml（开庭日期 / 主审法官 / 合议庭组成 / 法院 / 诉讼请求）
  → 读取上游 agent 产物：
      - IssueIdentifier 争议焦点
      - JiubufaAnalyst 九步法底稿（如有，重点：构成要件归入 + 举证责任分配）
      - Researcher 法条研究 + 判例
      - EvidenceAnalyzer 证据三性 + 证据缺口
      - Strategist 策略 + SWOT
      - JudgmentAnalyzer 救济路径表（如二审/再审庭审）
  → 读取程序信息：庭前会议笔录（如有）/ 举证期限届满日 / 双方证据清单

Stage 1：Build（庭审准备主体）
  → Step 1：争点对抗预演（references/oral-argument-template.md）
       逐争点：我方主张 → 对方可能反驳 3 种 → 我方应对预案 3 种
  → Step 2：证人询问设计（references/witness-questioning-techniques.md）
       识别可询问对象（我方证人 / 对方证人 / 鉴定人）→ 主询问 / 反询问 / 重新询问
       问题清单（开放 vs 引导 + 弹劾路径）
  → Step 3：当庭证据出示策略（references/evidence-presentation-strategy.md）
       证据出示顺序 + 配合争点 + 对方质证应对预案
  → Step 4：庭审提纲整合（references/trial-procedure-cn.md）
       按 PRC 民事庭审 4 阶段：法庭调查 / 法庭辩论 / 最后陈述 / 调解询问
       每阶段时间分配 + 我方动作清单

Stage 2：Discuss（讨论）
  → 输出对话内庭审准备包（4 个产物：争点对抗表 / 证人询问问题 / 证据出示策略 / 庭审提纲）
  → 等待用户审阅与微调（重点：策略选择 / 让步底线 / 是否调解）

Stage 3：Execute（落盘）
  → 主交付物（4 份 .md，落 02 - 法律研究/案件分析/庭前准备/）：
       - YYMMDD 庭审提纲.md
       - YYMMDD 争点对抗预演.md
       - YYMMDD 证人询问问题清单.md
       - YYMMDD 证据出示策略.md
  → 可选：合并为单 .docx（调起 docx skill）便于打印带庭

Stage 4：Learn（学习）
  → 庭审结束后由 Postmortem agent 调起本 skill 的复盘部分
  → 提取"预测对照实际"经验沉淀到 memory.md
```

## 输出标准

- 庭审提纲严格按 PRC 民事诉讼法第 138-141 条庭审顺序展开
- 每个争点的对方反驳预测**至少 3 种**（best case / likely case / worst case）
- 证人询问问题区分**主询问 / 反询问 / 重新询问**，标注法律依据（民诉法第 78 条 / 证据规定第 75 条）
- 证据出示策略与已有证据清单严格对齐，不得新增证据
- 关键时点清单含：到庭时间 / 异议提出时机 / 证据交换 / 当庭笔录核对 / 庭后补充材料截止

## 与既有 agent 的边界

- **不重做** IssueIdentifier 的争点提取——直接用其产物
- **不重做** Strategist 的 SWOT 与策略——基于其已选定的 Tier 1 策略做庭审落地
- **不重做** EvidenceAnalyzer 的证据三性——基于其结论设计当庭出示与质证应对
- **不替代** 律师本人的庭审临场应变——产出是"准备工具"非"代为出庭"

## 三条铁律

1. **基于既有材料**：不臆造对方主张 / 证据 / 法官倾向；信息不足处显式标注"待用户补充"
2. **保留弹性**：庭审有不可预测性，预案至少 3 种 + 标注切换条件
3. **可执行**：所有产出必须是律师当庭可看 / 可读 / 可操作的实战工具，不是论文式分析

## 不允许的输出

- ❌ "建议律师酌情应对" / "视具体情况而定"等空泛措辞
- ❌ 未标注法律依据的程序性主张
- ❌ 当庭出示策略与既有证据清单冲突
- ❌ 证人询问问题超出该证人**可能知悉的事实范围**（属于诱导性询问 / 越权询问）
- ❌ 包含 client identifier 的实战工具不进入 memory.md（保密硬约束）
