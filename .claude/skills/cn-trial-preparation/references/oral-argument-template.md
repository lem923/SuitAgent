# 口头辩论与争点对抗预演模板

## 争点对抗预演结构（每争点一表）

```
=== 争点 N：[争点描述] ===

我方主张：
  [一句话核心立场]

我方法律依据：
  - 法条：[《XX法》第 X 条第 X 款]
  - 司法解释：[法释〔YYYY〕XX 号第 X 条]
  - 判例（如有）：[案号 + 关键裁判要旨]
  - 学理（如有）：[简引]

我方事实依据：
  - 证据 X（编号）+ 证明目的：[直接对应到本争点]
  - 证据 Y + 证明目的

对方可能反驳（best case：对方反驳力度最弱）：
  反驳 1：[预测对方主张]
  我方应对：[应对策略 + 反驳理由 + 引用反驳法条]

对方可能反驳（likely case：最可能的反驳）：
  反驳 2：[预测]
  我方应对：[应对]

对方可能反驳（worst case：对方反驳最有力）：
  反驳 3：[预测]
  我方应对：[应对策略 + fallback：如对方此反驳被法庭部分接受，我方退守的次级立场]

退守底线（如对方反驳被全部接受）：
  → 转换主张：[次级请求 / 次级救济路径]

判定法庭倾向的信号：
  - 法官在质证 / 询问阶段对该争点的提问偏向
  - 庭审笔录中法官记录的细节
```

## 法庭辩论实战模板

### 第一轮主辩论（按争点顺序）

```
审判长，针对 [本争点]，[原告/被告] 主张如下：

第一，我方观点：[简洁明确]
第二，法律依据：[准确引用]
第三，事实依据：[已质证证据指引]

[简短引用对方观点（如对方此前已表达）]
[一句话反驳对方核心错误]

请法庭对本争点 [认可我方主张 / 驳回对方主张]。
```

### 第二轮反驳辩论（针对对方第一轮观点）

**关键**：不重复第一轮主辩论；只针对对方第一轮的**新观点 / 错误观点**反驳。

```
审判长，针对对方在第一轮辩论中提出的 [对方观点 X]，我方反驳如下：

第一，对方观点 X 与本案事实不符：[具体不符之处]
第二，对方援引 [法条 Y] 适用错误：[正确解释]
第三，对方对证据 Z 的解读不正确：[正确解读]

[最后一句话强调]：因此，对方观点 X 不能成立。
```

### 第三轮终结性陈述（如允许）

简短（1-2 分钟）：
```
审判长，请允许我方对本案核心问题作最终陈述：

本案争议归根结底是 [一句话归纳]。

我方主张 [核心诉求]，依据 [一句话核心法律依据]。

请法庭支持我方诉讼请求。
```

## 最后陈述模板

**严格简短（1-3 分钟）**：

```
审判长，本案审理至此，[原告/被告] 作如下最后陈述：

[一句话重申诉讼请求]

[一句话核心理由]

[调解表态]：
- 选项 A：本案可调解；和解条件 [基本框架]
- 选项 B：本案不接受调解，请法院依法判决
- 选项 C：调解需结合判决可能性，请法庭定夺

感谢法庭。
```

## 调解意愿口径决策表

| 案件状况 | 调解口径 | 风险 |
|---------|---------|------|
| 我方胜诉概率 ≥80% | 不接受调解或仅接受全额履行调解 | 调解后对方可能拖延履行 |
| 我方胜诉概率 50-80% | 接受合理调解（最多让步 10-20%）| 让步过多影响后续案件示范 |
| 我方胜诉概率 30-50% | 主动调解（最多让步 30-40%）| 调解优于败诉 |
| 我方胜诉概率 ≤30% | 优先调解（让步 50%+）| 败诉成本（诉讼费 + 律师费 + 商誉损失）|

**注**：胜诉概率应从 JiubufaAnalyst 底稿提取；如无底稿，按 Strategist SWOT 估算。
