# 当庭证据出示策略

## 证据出示顺序原则

**核心目标**：通过证据出示顺序构建有利的事实叙事，让法庭按"我方逻辑"理解事实。

### 4 种排序策略

| 策略 | 适用场景 | 排序逻辑 |
|------|---------|---------|
| 时间顺序 | 简单事实 / 时间线清晰 | 按事件发生先后 |
| 重要性顺序（强→弱）| 想给法庭最强初印象 | 关键证据先出，次要证据后出 |
| 逻辑递进 | 复杂法律关系 | 从基础事实证据 → 中间事实 → 关键争议事实 |
| 反驳预判顺序 | 主张需要预先反驳对方 | 先出对方可能否认的事实证据 |

**默认推荐**：**逻辑递进**——从无争议事实开始（建立 baseline）→ 部分争议事实 → 核心争议事实

## 证据出示标准动作

每件证据出示需说**三句话 + 一个动作**：

```
"审判长，[原告 / 被告] 提交证据 X：[证据名称]。

证明目的：[一句话写明证明哪个事实主张 / 哪条诉讼请求]。

请审判长查阅 [原件 / 复印件 / 电子数据演示]。"

[动作：递交证据原件 / 复印件 / 演示电子数据 / 播放视听资料]
```

## 各类证据特殊出示要点

### 1. 书证

- **原件优先**：当庭核对原件；如仅有复印件，必须说明无原件原因
- **多页文件**：当庭翻到关键页，引导法官 / 对方注意
- **域外书证**：是否经过领事认证 / 海牙公约附加证书 / 签订之日起 60 日内向我国法院提交

### 2. 电子数据

- 当庭演示（连接法庭显示设备 / 自带笔记本）
- 关键操作：
  - **完整链条**：从设备 → 软件 → 文件，演示数据真实性
  - **时间戳**：演示文件元数据中的时间（修改时间 / 创建时间）
  - **哈希值**：如已做证据保全（公证 / 区块链），出示哈希对比报告
- 法律依据：证据规定第 14-16 条

### 3. 视听资料

- 当庭播放（仅截取关键 1-3 分钟）
- 完整版本备底稿（法官如要求播放更多则提供）
- 配套书面文字稿（防止音频不清晰）
- **隐私边界**：涉及他人隐私 / 商业秘密的录音录像，提前申请不公开审理

### 4. 证人证言

- 主询问 / 反询问 / 重新询问（参 witness-questioning-techniques.md）
- 庭前提交证人书面陈述（民诉法司法解释第 117 条）
- 关键证人不出庭——影响证据效力（证据规定第 75 条）

### 5. 鉴定意见

- 鉴定人出庭（民诉法第 81 条规定的情形必须出庭）
- 出庭鉴定人质询：
  - 资质（CNAS / CMA / 鉴定人执业证）
  - 鉴定方法是否符合行业标准
  - 检材来源是否经过双方确认
  - 鉴定意见的可重复性
- 反鉴定 / 重新鉴定：异议要在质证阶段当庭提出

### 6. 勘验笔录

- 勘验人出庭（如对方申请）
- 现场照片 / 视频作配套出示

## 对方证据的质证应对

```
"审判长，[原告 / 被告] 对对方证据 X 发表质证意见如下：

真实性：
  - 选项 A：认可（不再质疑）
  - 选项 B：不认可（理由：[复印件无法核对原件 / 形成时间存疑 / 有篡改痕迹]）
  - 选项 C：部分认可（认可 X，不认可 Y）

合法性：
  - 选项 A：认可
  - 选项 B：不认可（理由：[取证程序违法 / 违反个人信息保护法 / 缺乏取证授权]）

关联性：
  - 选项 A：认可
  - 选项 B：不认可（理由：[与本案争议无直接关联 / 与拟证明事实不对应]）

证明力：
  - 综合：[强 / 中 / 弱 / 无]——基于 [真实性 / 合法性 / 关联性] 的瑕疵

综合质证结论：
  [一句话：对方证据 X 不能证明其主张 / 仅能证明 A 不能证明 B / 完整证明其主张]"
```

## 证据组合战术

**多证据互证**：单一证据存在瑕疵时，用多份证据互相印证

```
"审判长，证据 X、Y、Z 互相印证 [核心事实]：
- 证据 X 显示 [事实片段 1]
- 证据 Y 显示 [事实片段 2，与片段 1 时间衔接]
- 证据 Z 显示 [事实片段 3，与 1、2 因果衔接]

三份证据形成完整证据链，证明 [完整事实主张]。"
```

**反向证据反驳**：用对方曾认可 / 在先文件证明对方现今主张矛盾

```
"对方今日主张 X，但 [对方之前签订的合同 / 微信记录 / 邮件] 中明确说过 Y。
对方主张前后矛盾，应以最初真实意思表示（即 Y）为准。"
```

## 证据当庭呈现的禁忌

- ❌ 出示举证期限届满后才取得的证据（除非新证据 / 对方知悉）—— 法庭可能不予采纳
- ❌ 出示与对方达成的"庭前不予出示"约定中的内容
- ❌ 出示其他案件保密信息（律师执业道德底线）
- ❌ 当庭新增对方未质证的证据 ——程序违法
- ❌ 用 "建议法庭" 等命令性语气—— 法庭权威边界
