# 证人询问技巧参考

## 主询问 vs 反询问 vs 重新询问

| 类型 | 适用对象 | 法律依据 | 问题风格 |
|------|---------|---------|---------|
| 主询问 | 我方申请的证人 | 民诉法第 78 条 + 证据规定第 75 条 | **开放式**为主（"请描述...""您当时看到什么..."）|
| 反询问 | 对方申请的证人 | 同上 | **引导式 / 封闭式**为主（"您当时是不是...""您是否承认..."）|
| 重新询问 | 主询问后的我方证人，针对反询问中暴露的问题 | 同上 | **开放 + 修复式**（"刚才您提到 X，请详细说明背景"）|

## 主询问问题设计

**4 步原则**：

1. **铺垫层**（建立证人 credibility）：
   - "请介绍您与本案的关系"
   - "您是从什么时候开始知道本案事实"
   - "您在本案中担任什么角色"

2. **事实层**（让证人讲故事）：
   - "请按时间顺序描述..."
   - "在 X 时间，您在哪里？做什么？"
   - "请描述您所看到 / 听到 / 接触到的..."

3. **关键事实层**（针对争议焦点）：
   - "对于 [争议事实]，您当时的具体观察是什么"
   - "请展示证据 X，您是否能确认这是您当时看到的内容"

4. **完整性层**（防止反询问中漏点）：
   - "您还有什么补充事实"
   - "对于本案，您是否还知道其他相关情况"

**禁忌**：
- ❌ 诱导性问题（"您当时是不是看到了 X？"）
- ❌ 假设性问题（"如果当时...您会怎么做？"）
- ❌ 复合问题（一句话多个问题）
- ❌ 与本案无关的问题（拉关系 / 攻击人格）

## 反询问问题设计

**核心目标**：
- 削弱对方证人的可信度（credibility attack）
- 暴露其证言的逻辑漏洞 / 与已有证据矛盾
- 限制其表达空间，控制答案

**5 类反询问问题**：

1. **承认型**（让证人承认对我方有利的事实）：
   - "您是否承认 [对我方有利的事实]"
   - "您是否记得 [对方主张的相反事实] 没有发生"

2. **限制型**（限定答案为是/否）：
   - "您当时是否在场？"（是 / 否）
   - "您是否亲眼看到 X？"（是 / 否）
   - 不允许证人展开讲

3. **矛盾型**（指出与已有证据 / 之前陈述的不一致）：
   - "您刚才说 X，但是文件 Y 显示 [相反]，您如何解释？"
   - "您在 [先前文件 / 录音] 中说过 [不同陈述]，是否记得？"

4. **弹劾型**（攻击证人 credibility）：
   - 利益关系：" 您与 [当事人] 是什么关系？"（揭示偏见）
   - 利益冲突：" 您是否从 [当事人] 收到任何好处？"
   - 历史不诚信：" 您之前是否有过 [相关不诚信记录]？"
   - **法律依据**：证据规定第 78 条（证人证言可信度的影响因素）

5. **专家弹劾**（针对鉴定人 / 专家证人）：
   - 资质质疑：" 您的资质是什么？"" CNAS / CMA 是否仍然有效？"
   - 方法质疑：" 您采用的鉴定方法是否符合 [行业标准]？"
   - 数据质疑：" 您的鉴定依据的样品是从哪里获得？是否经过双方质证？"

## 重新询问

**触发**：反询问中我方证人出现了不利陈述 / 模糊回答 / 表达不清

**4 类重新询问问题**：

1. **澄清型**：
   - "刚才反询问中您提到 X，请补充说明背景"
   - "您说的 X 是什么意思 / 时间 / 地点？"

2. **修复型**（如反询问让证人陷入矛盾）：
   - "您刚才说 [反询问陈述]，与您主询问中说的 [主询问陈述]，您原本要说的是什么？"

3. **完整性型**：
   - "您当时还看到 / 听到什么没有提及？"

4. **再确认型**（重申有利陈述）：
   - "请您再次确认 [核心有利事实]"

## 弹劾路径

针对**对方证人**：

| 弹劾依据 | 准备工具 | 法律依据 |
|---------|---------|---------|
| 与当事人有利益关系 | 提前调查证人身份 + 工商档案 / 关联关系图 | 证据规定第 78 条 |
| 与当事人有亲属关系 | 户籍证明 / 关联关系（兄弟姊妹 / 配偶 / 同事） | 同上 |
| 历史不诚信记录 | 提前调查证人征信 / 公开诉讼 / 失信被执行人 | 同上 |
| 专业资质瑕疵 | 资质证书核查 + 是否在有效期 + 是否有违规处罚记录 | 鉴定意见审查规定 |
| 与本案事实矛盾 | 提前对比证人证言（如有书面）与已有证据 | 自相矛盾的证言不应采信 |

## 询问技巧总结

**询问时律师姿态**：
- 站姿稳 / 不要走来走去
- 语气平稳 / 不要威胁 / 不要嘲讽
- 听完证人答完才提下一问（不要打断，除非"漫无边际地陈述"——民诉法司法解释第 119 条赋予审判长制止权）

**问题节奏**：
- 短问题 → 短答案
- 1 问 1 答 / 不要多个问题叠在一起
- 关键问题 + 视频 / 文件配合（让证人对照实物 / 录像作答）

**记录**：
- 庭审笔录员记录是简略的；我方应安排助理或委托人**实时记录**完整问答（庭后核对）
- 关键问答的**对方证人答案**当庭强调"请记录员准确记录"
