# PRC 民事庭审程序参考（民事诉讼法 2023 修订）

## 庭审 4 阶段总览

| 阶段 | 法律依据 | 时间分配（一般案件） | 我方核心动作 |
|------|---------|------------------|------------|
| 法庭调查 | 民诉法第 138 条 | 50%-60% | 陈述事实 / 出示证据 / 质证 / 询问 |
| 法庭辩论 | 民诉法第 141 条 | 25%-35% | 围绕争议焦点提出主张 + 法律依据 + 对方反驳 |
| 最后陈述 | 民诉法第 142 条 | 5%-10% | 简短重申诉求 + 调解意愿 |
| 法官询问 / 调解 | 民诉法第 96 条 | 5%-10% | 视法官引导 |

## Stage 1：法庭调查（最关键）

**子阶段 + 我方动作**：

1. **当事人陈述**
   - 原告：宣读起诉状（精简版 + 重点突出）
   - 被告：宣读答辩状（针对原告每项请求逐一回应）
   - **我方提示**：陈述时**避免读全文**，挑核心争点说；3-5 分钟为宜

2. **举证质证**
   - 我方举证（按证据清单顺序）：
     - 出示前：明确"证据 X 编号 / 名称 / 证明目的"
     - 当庭操作：原件核对 / 电子数据当庭播放 / 视听资料当庭演示
   - 对方质证：注意捕捉对方质证立场（认可 / 不认可 / 部分认可）
   - 我方质证对方证据：按"真实性 / 合法性 / 关联性"逐项发表
   - **法律依据**：证据规定（最高人民法院关于民事诉讼证据的若干规定 2019 修订）

3. **法庭询问**
   - 法官询问双方
   - **关键**：法官的提问往往暗示法庭关注点 / 倾向；记录每个法官提问 + 我方应答

4. **当事人 / 证人发问**
   - 民诉法第 78 条：当事人可以在审判长许可后向证人发问
   - 我方申请询问对方证人（如有）— 准备主询问 + 反询问问题
   - **不允许**：威胁证人 / 诱导性问题（除非反询问）

## Stage 2：法庭辩论

**核心结构**：

1. 围绕争议焦点 1：
   - 我方主张
   - 法律依据（条文 + 司法解释）
   - 事实依据（已质证证据指引）
   - 反驳对方观点（针对其法庭调查阶段表态）

2. 围绕争议焦点 2 / 3...（同上结构）

3. 综合性主张：
   - 诉讼请求逐项落实
   - 违约金 / 损害赔偿 / 利息 计算口径再次明确（防止法官计算口径与我方不一致）

**辩论的层次结构**：
- **第一轮**：我方主辩论（围绕主要争点）
- **第二轮**：针对对方第一轮观点的反驳（不重复）
- **第三轮（如允许）**：对核心问题的最终陈述

## Stage 3：最后陈述

简短（1-3 分钟）：
1. 重申核心诉讼请求（不是诉状全文重读）
2. 一句话核心理由
3. **调解意愿表态**（视策略：明示愿意调解 / 不愿意 / 看条件）
4. 感谢法庭

## Stage 4：法官询问与调解

法官常见提问类型：
- "本案可否调解" → 我方应有事先策略（接受 / 拒绝 / 条件接受）
- "对争议事实是否补充" → 不再补充，避免节外生枝
- "对法律适用有何意见" → 重申主张

## 庭审中的程序性权利（必备）

- **管辖异议**：开庭前提出（提交答辩状期间内）；庭审中不得再提（已默示放弃）
- **回避申请**：庭审开始时审判长会询问；如有事由必须当时提出
- **延期审理申请**：突发情况导致庭审无法进行，民诉法第 149 条
- **庭审笔录核对**：庭审结束后**当庭核对**笔录，不一致处当场提出修改；签字后视为认可
- **当庭判决 / 择期宣判**：法官选择，我方记录但不要表态

## 关键时间节点（开庭日提示）

| 时间点 | 我方动作 |
|--------|---------|
| 开庭前 60 分钟 | 法院安检 + 找好法庭位置 + 与当事人确认到庭情况 |
| 开庭前 30 分钟 | 文件清单核对（证据原件 / 答辩状 / 委托手续 / 律师证）|
| 开庭前 15 分钟 | 与当事人最后沟通（重申庭审纪律 + 不得擅自发言 + 调解口径）|
| 开庭中 | 庭审笔录实时观察（不一致处当场提出）|
| 庭审结束 | 笔录核对签字 / 询问下次开庭 / 询问当庭判决意向 |
| 庭后 24 小时 | 整理庭审笔录 + 当庭出现的新事实 / 新争议 → 报告客户 |

## 庭审纪律（民诉法第 110 条）

- 不得鼓掌 / 喧哗 / 录音录像（除非法庭许可）
- 不得擅自离开法庭
- 听从审判长指挥
- **手机静音 / 关机**——多次违反法庭可处罚款 / 拘留
