# 阶段性总结模板

## 触发节点

5 类节点必出阶段总结：
1. **立案后**（法院出具受理通知书后 3-7 日内）
2. **庭审后**（每次庭审结束 3 日内）
3. **判决/裁定后**（送达后 5 日内，含上诉期限提示）
4. **调解 / 撤诉 / 和解后**（达成后 3 日内）
5. **执行启动 / 终本后**（执行立案 5 日内 / 终本通知送达后 3 日内）

## 通用模板

```markdown
# [客户称谓] · [节点名称] 阶段总结

> 案件：[案号或简称]
> 节点：[立案 / 庭审 / 判决 / 调解 / 撤诉 / 执行启动 / 终本]
> 节点日期：YYYY-MM-DD
> 报告日期：YYYY-MM-DD（节点后 X 日）

## 一、节点概述

[1-3 句话陈述节点的事件本质，例如：
"本案于 YYYY-MM-DD 在 [法院] 第一次开庭审理。庭审持续约 X 小时，主要围绕 [核心争点] 展开。"]

## 二、节点核心信息

| 字段 | 内容 |
|------|------|
| 法院 / 仲裁机构 | [具体名称] |
| 审判长 / 主任仲裁员 | [姓名 + 职务] |
| 合议庭 / 仲裁庭组成 | [姓名] |
| 我方出庭人员 | [律师 + 当事人] |
| 对方出庭人员 | [律师 + 当事人 + 代理身份] |

## 三、实际进展 vs 预期对比

| 维度 | 预期 | 实际 | 评估 |
|------|------|------|------|
| 时间 | [预期日期] | [实际日期] | [按时 / 提前 / 延后] |
| 争点确认 | [预期争点] | [法院最终归纳的争点] | [一致 / 部分一致 / 偏差] |
| 法庭倾向 | [预测] | [基于法官提问 / 表态推断] | [偏我方 / 中性 / 偏对方] |
| 调解可能性 | [评估] | [实际探讨情况] | [较高 / 一般 / 较低] |

## 四、关键事实与新发现

[本节点暴露的新事实 / 新争议 / 新证据问题，例如：
- 对方在庭审中承认 [不利于其的关键事实]
- 法官特别关注 [某具体争点]，可能成为判决核心
- 我方需补充 [证据 / 材料]]

## 五、后续策略调整

[基于本节点实况调整的策略，例如：
- 由于法庭倾向 [X]，下一步应 [具体动作]
- 调解空间已明确，建议客户 [接受 / 拒绝 / 谈判] 的口径]

## 六、客户决策事项

[需要客户拍板的事项，每项含：选项 + 利弊 + 律师推荐 + 决策时限]

| 决策事项 | 选项 | 律师推荐 | 决策时限 |
|---------|------|---------|---------|
| ... | ... | ... | ... |

## 七、近期 1-2 个月预期

[预期的下一阶段节点 + 时间窗]

---

如需面谈或电话沟通，请提前预约。
[律师姓名] · [律所]
```

## 各节点定制版要点

### 1. 立案后

新增字段：
- 立案号 / 案号
- 受理通知书送达日 → 计算所有后续期限的起算点
- 答辩期 / 举证期 / 反诉期 / 管辖异议期 → 列具体日期
- 法院送达地址确认书 → 是否已签

### 2. 庭审后

新增字段：
- 庭审笔录核对情况（是否完整 / 是否有出入）
- 当庭出现的新争议 / 新证据
- 法官提问倾向（每个法官的关注点）
- 是否当庭判决 / 择期宣判

### 3. 判决 / 裁定后

新增字段：
- 判决主文（逐项列出 + 是否支持我方 / 对方）
- 关键裁判理由（法官接受了哪方观点）
- 上诉期限（民事 15 日 / 行政 15 日 / 刑事 10 日）+ 起算点
- 上诉可行性评估（建议 JudgmentAnalyzer 出救济路径表）
- 客户决策：是否上诉 / 何时决定（**决策时限不得晚于上诉期限届满前 5 日**）

### 4. 调解 / 撤诉 / 和解后

新增字段：
- 协议主文（逐项列出双方义务）
- 履行节点（首期款 / 后续款 / 完结）
- 履行担保 / 强制执行公证（如有）
- 撤诉的诉讼费退还（民事案件撤诉一般退还 50% 诉讼费）
- 后续监督机制（定期回访 / 履行不能时的应对预案）

### 5. 执行启动 / 终本后

新增字段：
- 执行立案号
- 已查控财产清单（银行 / 房产 / 车辆 / 其他）
- 已采取措施（冻结 / 查封 / 限高 / 失信 / 拘传 / 拘留）
- 终本（终结本次执行程序）：何时可恢复执行 / 恢复条件
- 客户配合（提供财产线索 / 协助调查）

## 措辞要点

- **"实际进展 vs 预期对比"是核心**——客户最想知道"是否在轨"
- **法庭倾向评估务必谨慎**——基于客观信号（法官提问 / 笔录细节），不臆测；标注为"评估"而非"事实"
- **调解空间明示**——客户对调解空间的认知决定后续决策
- **决策时限红色加粗**——避免客户拖延导致法定期限错过
