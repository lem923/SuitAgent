# 风险预警模板

## 触发条件

任何**突发或紧急**事件需要客户立即关注或配合：

| 风险类型 | 触发实例 | 紧迫度 |
|---------|---------|--------|
| 时效届满 | 上诉期 / 举证期 / 答辩期剩余 ≤7 日 | 红 |
| 对方异常动作 | 对方申请保全 / 调查取证 / 撤回请求 | 橙 |
| 法院新发现 | 法院发现我方证据问题 / 主体资格瑕疵 | 红 / 橙 |
| 客户证据问题 | 客户证据被对方质疑 / 出现不利证据 | 橙 / 黄 |
| 当事人行为风险 | 客户言行可能影响案件（如媒体表态） | 橙 |
| 政策 / 法律变动 | 案件涉及的法规修订 / 司法解释发布 | 黄 |
| 第三方介入 | 案外人提出执行异议 / 被列入失信 | 红 / 橙 |

## 紧迫度分级（红 / 橙 / 黄）

| 等级 | 标准 | 客户应对时限 |
|------|------|------------|
| 🔴 红色（紧急）| 不立即应对将导致重大不利后果（如时效错过 / 财产被处分 / 案件被驳回）| 24-72 小时内必须配合 |
| 🟠 橙色（高度关注）| 可能影响案件走向但有应对窗口 | 5-7 日内决策 |
| 🟡 黄色（一般关注）| 当前不构成实质风险但需监控 | 视情况，1-2 周内 |

## 通用模板

```markdown
# [客户称谓] · 风险预警

> 案件：[案号或简称]
> 紧迫度：🔴 红色 / 🟠 橙色 / 🟡 黄色
> 触发日期：YYYY-MM-DD
> 报告日期：YYYY-MM-DD

## 一、风险概述

[1-2 句话陈述风险事件，必须具体可执行，不要空泛]

例如（红色）：
"本案上诉期限为 YYYY-MM-DD（即 X 日后），如客户决定上诉，需在 [日期] 前完成
书面授权 + 上诉费缴纳。逾期将丧失上诉权。"

## 二、风险性质

- **风险类型**：[时效 / 对方动作 / 法院发现 / 我方证据 / 当事人行为 / 政策变动 / 第三方]
- **触发原因**：[具体事件，含日期和来源]
- **可能后果**：[最严重情形 + 最可能情形 + 最佳情形]
- **可控性**：[完全可控 / 部分可控 / 需依赖外部]

## 三、即时应对（律师已采取）

[列出律师在收到风险信号后已经采取的动作，例如：
- 已立即与法院沟通了解 [情况]
- 已准备好 [应对文件]，待客户授权即可提交
- 已联系 [对方律师] 探讨 [可能解决方案]]

## 四、客户配合事项

| 序号 | 事项 | 截止时间 | 紧迫度 |
|-----|------|---------|--------|
| 1 | [具体动作，如"签署 [文书] 并回传扫描件"] | YYYY-MM-DD HH:mm | 🔴 |
| 2 | ... | ... | 🟠 |

**关键决策**：[一句话写明客户当下需要的核心决策；不超过 30 字]

## 五、应对方案

| 选项 | 描述 | 利 | 弊 | 律师推荐 |
|------|------|---|---|---------|
| A | [方案 A] | ... | ... | ⭐ 推荐 / 可选 |
| B | [方案 B] | ... | ... | 可选 |
| C | [方案 C] | ... | ... | 不推荐 |

## 六、决策时限

⚠️ **决策必须在 YYYY-MM-DD HH:mm 前完成**——否则将默认按 [选项 X] 执行。

如客户在该时点前未明确决策，律师将按已与客户既定方向（如有）继续操作。

---

如紧急请直接电话联系：[律师 + 联系方式]
[律师姓名] · [律所]
```

## 各风险类型的撰写要点

### 时效类风险

- **必含**：
  - 法定期限名称 + 法律依据
  - 起算点 + 届满日（精确到日，必要时精确到时）
  - 错过的法律后果（"丧失上诉权" / "证据不被采纳" 等）
  - 如何续期或恢复（如 [民事诉讼法] 第 86 条不可抗力顺延）
- **决策时限**：必须早于法定期限届满 2-3 日，给行政程序留缓冲

### 对方异常动作

- **必含**：
  - 对方动作的具体内容（含取得来源：法院通知 / 对方告知 / 媒体）
  - 法律依据（对方的合法性 / 是否程序合规）
  - 我方反制的法律依据（如执行异议 / 反保全申请 / 反诉）
  - 我方反制的时限（如反保全申请的期限）

### 法院新发现

- **必含**：
  - 法院发现的具体事实
  - 是否会触发法院依职权动作（如管辖权重新审查 / 主体资格补正）
  - 我方应对策略（积极补正 / 程序异议）

### 客户证据问题

- **谨慎措辞**：避免让客户感觉是"自己的错误"导致风险；客观陈述事实即可
- **必含**：
  - 证据问题的具体性质（来源 / 形式 / 内容瑕疵）
  - 对案件的实质影响（仅影响该项主张 / 影响整体）
  - 补救路径（补充新证据 / 重新调取 / 第三方证人）

### 当事人行为风险

- **极谨慎**：客户可能不接受被"指出问题"
- **必含**：
  - 行为的具体描述（言语 / 文字 / 媒体表态）
  - 法律风险（构成自认 / 违反诚信义务 / 影响调解）
  - 应对建议（不再就此话题对外发声 / 明确公开声明 / 配合律师统一口径）

## 措辞红线

- ✅ 客观、准确、可执行
- ❌ "建议尽快处理" → 改为 "请在 YYYY-MM-DD HH:mm 前完成 X 动作"
- ❌ "可能有风险" → 改为 "如不应对，可能导致 [具体后果]"
- ❌ "请律师建议" → 改为 "律师推荐选项 A，理由：[一句话]"
- ❌ 让客户在文档里学法律——风险预警不是普法

## 发送前自检

- [ ] 紧迫度分级是否准确（避免"狼来了"消耗客户信任）
- [ ] 决策时限是否合理（不能过于紧迫，不能过于宽松）
- [ ] 是否给出至少 2 个备选方案
- [ ] 律师推荐是否明确（含一句话理由）
- [ ] 是否含客户配合事项的具体动作
