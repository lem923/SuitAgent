# 决策建议书模板（兼客户问询回复）

## 与法律意见书的边界

**决策建议书 ≠ 法律意见书**：

| 维度 | 法律意见书（cn-firm-documents）| 决策建议书（本 skill）|
|------|----------------------------|---------------------|
| 性质 | 正式法律文件，有律所盖章 | 日常沟通文书，电子档为主 |
| 内容 | 完整法律分析（事实 / 法律 / 结论）| 引用已有 LegalOpinion 结论，给执行建议 |
| 长度 | 5-30 页 | 2-3 页 |
| 触发 | 客户对**法律问题本身**有疑问 | 客户面临**具体决策**需要拍板 |

**判断口径**：
- 客户问题本质是 **"X 在法律上算不算 Y？"** → 出 LegalOpinion（cn-firm-documents）
- 客户问题本质是 **"我现在该怎么办？选 A 还是选 B？"** → 出决策建议书（本 skill）

如果客户尚未有 LegalOpinion 但已经面临决策（一般是案件紧迫情况），**先快速出 LegalOpinion**（cn-firm-documents），再用本 skill 出决策建议；不要在决策建议书中重复 LegalOpinion 的法律分析。

## 决策建议书模板

```markdown
# [客户称谓] · 决策建议书

> 案件：[案号或简称]
> 决策事项：[一句话写清要决策什么]
> 报告日期：YYYY-MM-DD
> 决策时限：YYYY-MM-DD（前提：[依据何文件 / 何法律期限]）

## 一、决策事项概述

[1-3 句话明确客户需要决策的事项，例如：
"对方就 [X 案] 提出和解方案：撤回起诉 + 我方支付 [金额范围] + 后续 [义务]。
是否接受此方案，需在 YYYY-MM-DD 前给法院答复。"]

## 二、决策事项的事实背景

[简短回顾导致此决策点出现的事实链条；3-5 句话；不重复已知信息]

## 三、决策事项的法律基础（引用，不重复）

> 本案的法律基础已在 [YYYY-MM-DD 法律意见书] 中详细论述，本节仅引用核心结论。

[引用 LegalOpinion 的关键结论，例如：
- 我方在 [核心争点] 上的胜诉概率约 [区间]
- 对方主张的 [反驳点 X] 不成立，理由见 LegalOpinion 第 X 节
- 调解的法律基础：根据民事诉讼法第 96 条...]

如有未在 LegalOpinion 中涵盖的法律点，**列出"待确认事项"**而非在此展开新法律分析。

## 四、可选方案

每个方案 4 字段：描述 + 利 + 弊 + 风险

### 方案 A：[名称]

- **描述**：[具体方案，含数字 / 时间 / 行动]
- **利**：
  - [利益 1]
  - [利益 2]
- **弊**：
  - [代价 1]
  - [代价 2]
- **风险**：
  - [可能的不利后果 + 概率估计]

### 方案 B：[名称]

[同上结构]

### 方案 C：[名称]

[同上结构]

## 五、律师推荐

⭐ **律师推荐**：方案 [X]

**推荐理由**（3-5 点）：
1. [理由 1，含数据 / 法律依据 / 类案参考]
2. [理由 2]
3. [理由 3]

**fallback**：如客户出于 [X 因素] 不接受推荐方案，律师备选 [方案 Y]，
理由 [一句话]。

## 六、决策决议

请客户在 YYYY-MM-DD 前作出选择：

- [ ] 同意方案 A
- [ ] 同意方案 B
- [ ] 同意方案 C
- [ ] 其他（请说明：________）

【决策签字】

客户签字：____________________
日期：YYYY-MM-DD

## 七、决策后律师后续动作

| 决策选项 | 律师后续动作 | 完成时限 |
|---------|------------|---------|
| 选 A | [动作清单] | [时限] |
| 选 B | [动作清单] | [时限] |
| 选 C | [动作清单] | [时限] |

---

如有疑问需面谈或电话沟通，请在 YYYY-MM-DD 前预约。
[律师姓名] · [律所]
```

## 客户问询回复模板（决策建议书的局部简化版）

```markdown
# 客户问询回复

> 客户原问：[原问全文]
> 回复日期：YYYY-MM-DD

## 一、问题理解

[一句话复述客户问题，确保理解一致]

## 二、回复

[简明回答，1-3 段]

如涉及法律依据：
- [法条 / 司法解释引用]
- [简明解释，不展开法律分析]

## 三、后续配合事项（如有）

- [需要客户提供 / 确认 / 决定的事项]
- [时限]

---

[律师姓名] · [律所]
```

## 撰写要点

### 选项设计

- **每个决策必给至少 3 个选项**（包括"维持现状"作为默认选项之一）
- 选项之间要**真正可选**（不能 A 是 100% 优势 B 是 100% 劣势——这不是选项，是建议）
- 选项的"利"和"弊"要**对称**（不能 A 的利 5 项弊 1 项，B 的利 1 项弊 5 项——客户会觉得选项设计有偏向）

### 推荐表态

- 律师**必须**有明确推荐（不能"两个方案各有利弊，请客户酌定"）
- 推荐理由必须**可验证**（基于数据 / 法条 / 类案）
- fallback 方案必须**预备**（如客户拒绝推荐方案，下一步应对）

### 时限设置

- 决策时限**必须**早于法定期限 2-3 日（给行政流程留缓冲）
- 时限到期未决策的默认选项**必须**事先约定（避免空白期被动）

### 客户问询回复的快速决策

- 简单问题 ≤ 0.5 页 A4
- 引用既有产物（LegalOpinion / Strategist 策略 / Researcher 法条）而非重新论证
- 如问题超出本案范围（涉及客户未来其他事务），明确"建议另行委托咨询"
