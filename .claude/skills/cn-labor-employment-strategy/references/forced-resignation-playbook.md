# 被迫离职 / 推定解雇 Playbook（§38）

> **场景定位**：劳动者依《劳动合同法》§38 单方解除劳动合同（即时辞职 + 主张经济补偿）。
> 本 playbook 主要从 **employee 视角** 展开，作为 dismissal-misconduct-playbook 与 contract-modification-playbook 的反向应用。
> employer 视角主要是"如何避免被认定为被迫离职"的防御性策略。
>
> **stance 适用**：employer / employee 双视角，重点 employee。
> **判例支撑**：汇编 5.1 预告辞职 9 案 + 5.2 即时辞职 15 案 + 4.5(C) 涉疫解除部分案例，共约 27 案。
> 详见 `case-database/ch5-termination-and-exit.md` § 5.1 + § 5.2。

---

## 一、法理框架

### 1.1 §38 法定情形

《劳动合同法》§38：用人单位有下列情形之一的，劳动者可以解除劳动合同：

1. 未按照劳动合同约定提供劳动保护或者劳动条件的
2. 未及时足额支付劳动报酬的
3. 未依法为劳动者缴纳社会保险费的
4. 用人单位的规章制度违反法律、法规的规定，损害劳动者权益的
5. 因 §26(1) 致使劳动合同无效的
6. 法律、行政法规规定劳动者可以解除劳动合同的其他情形

**特殊路径**：§38 第二款（即时解除，无需提前通知）——用人单位以暴力、威胁或非法限制人身自由强迫劳动；违章指挥、强令冒险作业危及人身安全。

### 1.2 §38 与 §37 的关键区别

| 维度 | §37 预告辞职 | §38 即时辞职 |
|---|---|---|
| 触发条件 | 无需理由 | 单位存在法定情形 |
| 程序 | 提前 30 日书面通知 | 立即解除 |
| 经济补偿 | 0 | N（依 §46(1)）|
| 单位证明责任 | 无（劳动者主张时）| 单位反驳须举证 |

### 1.3 §38 与 §39 / §40 的攻防镜像

- 单位违法解除（§87）→ 2N
- 劳动者被迫解除（§38 + §46(1)）→ N

二者本质都基于"单位违反法律或合同义务"的事实，但触发主体不同：

- 单位先动手解除 → 劳动者主张 2N（违法解除赔偿金）
- 劳动者先动手解除 → 劳动者主张 N（被迫解除经济补偿）

**收益对比**：2N > N。员工在条件允许时优先选择 2N 路径（让单位先解除）。

## 二、§38 各项分述

### 2.1 §38(1) 劳动条件 / 劳动保护

**核心判例**：

| 情形 | 判例 | 是否成立 |
|---|---|---|
| 销售人员被要求居家办公致无法获得提成 | case 5.2.2 | 成立 |
| 调岗超出劳动者能力范围（变相辞退）| case 5.2.3 | 成立 |
| 调岗不合理 + 强行要求短时间交接（推定解雇）| case 5.2.6 苏州海星 | 成立 |
| 工作地点变更过远（劳动者拒绝提供劳动）| case 5.2.7 | 成立 |
| 假借疫情放长假变相逼迫离职 | case 4.5.17 | 成立 |
| 派遣员工被退回 + 不同意重新派遣 | case 5.2.4 | **不成立**（履行方式变化未达不能履行程度）|
| 短期临时性指派 + 工资性质隶属不变 | case 5.2.1 赖某 | **不成立**（适度调整非变更）|
| 内部异地调动符合合理性 + 实质影响不显著 | case 5.4.14、5.4.16 | **不成立** |

实务推论：**调岗 / 调动 / 工作地点变更引发的 §38(1) 争议，焦点在"是否实质影响"**。完全没影响（短期临时指派、合理范围内调动）→ 不成立；显著影响（居家办公变相辞退、调岗超出能力、跨城调动）→ 成立。

### 2.2 §38(2) 劳动报酬

**关键认定标准 —— 不是任何欠薪都构成"未及时足额"**：

case 5.2.9 周某诉某营销公司、case 5.2.10 宋某诉某木业（江苏立场）：

> §38 的立法目的是促进劳动合同当事人双方诚信履行劳动合同。"未及时足额支付劳动报酬"规制的是用人单位**有悖诚信恶意拖欠或拒绝支付**劳动报酬的行为。劳动者以此提出解除并主张经济补偿的，应综合考量：
> 1. 用人单位不支付劳动报酬的原因
> 2. 主观过错程度
> 3. 对劳动者生活的实质影响

实务推论：

| 情形 | 是否构成 §38(2) |
|---|---|
| 单位恶意拖欠 / 拒绝支付（无客观原因）| 成立 |
| 单位资金困难但有诚意（如疫情影响、客观经营困难）| 视情况严慎认定 |
| 单位在劳动者解除前已补发 | 不成立（消除违法情形）|
| 法定程序延期支付未超 30 日 + 无主观恶意 | 不成立（case 4.5.15 张某诉某旅游公司）|
| 停职检查期间按基本工资发放 + 后续合理处理 | 不成立（case 5.2.12）|
| 业务提成比例单方变更（损害权益）| 成立（case 5.2.8 陈某诉某公司）|
| 单位以"绩效"等浮动方式架空工资 | 视个案 |

### 2.3 §38(3) 社会保险

**关键认定标准**：

case 5.2.13 何某诉某保安公司（江苏立场）：

> §38 规定的"未依法为劳动者缴纳社会保险费"，是指用人单位因主观恶意未参保的情形。劳动者在自身不愿参保而与用人单位达成协议或者默契的情况下，又以用人单位未依法缴纳社会保险费为由主张经济补偿的，不予支持。但因缴纳社会保险费是用人单位的强制性义务，劳动者仍然有权要求用人单位补缴社会保险费。

case 5.2.14 田浩诉某煤矿（四川立场，与江苏不一致）：

> 用人单位以向劳动者发放社会保险现金补贴的方式代替参加社会保险 → 行为无效，劳动者主张 §38(3) 经济补偿应予支持。

**地区分歧**：

- 江苏：劳动者主动不参保 → 不能主张 §38(3) 经济补偿
- 四川等地：以补贴代替参保 → 仍可主张 §38(3) 经济补偿

### 2.4 推定解雇（implied dismissal）

汇编中的"推定解雇"概念（case 5.2.6 苏州海星、case 5.2.9 周某）：

> 用人单位根据工作需要变动劳动者岗位的，应当符合合理和诚信原则，不得滥用权利。用人单位在调岗过程中未向劳动者说明调岗在经营上的必要性，未告知新岗位的劳动条件、薪资待遇等基本事项，也未考虑对劳动者家庭和社会生活利益带来的不利影响，而是径直要求劳动者无条件接收调岗且必须在短时间内交接完毕的，明显有违合理和诚信原则。劳动者在此情形下辞职的，视为"推定解雇"，用人单位应当支付经济补偿。

实务推论：单位虽未明示解除，但通过不合理调岗、停薪留职（case 5.4.21）、停发工资等方式使劳动者无法继续履行的，构成推定解雇。

## 三、典型成本路径

### 3.1 employee 视角

| 路径 | 触发条件 | 收益 |
|---|---|---|
| **A 路径：直接 §38 解除** | 单位存在 §38 法定情形（恶意欠薪、违法降薪、未缴社保等）| N |
| **B 路径：被迫解除 + 主张违法解除赔偿金** | 单位虽未明示解除但实质构成推定解雇 + 在仲裁中"重新定性"为单位解除 | 2N（成功率低）|
| **C 路径：留岗 + 等单位先解除 + 主张 2N** | 单位违法事实清楚但未明示解除 | 2N（最优但需要耐心）|
| **D 路径：协商解除 N+1~3 月** | 单位有协商意愿 | N + 1~3 月 |

### 3.2 employer 视角（防御性）

| 单位动作 | 风险 | 防御要点 |
|---|---|---|
| 调岗不合理 | 推定解雇 → N | 严格按 contract-modification-playbook 四要素 |
| 拖欠工资 | §38(2) → N | 客观困难时书面告知 + 法定程序延期 |
| 不缴社保 | §38(3) → N（江苏除外） | 严禁以补贴替代参保 |
| 单方降薪 | §38(2) → N | 必须书面协议变更 |
| 停职检查不发工资 | §38(2) → N | 至少按基本工资发放 |
| 停薪留职 | 推定解雇 → 违法解除 2N | 严禁缺乏依据的"停薪留职" |
| 假借疫情放长假 | §38(1) → N | 必须有客观依据 + 程序合规 |

## 四、employee 操作清单（核心）

### 4.1 启动前自检

1. **核实 §38 触发情形**：哪一项？是否有证据？
2. **核查"恶意"标准**：欠薪是否单位故意？降薪是否未协商一致？
3. **核查地区裁判口径**：本地法院对 §38(2) "恶意"的认定标准（江苏严、北京宽）
4. **评估路径选择**：
   - 单位明示解除可能性高 → 等单位先动手（C 路径，2N）
   - 单位会一直拖 → 主动 §38 解除（A 路径，N）

### 4.2 §38 解除书面通知

**必备要素**：

- 解除依据（§38 具体项）
- 单位违法事实陈述（具体、明确、有据）
- 解除生效时间（即时生效）
- 工作交接安排
- 主张经济补偿的初步通知（具体金额 / N 计算公式）

**送达方式**：

- 现场签收 + 录音 / 同事见证
- EMS 邮政特快（公司注册地址）
- 邮件 / 微信同步（辅助证据）

### 4.3 仲裁请求要点

主请求：

- 经济补偿金 N（依 §46(1)）
- 未支付的劳动报酬（如适用 §38(2)）
- 补缴社保 / 公积金（如适用 §38(3)）
- 未休年休假折算工资
- 加班费（如适用）

辅助请求：

- 出具离职证明
- 办理社保 / 档案转移

### 4.4 关键证据清单

| 证据 | 证明目的 |
|---|---|
| 劳动合同 / 入职文件 | 劳动关系 + 原工资标准 |
| 工资银行流水（至少 12 个月）| 月工资基数 + 欠薪事实 |
| 单位的违法行为证据（调岗通知、降薪通知、欠薪记录、未缴社保查询单等）| §38 触发事实 |
| 自己的解除通知 + 送达证据 | 解除程序合法 |
| 单位的回应 / 反馈 | 防止单位反诉旷工 |

## 五、关键陷阱与红线

### 5.1 employee 红线

- ❌ **不要在解除通知上写"自愿离职"** —— 离职原因栏务必写明"因单位 [具体事实]，依 §38(X) 解除"
- ❌ **不要先停止工作再解除** —— 容易被反诉旷工
- ❌ **不要被诱导签"协商解除"** —— §38 解除 N + 协商解除 N 差异不大，但协商解除会丧失主张恶意欠薪 / 违法降薪等额外赔偿的空间
- ❌ **不要主张范围过窄** —— §38 解除可叠加主张未休年假、加班费、社保补缴等

### 5.2 employer 红线（防御性）

- ❌ "停薪留职"无明确依据 → 推定解雇
- ❌ 调岗未沟通即强推 + 短时间交接要求 → 推定解雇
- ❌ 单方降薪 + 默示推定 → 被迫离职 §38(2)
- ❌ 假借疫情、客观困难放长假 → §38(1)
- ❌ 拒绝出具离职证明 / 拒绝办理社保转移 → 附随义务违反 + 赔偿损失

## 六、预告辞职（§37）相关问题

虽然预告辞职无需理由也无经济补偿，但汇编 5.1 中有几条对 employer 重要的规则：

### 6.1 辞职权是形成权

case 5.1.2 刘宇红诉碧优缇、case 5.1.8 程某诉正大畜牧：

> 劳动者的辞职权系形成权，意思表示到达对方即为生效。在未经用人单位同意的情况下，劳动者无权自行撤销已生效的辞职。

但 case 5.1.3 张某诉某酒店：

> 劳动者提出辞职申请后，用人单位在合理期限内未作明确答复，能够认定双方以行为方式表明就继续履行劳动合同达成一致意见的，劳动者的辞职行为因此失效。用人单位再以"同意辞职"为由要求劳动者离职的行为缺乏事实依据，属于违法解除劳动合同。

实务推论：劳动者辞职后，单位应当**及时明确答复**（同意 / 不同意），否则可能产生"默示挽留"的法律效果。

### 6.2 单位有权要求提前离职

case 5.1.1 赵维波诉宁波均胜：

> 在劳动者的辞职预告期内，用人单位有权要求劳动者提前离职，该行为不属于用人单位违法解除合同。

### 6.3 辞职原因不明的处理

case 5.1.5 北京崇道广业诉刘江涛：

> 劳动者在用人单位提供的离职审批表、离职交接清单等材料中未写明离职理由，不能当然认定为主动辞职。劳动者主张系用人单位胁迫其辞职的，应当结合双方提供的证据综合认定解除原因。

### 6.4 自动离职

case 5.1.6 胡某诉乳源瑶族自治县名瑶酒店：

> 劳动者未履行任何告知程序而主动离开用人单位的，应视为其自动离职，用人单位无需支付经济补偿。

但单位仍应留证（多次催告返岗、最后通知函等），避免被反诉违法解除。

## 七、与其他 playbook 的衔接

- **上游触发**：调岗不合理（contract-modification-playbook）→ 触发 §38(1)
- **上游触发**：违法解除（dismissal-misconduct-playbook）→ 劳动者选 2N 路径而非 §38 路径
- **下游衔接**：§38 解除成立 → 转入 severance-agreement-playbook 处理协议事宜（如有）
- **关联场景**：续签场景中员工书面主张原岗位 + 单位坚持调岗 → 接近 §38(1) 情形（见 contract-renewal-playbook 第三阶段反向应用）
