# 文书模板速查

> 本文件提供 cn-labor-employment-strategy 涉及的关键文书模板。
> 各模板按"用途 / 法律依据 / 必备要素 / 模板正文 / 送达建议"组织。
>
> 模板均为基础版，主办律师应根据具体案件调整。涉及金额、期限等具体数值
> 由变量【】标注，使用时替换为实际事实。

---

## 一、《续订劳动合同要约书》（employer 用）

**用途**：合同到期前向劳动者发出续订要约，固定单位履行 §14 法定义务的证据。

**法律依据**：《劳动合同法》§14、§44(1)

**必备要素**：

1. 单位与劳动者基本信息
2. 原合同到期日
3. 续订合同的核心条款（期限、岗位、薪酬、地点、工时）
4. 续订条件与原合同条件的对比（凸显"维持或提高"的事实）
5. 劳动者答复期限
6. 送达方式与签收要求

**模板正文**：

```
                        续订劳动合同要约书

致：【劳动者姓名】，身份证号【】

您与本公司于【】签订的劳动合同（合同编号：【】）将于【】到期。
根据《劳动合同法》第十四条规定，本公司现向您发出续订劳动合同的书面要约，
具体条款如下：

一、合同期限：无固定期限【或：自【】至【】】
二、工作岗位：【新岗位名称】（原岗位：【】）
三、月工资：人民币【】元（原工资：【】元，提高【】%）
四、工作地点：【】（与原合同相同）
五、工作时间：【】（与原合同相同）
六、其他条款：与原合同条款一致【或：附件列明变更条款】

本要约的核心条件相对原合同已**维持或提高**：

| 项目 | 原合同 | 续订要约 | 变化 |
|---|---|---|---|
| 月工资 | 【】元 | 【】元 | 提高 【】% |
| 岗位 | 【】 | 【】 | 调整（业务依据见附件）|
| 期限 | 固定期限 | 无固定期限 | 期限保障提升 |
| 地点 | 【】 | 【】 | 不变 |

请您于【】日内书面答复本要约。逾期未答复或拒绝接受的，视为不同意续订，
合同期满终止。本公司将按法律规定处理后续事宜。

附件：
1. 《岗位调整说明》
2. 续订劳动合同文本（拟签版）

【单位盖章】
【签发日期】

------------------（以下由劳动者填写）------------------

劳动者答复：□ 同意续订   □ 不同意续订   □ 反要约（请书面说明）

劳动者签名：___________________
日期：___________________
```

**送达建议**：

- 优先现场签收（HR + 员工双签）
- 拒签时 EMS 送达劳动合同载明地址 + 身份证地址（双发）
- 保留送达底单 + 妥投记录

## 二、《岗位调整说明》（employer 用）

**用途**：作为续订要约的附件，证明岗位调整有独立业务依据。

**法律依据**：用工自主权 + 京高法发〔2024〕534号"四要素"

**必备要素**：

1. 业务调整的客观背景
2. 岗位调整的必要性
3. 新岗位与员工匹配度说明
4. 调整后劳动条件无不利变更的证明

**模板正文**：

```
                        岗位调整说明

一、业务调整背景

【公司】于【年月日】根据【经营计划/组织架构调整决议/部门撤并方案】（见附件 1），
对【部门/业务线】进行了如下调整：

1. 【具体调整事项 1】
2. 【具体调整事项 2】

该调整决议形成于【年月日】，早于本次续订要约的发出时间，系基于公司整体经营需要，
非针对特定劳动者。

二、岗位调整的必要性

基于上述业务调整，原【】岗位的工作职责已发生以下变化：

1. 【职责变化 1】
2. 【职责变化 2】

为适应业务需要，公司需要调整【】岗位的人员配置。

三、新岗位与员工匹配度

新岗位"【】"的核心职责为【】，与员工的专业背景（【】）和工作经验
（【】）实质衔接，员工具备胜任新岗位的能力。

四、劳动条件无不利变更

| 项目 | 原岗位 | 新岗位 | 变化 |
|---|---|---|---|
| 岗位级别 | 【】 | 【】（同级别） | 不变 |
| 月工资 | 【】元 | 【】元 | 提高 |
| 工作地点 | 【】 | 【】 | 不变 |
| 工作时间 | 【】 | 【】 | 不变 |
| 晋升通道 | 【】 | 【】 | 不变 |

五、过渡安排（可选）

公司承诺为员工提供以下过渡安排：

1. 转岗培训：【】
2. 试用期保留原薪资：【】月
3. 汇报关系：【】

附件：
1. 【组织架构调整决议】
2. 【部门撤并方案】
3. 【新岗位职责书】
```

## 三、《劳动合同到期不续订通知书》（employer 用）★ 重点

**用途**：合同到期后单位与劳动者未能达成续订合意时，固定证据 + 明确单位法律立场。

**法律依据**：《劳动合同法》§44(1)、§46(5) 但书

**必备要素**：

1. 单位已尽 §14 法定义务的证据指引
2. 劳动者拒绝接受 + 单位不接受反要约的事实陈述
3. 单位主张 §46(5) 但书的法律立场
4. 工作交接与离职手续安排

**模板正文**：

```
                        劳动合同到期不续订通知书

致：【劳动者姓名】，身份证号【】

您与本公司于【】签订的劳动合同（合同编号：【】）将于【】到期。
就续订劳动合同事宜，本公司特此通知如下：

一、本公司已尽《劳动合同法》第十四条法定义务

本公司已于【】通过《续订劳动合同要约书》向您提供合法续订要约，要约内容包括：

1. 无固定期限劳动合同
2. 工作岗位：【】（业务依据见《岗位调整说明》）
3. 月工资：【】元，较原合同提高 【】%
4. 工作地点、工作时间等条件维持不变

本公司已书面提供合法续订要约，依法履行了订立无固定期限劳动合同的法定义务。

二、双方未能达成续订合意

您于【】书面答复，不接受本公司的续订要约，要求按【您的反要约内容】续订。

经审慎评估，本公司不接受您的反要约。本公司的续订要约已为合法且条件优于原合同，
您拒绝接受本公司的要约，本公司亦不接受您的反要约。双方未能就续订劳动合同达成合意。

三、本公司曾提议协商解除作友好退出，您亦拒绝

本公司于【】通过书面/口头方式向您提议以【N + 0.5~1 月】对价协商解除劳动合同，
您于【】书面/口头表示拒绝。

四、本公司的法律立场

根据《劳动合同法》第四十六条第（五）项但书规定，本公司维持或提高劳动合同
约定条件续订劳动合同，劳动者不同意续订的，本公司不支付经济补偿。

本公司明确主张：本公司提供的续订要约已"提高"原劳动合同约定条件（薪酬提高
【】%），符合上述但书适用情形。本公司**无需支付经济补偿**。

五、合同终止与后续安排

您的劳动合同于【】期满终止。请按以下安排办理离职手续：

1. 工作交接：请于【】前完成工作交接（清单见附件）
2. 离职手续：请于【】前办理社保转移、公积金清算、工作证件归还等手续
3. 离职证明：本公司将于您完成上述手续后【】日内出具离职证明
4. 工资结算：截至合同到期日的工资 + 未休年休假折算将于【】支付至您的工资账户

特此通知。

附件：
1. 《续订劳动合同要约书》（已签收回执）
2. 您的反要约书面/录音记录
3. 协商解除提议记录
4. 工作交接清单

【单位盖章】
【签发日期】

签收：劳动者签名 ___________________   日期 ___________________
```

**送达建议**：

- **关键证据**——必须用最严格的送达方式
- 优先现场签收 + 录音/录像
- 拒签时 EMS 双发（合同载明地址 + 身份证地址）+ 公证送达备份
- 同步邮件 + 微信送达作为辅助证据
- 保留所有送达凭证 ≥ 3 年（仲裁时效 1 年 + 上诉周期）

## 四、《协商解除劳动合同协议》

**用途**：双方协商一致解除劳动合同时签订，含概括了结条款封堵翻案。

**法律依据**：《劳动合同法》§36、§46(2)、§47

**模板正文**：

```
                  协商解除劳动合同协议

甲方（用人单位）：【】
乙方（劳动者）：【】，身份证号【】

甲乙双方原签订《劳动合同》（编号：【】），合同期限自【】至【】。
经双方友好协商，达成如下协议：

一、解除事项

双方一致同意自【年月日】起协商解除劳动合同。解除性质为协商一致解除
（《劳动合同法》第三十六条）。

二、经济补偿

甲方一次性向乙方支付经济补偿人民币【】元（含税）。该金额包含：

1. 法定经济补偿金（按工龄折算）：【】元
2. 额外协商对价：【】元

支付方式：自本协议签订之日起【】日内，由甲方转账至乙方指定账户。

三、工作交接

乙方应于【】前完成工作交接，包括但不限于：

1. 在办项目移交（清单见附件 1）
2. 客户资料、文件、设备归还
3. 工作账号、门禁、邮箱权限清理
4. 知识产权确认（在职期间产生的成果归属甲方）

四、保密义务

乙方在职期间获悉的甲方商业秘密、客户信息、技术资料等，离职后仍负有保密义务。
保密期限【】年。

五、竞业限制（如适用）

【□ 启用 / □ 弃用】

启用时：乙方在离职后【】月内不得在与甲方有竞争关系的单位任职。甲方按月
支付经济补偿【】元。

六、其他费用结算

截至本协议签订日，甲方已结清乙方的：

1. 工资（含基本工资 + 绩效 + 奖金）
2. 加班费
3. 未休年休假折算工资
4. 报销款
5. 社保公积金（缴纳至【】月）

七、概括了结条款 ★ 关键

双方确认，本协议项下事项已涵盖双方因劳动关系产生的全部权利义务。除本协议
明确约定的事项外，双方再无其他任何争议或权利主张（包括但不限于工资、加班费、
经济补偿、社保、公积金、年假、奖金、股权激励、知识产权等）。

乙方明确放弃就劳动关系存续期间及解除事宜向甲方主张任何其他权利的权利。

八、违约责任

任一方违反本协议约定的，应向守约方支付违约金人民币【】元。

九、争议解决

因本协议产生的争议，由甲方所在地的劳动争议仲裁委员会管辖。

十、本协议自双方签字盖章之日起生效。一式两份，双方各执一份。

甲方（盖章）：___________________   日期：___________________
乙方（签字）：___________________   日期：___________________
```

**风险提示（双视角）**：

- **employer**：第七条"概括了结"是核心，缺失则未来仍有翻案风险
- **employee**：签字前必须想清楚——签后基本无法翻案；存在违法事实（如规章制度
  瑕疵、违法调岗）时，先不签，去咨询专业意见后再决定

## 五、《解除劳动合同通知书》（违纪解除 §39 用）

**用途**：单位以严重违纪解除劳动合同时使用。

**法律依据**：《劳动合同法》§39

**必备要素**：

1. 解除的法律依据（§39 具体款项）
2. 违纪事实描述（具体、明确）
3. 违反的规章制度条款（具体编号）
4. 证据指引
5. 工会告知情况

**模板正文**：

```
                    解除劳动合同通知书

致：【劳动者姓名】，身份证号【】

经查实，您存在以下违纪事实：

【具体事实描述：时间、地点、行为、后果】

上述行为违反了《【单位规章制度名称】》第【】章第【】条之规定（"严重违纪情形"
明确列举【】），构成严重违纪。

证据材料：
1. 【证据 1】
2. 【证据 2】
3. 【证据 3】

根据《劳动合同法》第三十九条第（二）项规定，本公司决定自【年月日】起与您
解除劳动合同。

本公司已于【】将本次解除决定书面告知公司工会（告知函附后）。

请您于【】前办理离职手续。本公司将于完成手续后【】日内出具离职证明。

附件：
1. 违纪事实证据材料
2. 《【单位规章制度名称】》（含民主程序记录 + 公示证据）
3. 工会告知函

【单位盖章】
【签发日期】

签收：劳动者签名 ___________________   日期 ___________________
```

## 六、模板调用规范

启用模板时按以下规范：

1. **变量替换**：所有【】标注的变量必须替换为实际事实，不得留空
2. **附件齐备**：附件清单中提及的所有文件必须实际附上
3. **签收确认**：所有通知必须有签收回执或可靠送达证据
4. **版本控制**：单位定期评估模板是否需要更新（如本地司法政策变化）
5. **个案调整**：模板为通用版，复杂案件应由主办律师根据具体情况调整
