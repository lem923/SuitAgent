# 合同续签 / 不续签 Playbook

> **场景定位**：劳动合同到期前后的续签/不续签策略博弈，含一次合同、二次合同、
> 第三次（应订立无固定期限）三个时点。本 playbook 重点覆盖**二次合同到期**场景——
> 这是 §14(2)(3) 与 §46(5) 但书的核心战场。
>
> **stance 适用**：employer / employee 双视角，下文以 employer 为主线，
> employee 视角在每节末尾以"反向应用"标注。

---

## 一、法理框架（§14 与 §46(5) 但书的分立）

### 1.1 两个独立测试

| 测试 | 管什么 | 后果 |
|---|---|---|
| **§14(2)(3)** | 合同**形式**——单位必须提供无固定期限合同（除非劳动者主动要求固定期限） | 违反 → §87 → 2N |
| **§46(5) 但书** | **经济补偿**——单位是否需要付 N | 但书成立 → 0；不成立 → N |

关键认知：**§14 与 §46(5) 但书是两个独立测试，不是从属关系**。
即便单位的要约形式合法（满足 §14），也可能因条件未维持而无法套用 §46(5) 但书。

### 1.2 §46(5) 但书的两条路径

```
§46(5) 但书 "用人单位维持或者提高劳动合同约定条件续订劳动合同，
              劳动者不同意续订的，不支付经济补偿"
                        │
                        ├──→ 路径 A："维持"路径
                        │     适用：条款逐项与原合同等价
                        │     风险：地区分歧大，"维持"的实质审查更严格
                        │
                        └──→ 路径 B："提高"路径 ★ 推荐
                              适用：核心条件（通常为薪酬）"提高"
                              优势：事实清晰可量化，司法审查相对稳定
                              边角条件（如岗位）变动不影响但书适用
```

### 1.3 二次合同到期的特殊性

劳动者在二次合同到期时享有 §14(2)(3) 法定选择权——单位无权直接拒绝续签。
这导致**直接不续签**几乎必然落入违法终止：

- 北京：京高法发〔2017〕142号 第 34 条，直接发终止通知 → 2N
- 湖北：鄂人社发〔2024〕7号 第 10 条，劳动者主张赔偿金或继续履行均支持
- 上海：2024 年市高院研讨意见已转向，旧 N 立场不可机械援引

## 二、五方案对比矩阵（employer 视角）

参考 `assets/comparison-template.pdf`（A4 横版仿宋字体）。

### 方式一：协商不再续约

- **法律依据**：《劳动合同法》§44(1)、§46(5) 主文、§47；可叠加 §36
- **操作要点**：书面要约 + 劳动者书面同意放弃 §14 选择权 + 签终止协议
- **最佳情况下成本**：N
- **司法实践一般成本**：N + 0.5~1 月（协商加码作为对价）
- **最差情况下成本**：N（基本封顶；协议中"概括了结"条款封堵翻案）
- **违法解除风险**：低
- **适用场景**：单位明确不想留人 + 员工无对抗意愿

### 方式二：公司单方面不再续约 ❌

- **法律依据**：形式援引 §44(1)，实质违反 §14(2)(3)，适用 §87
- **操作要点**：直接发《合同到期不再续签通知书》——无任何合规空间
- **最佳情况下成本**：0（单位主张）
- **司法实践一般成本**：**2N**（违法终止几乎必败）
- **最差情况下成本**：2N + 期间工资（劳动者依 §48 选恢复劳动关系：1-2 年仲裁周期工资）
- **违法解除风险**：极高
- **判断**：**无任何适用情形**，单位绝不应采用

### 方式三：无固定期限合同 + 调岗（薪酬不变）

- **法律依据**：§14(2)(3) + §46(5) 但书（条件审查）
- **操作要点**：提供无固定期限要约 + 同步变更岗位 + 等候劳动者拒签
- **最佳情况下成本**：0
- **司法实践一般成本**：约 1.0~1.3N（劳动者反向要约风险高）
- **最差情况下成本**：2N + 期间工资（劳动者反向要约后认定违法终止）
- **违法解除风险**：中-高
- **判断**：薪酬不变情形下"维持"路径太脆弱，劳动者反向要约容易得手

### 方式四：员工主动离职

- **法律依据**：§37（提前 30 日书面通知）
- **操作要点**：不可主动追求；仅在员工真实自愿离职时被动承接
- **最佳情况下成本**：0（员工真主动时）
- **司法实践一般成本**：0（真主动）/ N~2N（被认定为单位施压）
- **最差情况下成本**：N（被认定协商解除）/ 2N（被认定胁迫离职）
- **违法解除风险**：中
- **判断**：不可作为策略目标，主动追求即意味着施压

### 方式五：无固定期限合同 + 调岗 + 略微提高薪酬 ★ 推荐

- **法律依据**：§14(2)(3) + §46(5) 但书"**提高**"路径 + 用工自主权
- **操作要点**：提供无固定期限要约 + 调岗 + 同步加薪 5% 以上作为对价
- **最佳情况下成本**：加薪成本（员工接受 → 单位获得长期用工 + 岗位灵活性）
- **司法实践一般成本**：加薪成本 ≈ 单年薪资增量 × N 年（折算通常 < 0.5N）
- **最差情况下成本**：加薪成本 + N（极少数法院认岗位贬损未维持条件的极端情形）
- **违法解除风险**：低-中
- **综合期望成本**：约 0.5~0.8N
- **判断**：推荐方案

## 三、方式五法理深度拆解

### 3.1 为什么走"提高"路径而非"维持"

加薪 5% 以上使薪酬"提高"事实清晰可量化；岗位变更不影响但书适用，
因薪酬这一最核心条件已"提高"——法院在"维持或提高"整体审查中，
薪酬权重压倒岗位权重（除非岗位明显贬损）。

### 3.2 关键执行要件

1. **加薪写入新合同工资条款**——不得以"绩效奖金"等浮动方式架空
2. **岗位调整满足北京高院"四要素"**（京高法发〔2024〕534号）：
   - 经营必要性
   - 目的正当性
   - 员工能胜任
   - 劳动条件无不利变更
3. **业务依据须有早于谈判节点形成的独立客观证据**：
   - 部门调整决议
   - 组织架构变更文件
   - 岗位需求文件
   - 不得为单一员工量身定制
4. **全程书面化**——口头沟通后即时邮件确认

### 3.3 司法路径分布（综合期望成本来源）

```
路径 ①：但书"提高"成立认定（约 60-70%概率）→ 0 经济补偿
路径 ②：条件未维持认定（约 15-25%）→ N
路径 ③：§14 实质违反认定（约 10-15%）→ 2N
```

综合期望成本 = 0×0.65 + N×0.2 + 2N×0.15 ≈ 0.5N

## 四、五阶段谈判时序（按 employer 视角）

### 第一阶段 · 开局——书面发出方式五完整方案

**动作**：

- 无固定期限合同 + 新岗位 + 加薪 5% 以上
- 同步附《岗位调整说明》阐述独立业务依据
- 预备过渡安排（保留原薪资若干月、转岗培训、明确汇报关系）作为后续让步空间，
  但**岗位变更本身不可后退**

**单位成本预期（员工此节点接受时）**：加薪成本 ≈ < 0.5N（按工龄折算）+ 可选过渡期成本

### 第二阶段 · 员工坚拒调岗时——坚持要约 + 平行提出协商解除

**动作**：

- 方式五要约保持不变
- 同步以 N + 0.5~1 月为对价提议协商解除
- 话术明确：调岗方案基于业务需要、已加薪、未撤回；员工二选一——接受新方案或协商离开

**单位成本预期**：N + 0.5~1 月

### 第三阶段 · 员工拒绝协商解除、主张原岗位 + 无固定期限时——继续坚持原方案

**动作**：

- 员工的反要约**不强制单位变更原方案**
- **这是策略一致性的关键节点**——岗位一旦松动，时序意图链条断裂，但书"提高"路径同步失效
- 给员工最后决定期限

**单位成本预期**：加薪成本 ≈ < 0.5N（员工最终接受方式五时）；否则进入第四阶段

### 第四阶段 · 员工最终全部拒绝时——发出《劳动合同到期不续订通知书》固定证据

**动作**：合同到期前书面发出通知（签收确认或 EMS 留证），载明：

1. 单位已提供无固定期限合同 + 加薪 + 岗位调整的合法要约（已尽 §14 法定义务），
   员工拒绝接受，单位亦不接受员工"原岗位 + 无固定期限"的反要约，双方未能达成续订合意
2. 单位曾提议协商解除作友好退出，员工亦拒绝
3. 依《劳动合同法》§46(5) 但书"提高条件"路径，单位主张无需支付经济补偿
4. 合同期满终止 + 工作交接 + 离职手续办理安排

**此通知是后续仲裁/诉讼的核心证据**，发送时机宜在合同到期前合理期限内、
谈判明确破裂之后。

**单位成本预期**：0（员工接受合同到期终止，无后续争议）

### 第五阶段 · 员工提起仲裁/诉讼时——司法应对（兜底）

司法路径分布（同 3.3）：①但书成立 60-70% → 0；②未维持 15-25% → N；③§14 违反 10-15% → 2N。

**综合期望成本 ≈ 0.5~0.8N**。

一审不利可加码协商解除（N + 1 月递增）促撤案；最坏封顶 ≈ 2N + 期间工资。

## 五、红线禁止

施压、停发工资、擅自调离工位、不安排工作——任一动作可能被认定为单位被迫解除，
前述策略链全部失效，直接落入 N 或 2N 路径。

## 六、反向应用（employee 视角）

stance = employee 时，同样的法理框架做相反操作：

### 6.1 二次合同到期前的主动布局

- 合同到期前**主动书面提出**"按 §14(2)(3) 订立无固定期限合同"
- 时点**早于**单位发出方式五要约 → 剥夺单位的时序意图
- 保留送达证据

### 6.2 收到单位方式五要约时的反向操作

不要直接拒签，**书面反要约**："我同意签无固定期限合同，但要求维持原岗位 + 原薪资。
请按此条件重新发出要约。"

### 6.3 单位坚持原方案时的诉求选择

依 §48 二选一：

- **路径 A**：主张恢复劳动关系 + 订立无固定期限合同（按原条件）
- **路径 B**：主张违法终止赔偿金 2N

选择 B 时收益更高（2N > N），且不需要长期博弈。

### 6.4 关键证据准备

- 单位方式五要约书 + 自己的反要约书面
- 单位拒绝按原条件续签的书面/录音证据
- 合同到期日的工作状态（继续在原岗位履职的证据）
- 单位的《不续订通知书》（关键证据）

### 6.5 仲裁请求建议

主请求：违法终止赔偿金 2N + 期间工资（如选恢复）
辅助请求：未休年假折算、加班费、社保差额等可叠加请求
