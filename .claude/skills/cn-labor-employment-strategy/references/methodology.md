# 核心方法论

本文件定义 cn-labor-employment-strategy 的三大方法论支柱。所有 scenarios 应用这些方法论
进行策略分析。

---

## 一、三档成本矩阵 + 概率分布

### 1.1 计价单位：N 倍数

不使用绝对金额，统一使用 N 倍数表达：

- **N** = 月工资 W × 工龄年数 Y
- 计算规则：6 个月以上不满 1 年按 1 年计；不满 6 个月按 0.5 个月计
- 月工资 W = 劳动者解除前 12 个月平均工资（含奖金、津贴、补贴、加班费等所有劳动报酬）
- 工资基数封顶：当地上年度社平工资 3 倍（高薪员工适用，§47(2)）；同时工龄
  封顶 12 年（仅适用于 3 倍封顶时）

常见 N 倍数表达：

| 表达 | 含义 |
|---|---|
| 0 | 单位无需支付 |
| N | 法定经济补偿（§47）|
| N + 1 | 加付 1 个月工资（如代通知金 §40 / 协商加码）|
| N + X | 协商解除加码（X 月数） |
| 2N | 违法解除赔偿金（§87）|
| 2N + 期间工资 | 违法解除 + 劳动者依 §48 选择恢复劳动关系（含仲裁/诉讼周期工资）|
| 加薪成本 | 选择长期用工时的对价（非一次性，按工龄折算） |

### 1.2 三档表达

每方案必须给出：

| 档位 | 含义 | 输出格式 |
|---|---|---|
| **最佳情况下成本** | 执行无阻力时的支付 | 单一数值或区间，如 "0" / "N" / "加薪成本 ≈ < 0.5N" |
| **司法实践一般成本** | 进入仲裁/诉讼时的预期 | 区间，如 "N + 0.5~1月" / "0.5~0.8N" |
| **最差情况下成本** | 极端情形封顶 | 单一上界，如 "2N + 期间工资" |

### 1.3 概率分布要求

成本数额后必须附概率估算。分布粒度：

- **粗粒度**（场景明确时）：高/中/低（如"该方案被认定违法解除风险：低"）
- **中粒度**（多路径情形）：百分比区间（如"司法路径分布：①但书成立 60~70% → 0；
  ②未维持 15~25% → N；③§14 违反 10~15% → 2N"）
- **细粒度**（涉及具体地区+变量）：附条件概率（如"在北京、工龄 ≥ 5 年、岗位
  贬损明显时，§14 违反认定率上升至 25~30%"）

无判例依据时标 ⚠️[估算]。

### 1.4 综合期望成本计算

多路径方案应给出综合期望成本：

```
E[成本] = Σ (路径成本 × 路径概率)
```

例（方式五 / 二次合同到期场景）：

```
E = 0 × 65% + N × 20% + 2N × 15% = 0.5N
```

这是单一可比的总成本指标，便于跨方案对比。

## 二、时序意图原则

### 2.1 核心命题

单位（或劳动者）动作的法律意义高度依赖**发起时间点**。同一动作在不同时点提出，
法律后果可能截然相反。

### 2.2 经典对照

| 时序 A：员工 §14 主张前已提出调岗 | 时序 B：员工 §14 主张后才推调岗 |
|---|---|
| 调岗是单位的"既定方案"，员工的反要约是对单位方案的回应 | 调岗是对员工诉求的"反向打击" |
| 目的正当性可立得住 | 目的正当性几乎必败 |
| §46(5) 但书"提高"路径有效 → 0 或 N 风险 | 跳过 §46(5) 直接落入 §14 违反 → 2N 风险 |

### 2.3 操作要件

时序意图想发挥法律效力，证据必须满足：

1. **时间线证据**——文件签发日期、内部决策记录、HR 备忘录都能证明动作发起时间
2. **业务依据独立性**——部门调整决议、组织架构图变更、岗位需求文件等，**不是
   为单一员工量身定制的说辞**
3. **沟通过程连贯性**——单位在每一轮沟通中都坚持原方案，不出现"先放弃再捡回来"的反复
4. **书面化全程贯穿**——开局要约、调整说明、对反要约的书面回应、最终文件

### 2.4 反向应用（劳动者视角）

stance = employee 时，时序意图同样适用：

- 主动书面提出 §14 诉求的时点应**早于单位的不利动作**
- 若单位先提出调岗，劳动者应在收到调岗通知**后立即**书面提出 §14 诉求，并
  保留单位反应的全部证据
- 主张被迫解除（§38）时，触发事由（如停发工资、调离工位）的时间点必须早于
  劳动者提出解除的时间点

## 三、证据链固定策略

### 3.1 关键节点必发书面通知

| 动作 | 必发文书 | 核心证据价值 |
|---|---|---|
| 调岗 | 《岗位调整通知书》+ 业务依据说明 | 固定调岗方案与时点 |
| 调薪 | 《薪酬调整通知书》+ 调薪依据 | 固定调薪方案与依据 |
| 续签 | 《续订劳动合同要约书》（含完整条款对比） | 证明已尽 §14 法定义务 |
| 不续签 | 《劳动合同到期不续订通知书》 | 主张 §46(5) 但书 / 锁定终止性质 |
| 违纪警告 | 《违纪事实告知书》+ 员工签收 | 累计违纪证据 |
| 违纪解除 | 《解除劳动合同通知书》 | 载明法定依据 + 事实理由 + 证据指引 |
| 协商解除 | 《协商解除劳动合同协议》 | 含概括了结条款封堵翻案 |
| PIP 启动 | 《绩效改进计划通知书》+ 员工签收 | §40(2) 不胜任认定的程序要件 |
| 不胜任解除 | 《解除劳动合同通知书》+ PIP 评估结论 | §40(2) 调岗或培训后仍不胜任的实质要件 |

### 3.2 送达方式

按可靠性排序：

1. **现场签收**（HR + 员工双签，含日期）——最稳
2. **EMS 邮政特快**（按合同载明地址或员工身份证地址，保留底单 + 妥投记录）
3. **公证送达**（邮政或公证员协助送达，复杂案件使用）
4. **电子邮件 + 微信/钉钉同步**（仅作为辅助证据，不单独使用）
5. **公告送达**（仅限劳动者下落不明，慎用）

### 3.3 沟通过程留证

- 口头沟通后即时**邮件总结**（含时间、地点、参与人、主要内容、待办）
- 微信沟通保留**完整聊天记录**（截图 + 原始数据导出）
- 现场谈话**经员工同意**后录音；不同意时改用纸质沟通记录单 + 双签
- 必要时安排**第三人在场**作证（如工会代表、HR 主管）

### 3.4 反证陷阱（红线动作）

stance = employer 时，下列动作可能被认定为"单位被迫解除"前置因素：

- ❌ 停发工资 / 工资延迟支付
- ❌ 擅自调离工位、不安排工作
- ❌ 当众羞辱、警告语言过激
- ❌ 关闭办公账号 / 门禁卡
- ❌ 不缴/少缴社保公积金
- ❌ 不开离职证明、不办社保转移

任一动作可能被认定为单位被迫解除，前述策略链全部失效，直接落入 N（§38 + §46(1)）或
2N（§87）路径。

## 四、地区敏感性

司法实践在以下地区存在系统性分歧。涉及这些地区时必须标注：

### 4.1 北京

- **京高法发〔2024〕534号** 第 5 条：调岗合理性按四要素审查（经营必要性、目的正当性、
  员工能胜任、劳动条件无不利变更）
- **京高法发〔2017〕142号** 第 34 条（仍有效）：二次固定期限到期单位直接发终止通知，
  构成违法终止 → 2N
- 整体倾向：在 §14 适用上严格于劳动者倾斜

### 4.2 上海

- 历史立场（坚持 16 年）：无固定期限合同的订立以双方合意为前提，单位有权拒签，
  单方终止仅支付 N
- 2024 年起市高院民事庭转向：开始支持劳动者的单方选择权
- 实务建议：上海地区不能再机械引用旧 N 说，需检索最新本市裁判口径

### 4.3 广东

- 整体倾向：用工自主权认定相对宽松，但对程序要件要求严格
- 经济性裁员 §41 适用门槛较高，实务中较少成功

### 4.4 江苏

- 整体倾向：对单位规章制度有效性的审查相对宽松
- 但对违纪解除的程序要件（民主程序、公示、员工签收）要求严格

### 4.5 输出要求

涉及地区分歧时：

- **必须列明本地立场 + 至少一个对比地区立场**
- 不得给出"全国统一结论"
- 同一案件在不同地区会有不同建议时，明确说明"如本案在 X 地区，建议 ...；
  如在 Y 地区，建议 ..."

## 五、stance 切换的攻防对称

stance 切换时，同一方法论的应用方向相反，但工具相同：

| 方法论 | employer 视角 | employee 视角 |
|---|---|---|
| 三档成本 | 最小化期望成本 | 最大化期望成本 |
| 时序意图 | 主动发起动作以掌握时序意图 | 主动发起 §14 诉求以剥夺单位的时序意图 |
| 证据链 | 固定有利于单位的事实 | 固定有利于劳动者的事实 |
| 红线动作 | 避免触发被迫解除 | 主动识别被迫解除 + 留证 |

启动 skill 时确认 stance 后，本方法论的所有工具自动适配。
