# 合同变更 Playbook（调岗 / 调薪 / 工作地点）

> **场景定位**：劳动合同存续期内单位提出工作岗位、工作内容、工作地点、薪酬、工时等条款变更。
> 区别于 dismissal-incompetence-playbook 的视角：本 playbook 不预设解除目的，**侧重变更动作本身的合法性 + 协商策略**。
>
> **stance 适用**：employer / employee 双视角。
> **判例支撑**：汇编 3.8 变更 25 案 + 5.4(B) 情势变更 13 案 + 5.2 被迫离职涉调岗 5 案，共约 40 案。
> 详见 `case-database/ch3-contract-formation-and-performance.md` § 3.8 + ch5 § 5.4(B) + § 5.2。

---

## 一、法理框架

### 1.1 三层规则

**第一层：§35 协商一致原则**

> 用人单位与劳动者协商一致，可以变更劳动合同约定的内容。变更劳动合同，应当采用书面形式。

这是基础规则——岗位、薪酬、工时、地点等劳动合同必备条款（§17）的变更，**应以双方协商一致 + 书面形式**为原则。

**第二层：用工自主权例外**

司法实践承认单位有限的单方调岗权，但需经"合理性"审查（京高法发〔2024〕534号 + case 3.8.5、3.8.6、3.8.7）。

**第三层：§40(3) 情势变更**

客观情况重大变化致合同无法履行 → 协商不成单方解除（详见 dismissal-incompetence-playbook）。

### 1.2 调岗合理性 —— 北京高院四要素 + 江苏六要素

**北京高院四要素**（京高法发〔2024〕534号 第 5 条 + case 3.8.5）：

1. 经营必要性
2. 目的正当性
3. 员工能胜任
4. 工资待遇等劳动条件无不利变更

**江苏 / 人社部六要素**（case 3.8.6 孙某诉某模具公司，人社部最高院联合发布）：

1. 是否基于生产经营需要
2. 是否属于对劳动合同约定的较大变更
3. 是否具有歧视性、侮辱性
4. 是否对劳动报酬和劳动条件产生较大影响
5. 劳动者能否胜任新岗位
6. 工作地点调远后是否有补偿措施

**江苏三正当**（case 3.8.7 姚某诉某公司）：

1. 调岗目的正当（具有经营上的必要性）
2. 调岗程序正当（先征求本人意愿 + 协商）
3. 调岗结果正当（前后岗位有关联 + 工时工资地点变动合理）

地区差异不大，本质均围绕"经营必要性 + 目的正当性 + 不利变更程度 + 补救措施"展开。

## 二、调岗类型分类

### 2.1 临时性短期指派 —— 不属于变更

case 3.8.3 周某诉某电子公司、case 5.2.1 赖某诉某电缆公司：

> 用人单位基于业务需要，临时性、短期性地指派劳动者至本单位其他部门支援工作，且工作内容不超出劳动者技能范围的，属于劳动合同履行过程中的正常调整，不属于劳动合同的变更。

case 4.5.12 王某诉某人力公司：疫情期间临时短期支援其他部门，属于合理行使用工管理权范畴。

**实务推论**：单位短期临时调整（如几天到几周、明确临时性）+ 不超出技能范围 → 劳动者应服从。

### 2.2 合同约定范围内的调整 —— 一般不构成变更

case 3.8.8 吴雪萍诉顺丰：

> 如果用人单位对工作岗位或者工作内容的调整没有超出劳动合同约定的范围，一般不构成劳动合同变更，不适用 §35。只要用人单位的单方调整行为没有违法或者明显不合理之处，劳动者就应当服从安排。
> 但是，如果劳动合同对岗位的约定过于宽泛或者未作约定，则不能据此认为用人单位可以随意调岗，而应当按照约定不明处理。

case 3.8.19 陈某诉某银行彭水支行：单位在合同约定范围内适度调岗 + 劳动者实际到新岗位履职较长时间 → 视为双方已就工作岗位进行有效变更。

### 2.3 实质性调岗 —— 必须合理性审查

case 3.8.9 王某诉某超市、case 3.8.10 陈桂昌诉大全：

> 工作内容、工作地点、劳动报酬等是劳动合同重要条款。如果用人单位在劳动合同或者规章制度中明确规定了调岗、降薪的情形，劳动者构成该条件时，用人单位可以进行相应的调整。如果用人单位没有规定或者规定不明确，应当提供充分证据证明调整的合理性。用人单位不能证明合理性的，应认定其单方调整行为无效。

### 2.4 关联企业之间的"调岗" —— 实质是劳动关系转移

case 3.8.4 华某诉中国移动、case 3.8.12 北京旺旺食品诉王某：

> 用人单位将业务划转至其他单位，劳动者随业务一并转移，但三方未就劳动关系转移达成协议 → 该情形与用人单位合并、分立并非同一情形，应认定劳动者的劳动关系仍在原用人单位。

实务陷阱：单位以"调岗"名义将劳动者关系转入关联企业，**未经协商一致且采用长期培训等方式架空原岗位**的，构成违法（case 3.8.12）。

### 2.5 职业病危害岗位的特殊规则

case 3.8.14 江阴挪赛夫诉顾某：

> 用人单位将劳动者从不具有职业病危害的岗位调整至具有职业病危害的岗位，应当履行充分告知义务，并与劳动者协商一致。该情形下因涉及对劳动者身体健康将产生不利影响，在未能协商一致的情形下，用人单位的单方调岗行为应认定为无效。

## 三、降薪规则

### 3.1 降薪 = 不利变更，不得默示推定

case 3.8.15 王某诉恩梯梯通信北分：

> 用人单位未与劳动者就降低工资标准达成书面协议，**即使劳动者在收到被降低的工资后未明确提出异议，也不能反推得出双方已经就降薪协商达成一致意见的结论**。

case 3.8.16 北京大风车诉魏某：单位通过办公系统送达调岗调薪通知 + 劳动者未答复 → 不能视为协商一致。

case 3.8.18 田某诉雕刻时光：单位主张协商一致变更，劳动者否认的 → 单位承担举证责任。

实务推论：**降薪几乎不能通过默示推定**，必须有书面协议或明确同意的证据。

### 3.2 调岗 + 不调薪的特殊处理

case 3.8.20 英飞凌诉朱某：

> 用人单位在承诺待遇不变的情形下将劳动者调整至与原岗位工作具有密切联系的新岗位，劳动者无正当理由拒绝调动，不服从工作安排，属于违纪行为。

这与续签场景中的方式三（无固定期限 + 调岗 + 薪酬不变）类似，但**单位需证明岗位"密切联系"——级别、专业、晋升通道实质衔接**。

### 3.3 工时变更

case 3.8.17 北京瑞友诉郑某：

> 用人单位以内部会议纪要的方式改变本单位实行的工时制度，未与劳动者协商一致的，不能发生变更劳动合同的效果。

## 四、典型成本路径

### 4.1 employer 视角

| 操作 | 法律构成 | 单位成本 |
|---|---|---|
| 调岗合法（四要素全过）+ 员工接受 | 合同变更生效 | 0 |
| 调岗合法 + 员工拒绝到新岗位（旷工）| §39(2) 严重违纪解除 | 0 |
| 调岗不合法 + 员工 §38(1) 被迫解除 | §46(1) | N |
| 调岗不合法 + 单位强行解除 | §87 | 2N |
| 单方降薪未协商一致 | 变更无效 | 补差额 + 员工可主张 §38 被迫解除（N）|
| 关联企业"调岗"未协商一致 | 变更无效 / 违法解除 | 视后续动作（N 或 2N）|
| 职业病危害调岗未协商一致 | 变更无效 | 同上 |

### 4.2 employee 视角

调岗不合法时的选择权（关键）：

| 路径 | 触发条件 | 单位成本（员工收益）|
|---|---|---|
| **路径 1**：留岗位待命 + 单位强行解除 → 诉违法解除 | 单位执意按新岗位管理 | 2N（员工选）|
| **路径 2**：§38(1) 被迫解除 + 主张 §46(1) | 调岗实质改变劳动条件 | N（员工选）|
| **路径 3**：拒绝调岗 + 继续履职 + 要求按原合同 | 调岗未生效 | 维持原状 |
| **路径 4**：要求恢复劳动关系（如已被解除）| 选择权在员工 | 恢复 + 期间工资 |

员工选择路径 1 vs 2 的考量见 dismissal-misconduct-playbook + forced-resignation-playbook。

## 五、双视角策略

### 5.1 employer 操作清单

**调岗启动前**：

1. **审查合同条款**——岗位条款是否明确？是否有"调岗权"条款？
2. **形成业务依据**——独立的部门调整决议 / 组织架构图变更（必须早于针对个体的动作形成）
3. **审查特殊保护期**——孕产期 / 医疗期 / 工伤期 / 职业病危害岗位（特殊规则）
4. **自检四要素 / 六要素**：经营必要性 / 目的正当性 / 能胜任 / 不利变更 / 补救措施

**调岗实施时**：

1. **书面通知**：《岗位调整通知书》+ 业务依据说明
2. **协商先行**：先征求本人意愿，给予合理答复期
3. **过渡期安排**（必要时）：保留原薪资若干月、转岗培训、明确汇报关系
4. **沟通记录**：所有沟通即时邮件确认

**调岗后续**：

1. 员工接受 → 签订《劳动合同变更协议》（书面 §35 要件）
2. 员工拒绝且新岗位经得起合理性审查 → 视情况依规章制度处理（不超过 §39 范围）
3. 员工拒绝且新岗位不能完全自证合理 → 评估调整方案或撤回

**红线动作**：

- ❌ 单方降薪（即使员工未异议）→ 仍可被认定变更未生效
- ❌ 以"调岗"名义实施关联企业间劳动关系转移
- ❌ 未告知职业病危害的岗位调整
- ❌ "服从公司安排"约定下的跨省调动（case 5.4.17）
- ❌ "江苏"等大范围约定下的不合理跨城调动（case 5.4.16）

### 5.2 employee 操作清单

**收到调岗通知时**：

1. **不要立刻不去上班**——构成旷工即便调岗最终被认定违法，对解除性质判定也不利
2. **继续在原岗位履职 + 书面反对调岗**（同时要求说明合理性依据）
3. **保留沟通证据**——调岗通知、邮件、微信、说明理由的回复

**单位强行推进新岗位时**：

1. 评估调岗是否合理（按四要素 / 六要素）
2. 选择维权路径：
   - 攻势（想走人）：依 §38(1) 被迫解除 → 主张 N
   - 守势（想留人或筹码最大化）：留原岗位 → 等单位解除 → 主张 2N + 恢复劳动关系（依 §48）

**降薪场景**：

1. 收到降薪工资后立即书面提出异议（避免默示同意争议）
2. 主张按原工资标准补差额
3. 严重时考虑 §38(2) 被迫解除（拖欠劳动报酬路径）

## 六、企业搬迁 / 情势变更专题

详见 dismissal-incompetence-playbook §三。本 playbook 仅补充几个 employer 的实操要点：

### 6.1 搬迁前的"四要素自检"

最高法院公报 2020 年第 9 期（case 5.4.12）的判断框架：

1. 搬迁距离（地理距离 + 通勤时间增加）
2. 单位补救措施（班车 / 交通补贴 / 调整上下班时间）
3. 对劳动者生活的实质影响
4. 是否足以致合同无法履行

### 6.2 实操要点

- **提供补救措施**：班车、交通补贴、灵活上下班、过渡期住宿补贴
- **协商优先**：与劳动者协商变更工作地点条款（书面）
- **不愿接受搬迁的员工**：依 §40(3) 解除 N+1（前提：协商不成 + 补救已尽）
- **整体搬迁案件优先适用 §40(3)**，避免单个员工调岗争议

### 6.3 江苏地区裁判倾向

汇编 case 5.4.10 周红梅诉常熟白雪、case 5.4.11 魏丽娜诉楼氏电子均强调：

> 用人单位整体搬迁导致劳动者上下班路途时间延长、生活不便的，是否构成情势变更，应当结合企业搬迁的距离、企业搬迁有无提供班车或交通补贴等便利措施、企业有无调整上下班时间等因素综合判断。

江苏地区对 §40(3) 适用相对宽松，但单位必须先做补救。

## 七、关键证据策略

### 7.1 employer 证据清单

| 文件 | 证明目的 |
|---|---|
| 部门调整决议 / 组织架构图变更 / 业务调整方案 | 经营必要性 + 业务依据独立 |
| 新岗位职责书 | 员工能胜任 + 与原岗位关联 |
| 调岗通知书 + 业务依据说明 | 程序合法 |
| 协商记录 / 沟通邮件 / 会议纪要 | 协商先行 |
| 补救措施承诺（班车、补贴、过渡期）| 单位已尽义务 |
| 员工签收或书面反对 | 协商结果 |

### 7.2 employee 证据清单

| 文件 | 证明目的 |
|---|---|
| 调岗通知书原件 | 单位单方变更证据 |
| 原岗位的级别 / 薪酬 / 职责证据 | 比较新旧岗位差异 |
| 单位的业务依据材料（如已披露）| 评估目的正当性 |
| 自己继续在原岗位履职的证据 | 拒绝调岗 ≠ 旷工 |
| 与单位沟通的全部记录 | 程序违法证据 |
| 通勤距离 / 时间证据（地点变更场景）| 不利变更程度 |
| 家庭情况证据（如适用）| 综合影响 |

## 八、与其他 playbook 的衔接

- **下游**：调岗后劳动者不胜任 → 转入 dismissal-incompetence-playbook（§40(2) 路径）
- **下游**：调岗不合理 → 劳动者走 forced-resignation-playbook（§38 被迫离职）
- **上游**：续签场景中的方式五（调岗 + 加薪）→ 见 contract-renewal-playbook
- **关联**：调岗导致"工作地点变更"达到情势变更程度 → 触发 §40(3)
- **替代**：调岗博弈成本过高时 → 转入 severance-agreement-playbook 走 N+1~3 月协商解除
