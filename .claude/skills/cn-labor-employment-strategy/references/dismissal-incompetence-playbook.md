# 无过失性辞退 Playbook（§40、§41）

> **场景定位**：用人单位以"不能胜任工作"（§40(2)）、"客观情况发生重大变化"（§40(3)）、"经济性裁员"（§41）为由解除劳动合同。
> 三种路径均需 **N + 1 月**经济补偿（§40 + 代通知金），但司法门槛差异显著。
>
> **stance 适用**：employer / employee 双视角。
> **判例支撑**：汇编 5.4(A) 不胜任 8 案 + 5.4(B) 情势变更 13 案 + 5.4(C) 经济性裁员 1 案。
> 详见 `case-database/ch5-termination-and-exit.md` § 5.4。

---

## 一、三条路径速查

| 路径 | 法律依据 | 适用情形 | 核心难点 | 经济补偿 |
|---|---|---|---|---|
| **不胜任** | §40(2) | 劳动者经培训或调岗后仍不胜任 | "不胜任"客观认定 + 培训/调岗实际履行 | N + 1 |
| **情势变更** | §40(3) | 客观情况重大变化致合同无法履行 | "客观情况"严格审查 | N + 1 |
| **经济性裁员** | §41 | 四种法定情形 + 20 人/10% 门槛 | 实体 + 程序双重要件 | N |

三条路径都触发 §42 禁止解除事由（孕期/医疗期/工伤期/15+5 老员工等）。

---

## 二、§40(2) 不胜任路径

### 2.1 核心规则：末位淘汰 ≠ 不胜任

**最高人民法院指导案例第 18 号**（case 5.4.2 中兴通讯诉王鹏）：

> 劳动者在用人单位的等级考核中居于末位等次，不等同于"不能胜任工作"，不符合 §40 规定的解除条件，用人单位不能据此单方解除劳动合同。

后续司法一贯坚持（case 5.4.3、5.4.4、5.4.5、5.4.6、5.4.7、5.4.8）：

- 不胜任 = 不能按要求完成劳动合同约定的任务或同工种同岗位人员的工作量
- 末位淘汰 = 相对评价（必然有人末位）
- 二者**不具有必然联系**
- 单位实施末位淘汰必须先经过"能否胜任"的实质审查后才可调岗（case 5.4.7）

实务结论：**任何"末位淘汰"条款本身无效**（case 5.4.8 明确）；即便规章制度有此条款也不能作为解除依据。

### 2.2 §40(2) 三段式流程

```
第一段：初始考核认定"不胜任"
  ↓
  必备证据：岗位职责书 + 量化考核标准 + 考核结果
  必备程序：员工签收岗位职责 + 公示考核办法 + 考核结果送达员工
  ↓
第二段：培训或调岗（二选一）
  ↓
  必备证据：培训记录 / 调岗通知书 + 新岗位职责描述
  ↓
第三段：二次考核仍"不胜任"
  ↓
  二次考核间隔合理（一般 1~3 个月）
  ↓
满足条件 → 提前 30 日书面通知 / 额外支付 1 个月工资 → 解除（§40(2)）
  ↓
法定补偿：N + 1
```

### 2.3 典型成本路径

| 状态 | 单位成本 |
|---|---|
| 完整三段式 + 证据扎实 + N+1 补偿 | **N + 1** |
| 末位淘汰直接解除 | **2N** |
| 跳过培训/调岗直接解除 | **2N** |
| 考核标准不明确 / 未公示 | **2N** |
| 二次考核间隔过短 / 仅 1 次考核 | **2N** |
| 调岗本身不合理（参 contract-modification-playbook）| **2N** |
| 在 §42 保护期内启动 §40 | **2N**（禁止解除）|

## 三、§40(3) 情势变更路径

### 3.1 核心判例：什么算"客观情况重大变化"

**支持情势变更的情形**：

| 情形 | 判例 | 关键要件 |
|---|---|---|
| 公司分立 + 部门搬出 | case 5.4.9 | 涉及法人主体变更 |
| 整体搬迁（路途明显延长）| case 5.4.10 | 搬迁距离 + 影响生活 + 单位无补救 |
| 政策性外迁（核心区 → 远郊/外省）| case 5.4.15 | 政策强制 + 远距离 |
| 政府疫情管控措施 | case 4.5 系列 | 政府强制力 + 实际履行不能 |

**不支持情势变更的情形**（极重要 —— employer 的红线）：

| 情形 | 判例 | 不支持原因 |
|---|---|---|
| 内部组织架构调整 | case 5.4.18 戴尔 | 企业可控范围 |
| 减员增效 / 机构改革 | case 5.4.19 | 自主经营行为，非客观情况 |
| 业务外包 | case 5.4.20 周某 | 市场选择，非客观情况 |
| 整体搬迁 + 单位已采补救措施 | case 5.4.11、5.4.12 | 不足以致合同无法履行 |
| 工作地点约定"江苏"等宽泛范围 + 调动不合理 | case 5.4.16 | 约定不明，调动须有合理性 |
| "服从公司安排"约定 + 跨省调动 | case 5.4.17 | 约定不能授予无限调动权 |

### 3.2 整体搬迁 / 工作地点变更 —— 四要素综合判断

最高人民法院公报 2020 年第 9 期（case 5.4.12 吴继威诉搏峰电动）确立的判断框架：

1. **搬迁距离**（地理距离 + 通勤时间增加）
2. **单位补救措施**（班车 / 交通补贴 / 调整上下班时间）
3. **对劳动者生活的实质影响**（家庭、子女、健康等）
4. **是否足以致合同无法履行**（综合上述三项）

**实务推论**：单位整体搬迁 + 充分补救（班车 + 补贴 + 弹性工时）→ 劳动者不能拒绝劳动；单位整体搬迁 + 无补救 → 构成 §40(3) 情势变更 → 协商不成可解除（N+1）。

### 3.3 §40(3) 操作流程

```
第一步：固定客观情况变化的证据
  ↓
  搬迁决议 / 政府文件 / 行业政策 / 不可抗力证明
  ↓
第二步：与劳动者协商变更劳动合同
  ↓
  书面变更要约 + 协商记录 + 劳动者反应留证
  补救措施同步提出（班车、补贴、过渡期）
  ↓
第三步：协商不成 → 提前 30 日通知 / 额外 1 月工资 → 解除（§40(3)）
  ↓
法定补偿：N + 1
```

## 四、§41 经济性裁员路径

### 4.1 双重要件

**实体要件四选一**：

1. 依照企业破产法规定进行重整
2. 生产经营发生严重困难
3. 企业转产 / 重大技术革新 / 经营方式调整，经变更劳动合同后，仍需裁减人员
4. 其他因劳动合同订立时所依据的客观经济情况发生重大变化，致使劳动合同无法履行

**数量门槛**：裁减 20 人以上 **或** 不足 20 人但占总人数 10% 以上。

**程序要件四步**：

1. 提前 30 日向工会或全体职工说明情况
2. 听取工会或职工意见
3. 裁减人员方案向劳动行政部门**报告**（非审批）
4. 执行裁减

**优先留用顺序**（§41(2)）：

1. 与单位订立较长期限的固定期限合同的
2. 与单位订立无固定期限合同的
3. 家庭无其他就业人员，有需要扶养的老人或未成年人的

### 4.2 §41 的司法门槛 —— 极高

汇编 5.4(C) 仅 1 案（case 5.4.22 聂波诉施耐德电气），裁判要旨：

> 劳动者与用人单位就经济性裁员的合法性发生争议，应由用人单位对其实施裁员符合法定实体性要件和履行法定程序性义务承担举证证明责任。

实务现象：京沪粤等一线城市单位**很少能走通 §41**。原因：
- 实体证据要求高（财务报表、董事会决议、行政机关备案）
- 程序要件严格（任一缺失即 2N）
- 法院倾向严格审查"严重困难"标准

### 4.3 实务建议

如必须走 §41：

- 准备完整财务证据（亏损报表、银行流水、董事会决议）
- 与劳动行政部门沟通**报告**手续（非审批，但争议时是证据）
- 严格执行优先留用顺序（违反即 2N）
- 工会沟通完整留痕

替代路径：**多数情况下，N + 1 月协商解除（§36 + §46）比 §41 更稳**——以裁员预算的钱用于个体协商，避免诉讼风险。

## 五、典型成本路径横向对比

| 路径 | 最佳情况 | 司法实践一般 | 最差情况 | 司法审查严格度 |
|---|---|---|---|---|
| §40(2) 不胜任 | N+1 | N+1（流程齐备）| 2N | 中（关键看末位淘汰还是真不胜任）|
| §40(3) 情势变更 | N+1 | N+1（限于搬迁、政策性等）| 2N | 高（内部调整几乎不支持）|
| §41 经济性裁员 | N | N（极少数案件走通）| 2N | 极高（实体+程序双严）|
| 协商解除（替代）| N+0.5~1 | N+1~2 | N+2~3 | 低（合意为准）|

实务建议：能用协商解除避免 §40 / §41 走司法审查的，优先协商解除。

## 六、双视角策略

### 6.1 employer 视角

**核心选择树**：

```
启动想法：减员 / 优化 / 缩减成本
        │
        ├─ 个别员工 + 绩效问题 → §40(2) PIP 流程（完整三段）
        │                       └─ 或转协商解除 N+1~2
        │
        ├─ 整体搬迁 / 政策外迁 → §40(3) 客观情况重大变化
        │                       └─ 必须提供补救措施 + 协商
        │
        ├─ 业务调整 / 组织优化 → ❌ 不能援引 §40(3)（内部可控）
        │                       └─ 走协商解除 N+1~3
        │
        └─ 大规模裁员（20 人以上）→ §41 经济性裁员（高门槛）
                                  └─ 或拆解为协商解除批次
```

**红线动作**：

- ❌ 任何"末位淘汰"直接解除 → 必败
- ❌ 跳过培训/调岗的"不胜任"解除 → 必败
- ❌ 内部组织调整冒充"客观情况重大变化" → 必败
- ❌ 业务外包冒充情势变更 → 必败（case 5.4.20）
- ❌ §42 保护期内启动 §40 / §41 → 必败

### 6.2 employee 视角

**被 §40(2) 解除时的攻击点**：

1. **质疑"不胜任"认定**：考核标准未事先公示 / 标准模糊 / 实质是末位淘汰
2. **质疑培训/调岗实际履行**：培训记录 / 调岗通知是否真实发生
3. **质疑二次考核合理性**：间隔过短 / 标准变更 / 主观打分
4. **质疑调岗合理性**（如走调岗路径）：是否符合北京四要素（参 contract-modification-playbook）

**被 §40(3) 解除时的攻击点**：

1. **质疑"客观情况"性质**：是否实质是内部调整（case 5.4.18、5.4.19）？
2. **质疑"合同无法履行"**：单位是否已采取补救措施？补救是否充分？
3. **质疑协商程序**：是否真实进行了变更协商？
4. **工作地点约定不明**：约定为"江苏"等大范围时，主张以实际履行地为准（case 5.4.16）

**被 §41 解除时的攻击点**（极高胜诉率）：

1. **实体证据不足**：要求单位出示财务报表、董事会决议
2. **程序违法**：未告知工会 / 未向劳动部门报告 / 未给优先留用机会
3. **优先留用违反**：你符合优先留用情形但被裁

## 七、关键证据策略

### 7.1 employer 的证据清单

**§40(2) 不胜任**：

- 岗位职责书（员工签收）
- 绩效考核办法（民主程序 + 公示）
- 每轮考核结果（员工签字 / 拒签留证）
- 培训记录 / 调岗通知书 + 新岗位描述
- 解除通知书 + 工会告知函 + 送达证据

**§40(3) 情势变更**：

- 客观情况变化的客观证据（搬迁决议、政府文件、政策文本）
- 变更要约 + 协商记录
- 补救措施承诺（班车、补贴、过渡期）
- 解除通知书 + 工会告知函 + 送达证据

**§41 经济性裁员**：

- 财务报表（连续亏损证据）
- 董事会决议 / 股东会决议
- 工会沟通记录 / 职代会决议
- 劳动行政部门报告回执
- 优先留用名单与依据
- 裁员方案 + 经济补偿支付凭证

## 八、与其他 playbook 的衔接

- **失败后**：§40 / §41 被认定违法 → 转入 severance-agreement-playbook 走加码协商解除
- **替代路径**：发现 §40(3) 不能成立 → 转入 contract-modification-playbook 走调岗博弈
- **关联场景**：调岗成功后劳动者仍不胜任 → 回到 §40(2) 路径
- **特殊保护期**：触发 §42 时 §40 / §41 均禁用，唯一通道是 §39 严重违纪解除（dismissal-misconduct-playbook）或协商解除
