# 离职协议与经济补偿 Playbook

> **场景定位**：劳动合同解除 / 终止后的两个核心问题——
> （1）经济补偿数额计算（工作年限、月工资基数）
> （2）离职协议效力 + 恢复劳动关系选择权
>
> **stance 适用**：employer / employee 双视角。
> **判例支撑**：汇编 5.7(A) 工作年限月工资 10 案 + 5.7(B) 恢复劳动关系 9 案 + 5.8 离职协议 13 案，共约 32 案。
> 详见 `case-database/ch5-termination-and-exit.md` § 5.7 + § 5.8。

---

## 一、经济补偿计算（§47）

### 1.1 基本规则

```
N = W × Y

W = 劳动者解除前 12 个月平均工资（含所有劳动报酬）
Y = 工作年限
    · 满 6 个月不满 1 年的，按 1 年计算
    · 不满 6 个月的，按 0.5 个月计算

封顶规则（§47(2)）：
    W 高于当地上年度职工月平均工资 3 倍的，
    · W 封顶为社平工资 3 倍
    · Y 封顶为 12 年
    · 二者同时适用（仅适用于高薪员工）

违法解除赔偿金：2N（§87）
```

### 1.2 工作年限连续计算（非因本人原因转移）

**最高人民法院公报 2016 年第 12 期**（case 5.7.1 包利英诉上海申美饮料食品）——劳动法领域的标杆判例：

> 劳动者仍在原工作场所、工作岗位工作，劳动合同主体由原用人单位变更为新用人单位的，应当认定属于"劳动者非因本人原因从原用人单位被安排到新用人单位工作"的情形，工作年限应当连续计算。

**应用范围扩展**：

| 情形 | 是否连续计算 | 判例 |
|---|---|---|
| 关联企业间变更签约主体 | 是 | case 5.7.3、5.7.4、5.7.9 |
| 劳务派遣 → 直接用工 | 是（即便辞职转岗）| case 5.7.8 |
| 改制过程中的转岗 | 是 | case 5.7.2 |
| 违法解除赔偿金（2N）的年限 | 同样连续计算 | case 5.7.5、5.7.7 |
| 劳动合同法施行前后跨期 | 自实际入职日起算（不分段）| case 5.7.6 |

**例外**：劳动者真实自愿主动辞职后再入职新单位的，**不能连续计算**。但需注意 case 5.7.8：派遣转直接用工的工作状态连续 + 岗位内容不变 → **推定**非因本人原因，单位反驳举证。

### 1.3 月工资基数（W）的特殊问题

**待岗生活费不计入基数**（case 5.7.10 腾翔公司诉潘某）：

> 在计算用人单位应当向劳动者支付的经济补偿数额时，如果劳动者在离职前 12 个月内存在因用人单位停产歇业而导致的待岗状态，因待岗期间的生活费并非劳动者享有的正常工资收入，故不应作为经济补偿月工资的计算基数。

实务推论：W 计算时应**剔除**待岗 / 停工 / 病假 / 三期等非正常工作期间的非正常工资，按正常工作月份的平均工资计算。

### 1.4 N+1 的代通知金

适用情形：依 §40 解除（不胜任、客观情况重大变化、医疗期满不能从事工作）：

- 提前 30 日书面通知 → N
- **或**额外支付 1 个月工资（代通知金）→ N + 1

仅 §40 适用；§39（违纪）、§41（裁员）、§44（终止）均不适用。

### 1.5 N+X 的协商加码

§36 协商解除时市场对价区间（北京 / 上海 / 长三角 / 珠三角）：

| 员工配合度 | 对价区间 |
|---|---|
| 高（已找到新工作）| N |
| 中（标准加码）| N + 0.5~1 |
| 中-高（多数成交点）| N + 1.5~2.5 |
| 高（特殊保护期 / 高争议风险）| N + 3~6 |

## 二、恢复劳动关系选择权（§48）

### 2.1 法律基础

《劳动合同法》§48：

> 用人单位违反本法规定解除或者终止劳动合同，劳动者要求继续履行劳动合同的，用人单位应当继续履行；劳动者不要求继续履行劳动合同或者劳动合同已经不能继续履行的，用人单位应当依照本法第八十七条规定支付赔偿金。

劳动者享有"二选一"形成权：

- **路径 A**：恢复劳动关系 + 期间工资（直到恢复）
- **路径 B**：违法解除赔偿金 2N

### 2.2 司法对恢复劳动关系的限制审查

汇编反映的核心规则：法院**不会机械地"劳动者要恢复就恢复"**，而是综合判断"是否能继续履行"。

**支持恢复履行的情形**：

case 5.7.12 唐某诉某齿轮集团：单位违反 §43 通知工会程序，被判决撤销解除 + 恢复履行的，仍属合法路径。

**不支持恢复履行的情形**：

| 情形 | 判例 |
|---|---|
| 双方已完全丧失互信 + 对继续履行方式无法达成合意 | case 5.7.11 |
| 用人单位已聘用他人接替高管岗位 + 无法重新安排 | case 5.7.16 联联新产业 |
| 高度信任关系的岗位（人事、财务、法务、高管、信托）| case 5.7.14、5.7.17 中信信托 |
| 劳动者已重新就业并入职他单位 | case 5.7.18（除单位同意外）|
| 试用期违法解除 + 双方未建立互信 | case 5.7.19 |

### 2.3 实务释明规则（江苏）

case 5.7.11（江苏立场）：

> 法院审理该类案件时，不仅要考虑劳动者的选择权，还要考虑决定劳动合同是否能够真正继续履行的主客观因素。如果劳动者与用人单位已经完全丧失互信，对继续履行的方式无法达成合意，则应认定劳动合同已经不能继续履行。法院应当向劳动者进行充分释明，引导其变更请求为主张赔偿金。劳动者坚持主张恢复劳动关系的，不予支持，告知另行主张赔偿金。

实务推论：劳动者主张恢复履行的，需要证据支持"互信基础仍在"或"岗位仍可履行"——单纯高呼"我要回去"不一定有效。

### 2.4 employee 视角的选择策略

| 因素 | 偏向恢复履行（A）| 偏向 2N（B）|
|---|---|---|
| 工龄 | 短（< 5 年）| 长（≥ 10 年，2N 显著大）|
| 年龄 | 中青年（再就业容易）| 临近退休（恢复后续延长缴费）|
| 岗位性质 | 高互信岗位（已被替代）| 普通岗位 |
| 单位态度 | 强硬拒绝 | 妥协意愿 |
| 司法地区 | 北京 / 江苏（释明严）| 上海 / 广东（恢复更难）|
| 已重新就业 | 不可（除非单位同意）| 可 |
| 仲裁周期 | 接受 1~2 年等待 | 速战速决 |

**典型计算**：

- 工龄 5 年、月工资 1.5 万：N = 7.5 万，2N = 15 万
- 选恢复：期间工资 × 18 个月（仲裁周期）= 27 万 + 后续工资（但有失败风险）
- 选 2N：确定性 15 万

工龄越长，2N 越优；工龄越短，期间工资恢复路径越优（但需考虑岗位是否还能回得去）。

## 三、离职协议效力（§36 协商解除产物）

### 3.1 离职协议的基本效力

case 5.8.4 戴允锋诉北京晟邦：

> 用人单位与劳动者就解除或者终止劳动合同及相关权利义务的清理达成协议，该协议不存在法定无效、可撤销事由的，应认定有效。

case 5.8.5 北京天越门窗诉张吉志：

> 劳动争议发生后，经双方协商，或者通过工会、第三方共同参与协商后，达成和解协议，且协议内容系真实意思表示，不违反法律强制性规定，不损害他人合法权益的，对当事人具有约束力。

**实务原则**：离职协议有效性是司法默认立场，**主张无效的一方承担举证责任**。

### 3.2 离职协议无效 / 可撤销情形

| 情形 | 判例 | 法律构成 |
|---|---|---|
| **签字者无权代理**（公章被盗用 / 非控股股东代签）| case 5.8.1 某光伏公司、case 5.8.6 欧文斯伊利诺斯 | 越权代理 + "看人不看章" |
| **以盖章但无负责人签字的协议主张权利** | case 5.8.6 | 真实性举证不足 |
| **附条件不可成就**（明显不可成就 / 期限不能确定）| case 5.8.9 高某诉甲骨文 | 所附条件无效 |
| **变相迫使签字放弃权利**（利用工资 / 离职证明 / 档案转移优势地位）| case 5.8.3 肖某诉某科技公司 | 弃权行为无效 |
| **怀孕女职工签解除协议 + 不知怀孕** | case 5.5.15、5.8.7、5.8.8 | **不构成重大误解**（多数判例不予撤销）|

### 3.3 概括了结条款（"漏项"问题）

case 5.8.4 戴允锋诉北京晟邦：

> 劳动者主张协议约定项目以外的"漏项"权利的，应审查协议中有无劳动者放弃其他实体性权利的兜底条款，并在此基础上作出相应处理。

实务推论：

- 协议**有**概括了结条款（如"双方再无其他争议"）→ 漏项主张通常不支持
- 协议**无**概括了结条款 → 漏项主张可以另行起诉

### 3.4 附条件离职协议

case 5.8.10 中安消公司诉郭某：

> 用人单位与劳动者就解除劳动合同事项达成协议，明确约定在劳动者完成后续事务的情况下才支付经济补偿的条件，该约定不存在无效、可撤销情形的，应认定有效。劳动者在未完成相关事务的情形下，无权主张协议约定的经济补偿。

实务推论：附"完成交接后支付"条件的协议**有效**，劳动者需先履行义务。

### 3.5 离职协议的违约保留

case 5.8.2 王某诉某航空公司：

> 劳动者因用人单位拖欠劳动报酬而被迫离职时，与用人单位就工资清偿问题达成协议，承诺放弃包括经济补偿在内的其他权利，但在签字时备注了如果用人单位违约则保留追究责任权利的条件，用人单位接受协议未提出异议，应认定该备注内容属于离职协议的组成部分，属于违约条款。

实务推论：劳动者在签字时可备注"如单位违约，保留追究全部权利"，单位接受签字即生效。

## 四、双视角策略

### 4.1 employer 视角

**离职协议拟定要点**：

1. **概括了结条款（关键）**：

   > "双方确认，本协议项下事项已涵盖双方因劳动关系产生的全部权利义务。除本协议明确约定的事项外，双方再无其他任何争议或权利主张（包括但不限于工资、加班费、经济补偿、社保、公积金、年假、奖金、股权激励、知识产权等）。"

2. **代理权清晰**：协议必须由法定代表人或经授权的代理人签字盖章
3. **附条件付款**：可约定"完成工作交接后支付经济补偿"
4. **避免变相弃权陷阱**：不要用扣留离职证明 / 阻碍社保转移等手段强迫签字
5. **特殊保护期员工加码协商**：孕产期 / 医疗期员工的对价应在 N + 3~6 月起谈

**违法解除后的紧急处理**：

1. 评估恢复履行 vs 2N 的成本 + 单位接受程度
2. 主动与劳动者协商：以 2N + 加码（如 2N + 1~2 月）换取放弃恢复履行
3. 高互信岗位（高管、人事、财务、法务）：尽快聘用替代人员（强化"不能恢复"的事实基础）

### 4.2 employee 视角

**签离职协议前的核查清单**：

1. **未结算项目逐项列明**：工资、加班费、年休假、绩效奖金、股权激励、报销款、社保差额、商业保险
2. **拒绝接受"概括了结"**或仅在所有项目都已结算时接受
3. **附违约保留条款**：单位违约时保留追究全部权利的备注
4. **特殊保护期请求加码**：孕产 / 医疗 / 工伤期员工，对价应显著高于普通员工
5. **签字前 24~48 小时冷静期**：不要在情绪化时签字

**违法解除后的选择策略**：

1. **第一步：计算两种路径的预期收益**
   - 路径 A（恢复 + 期间工资）：期间工资 = W × 仲裁周期（一般 12~18 个月）+ 后续工资 + 社保福利
   - 路径 B（2N）：确定性现金
2. **第二步：评估单位接受度**
   - 单位态度强硬 + 高互信岗位被替代 → 选 B（2N）
   - 单位有协商意愿 + 普通岗位 → 选 A 当筹码再谈 N + 2~3 月协商
3. **第三步：仲裁请求权写法**
   - 主请求：恢复履行（或 2N，二选一）
   - 备选请求：另一方案
   - 法官释明时可灵活调整

### 4.3 涉及怀孕的特殊判例

case 5.5.15 / 5.8.7 / 5.8.8 三个案例确立的规则：

> 怀孕女职工与用人单位协商解除劳动合同，女职工对自己是否怀孕这一事实的认识错误，并不代表对协商解除劳动合同行为性质的认识错误，不属于法律规定的重大误解，故不能以此为由撤销解除协议。

实务推论：怀孕女职工**不要在确认自己未怀孕之前签离职协议**——签了之后才发现怀孕，多数司法不支持撤销。如有怀疑应先做检查后再决定。

## 五、关键证据策略

### 5.1 经济补偿计算

**employer 证据清单**：

- 入职登记表 / 劳动合同（确定起算日）
- 工资银行流水（12 个月）
- 工资构成证明（基本工资、绩效、奖金、津贴）
- 待岗 / 病假 / 三期等非正常状态证明（可剔除非正常期间）
- 社平工资查询结果（高薪员工封顶适用）

**employee 证据清单**：

- 完整工资流水（包含奖金、年终奖、加班费）
- 原始入职证明 / 关联企业转移文件（主张工龄连续计算时）
- 派遣转直接用工的证据（如适用）
- 拒绝单位以待岗压低基数的证据

### 5.2 恢复劳动关系

**employee 证据清单**：

- 与同事的互动证据（互信基础仍在）
- 自己未重新就业的证据（如适用）
- 单位未聘用替代人员的证据（如适用）
- 原岗位仍可履行的证据

**employer 证据清单**（反对恢复履行）：

- 已聘用替代人员的劳动合同 / 工资单
- 双方已彻底失去互信的事实（如冲突、举报、媒体曝光）
- 劳动者已重新就业的证据
- 岗位性质要求高度互信的证据

## 六、与其他 playbook 的衔接

- **上游**：违纪解除被认定违法（dismissal-misconduct-playbook）→ 进入本 playbook §二选择路径
- **上游**：不胜任解除被认定违法（dismissal-incompetence-playbook）→ 同上
- **上游**：调岗不合理引发的违法解除（contract-modification-playbook）→ 同上
- **上游**：被迫离职 §38 成立（forced-resignation-playbook）→ 进入本 playbook §一计算 N
- **平行**：续签场景的协商解除（contract-renewal-playbook 方式一）→ 直接使用本 playbook §三协议条款
- **下游**：协议签订后的争议（漏项、违约、效力）→ 仲裁主张协议无效或履行
