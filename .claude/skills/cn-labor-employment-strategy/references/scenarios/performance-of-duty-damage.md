# 履职过错损害赔偿

> 劳动者在履职过程中给用人单位造成损失的赔偿责任。
> 判例支撑：汇编 3.9 履职损害赔偿 12 案。详见 `case-database/ch3-contract-formation-and-performance.md` § 3.9。

## 一、法理框架

### 1.1 基本规则

劳动者在工作过程中给用人单位造成损失的，单位可按合同约定或规章制度请求赔偿，但需考虑：

1. 劳动者过错程度（故意 / 重大过失 / 一般过失）
2. 工作风险状况
3. 工资收入水平
4. 用人单位的管理责任

### 1.2 "故意 / 重大过失"门槛

case 3.9.1 嘉诺公司诉朱贤斌、case 3.9.3 履职过错损害赔偿：

> 劳动者在履行职务过程中因过错致用人单位损失发生的纠纷，应按劳动争议处理。劳动者对用人单位的损失存在**故意或者重大过失**的，应当承担赔偿责任。

**一般过失** → 不承担赔偿责任（属于经营风险范畴）

### 1.3 经营风险不得转嫁

case 3.9.1：

> 用人单位通过劳动合同、规章制度的方式将经营风险**全部转嫁**给劳动者的，相关条款无效，但劳动者的责任并不能全部免除。

case 4.2.21 李某诉登跃公司：单位以规章制度或离职协议将回款风险转嫁给劳动者的约定**无效**。

## 二、赔偿比例认定因素

case 3.9.3、3.9.4、3.9.5 综合：

1. 双方之间的约定
2. 劳动者过错程度
3. 行为与损失的因果关系
4. 具体损失情况
5. 劳动者收入水平
6. 用人单位事前培训情况
7. 用人单位事后减损措施
8. 用人单位管理缺失
9. 损害是否可通过其他方式补救

实务推论：法院综合考量上述因素**酌定**赔偿比例，通常不会判全额赔偿。

## 三、对第三人侵权后单位追偿

case 3.9.2 南通恒天船舶诉周建：

> 劳动者在工作期间因故意或者重大过失致第三人损害，用人单位对第三人承担赔偿责任后，**有权向劳动者追偿**。在确定用人单位的追偿比例时，可以根据劳动者在侵权行为中的过错程度酌情确定。

## 四、典型成本路径

### employer

| 情形 | 收益 |
|---|---|
| 劳动者故意 / 重大过失 + 因果关系清楚 + 损失证据扎实 + 单位已尽培训 / 管理义务 | 可酌情追偿（通常 30%~70%）|
| 单位将经营风险全部转嫁劳动者 | 无效 |
| 劳动者一般过失 | 不承担赔偿 |
| 单位本身存在管理缺失 | 减轻劳动者责任 |

### employee

| 操作 | 收益 |
|---|---|
| 主张一般过失（非故意 / 非重大过失）| 不承担赔偿 |
| 主张单位管理缺失（未培训 / 监督不力）| 减轻责任 |
| 主张经营风险条款无效 | 抗辩整体赔偿 |
| 主张损失数额不实 / 因果关系不充分 | 减少赔偿数额 |

## 五、操作要点

### employer

1. **劳动合同 / 规章制度的赔偿条款合理化**：不全额转嫁经营风险
2. **保留培训记录 + 操作规程公示**：证明已尽管理义务
3. **损失发生后及时减损**：留证已采取的补救措施
4. **追究赔偿时综合证据**：损失数额 + 因果关系 + 过错程度

### employee

1. **审查赔偿条款**：是否将经营风险全部转嫁？
2. **保留岗位培训 / 操作规程证据**：证明单位管理缺失
3. **协助单位减损**：避免被认定故意扩大损失
4. **争议出现时**：聚焦过错程度（争取一般过失认定）+ 因果关系挑战
