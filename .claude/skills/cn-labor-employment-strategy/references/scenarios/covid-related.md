# 涉疫情案件

> 涵盖疫情期间工资支付、用工管理、合同履行 / 解除等争议。
> 判例支撑：汇编 4.5 涉疫情案件 17 案。详见 `case-database/ch4-wages-and-benefits.md` § 4.5。

## 一、疫情期间工资支付规则

### 1.1 隔离 / 医学观察期工资

按《传染病防治法》及相关规定：

- 患者 / 疑似 / 密切接触者**依法隔离治疗 / 医学观察期间** → 视同正常出勤，工资照付
- 居家隔离（非政府强制）不当然适用 → 看具体情形

case 4.5.7：劳动者不属于需隔离治疗或医学观察的三类人员 + 所在地未实施小区隔离 + 物业单位的居家隔离仅是物业管理措施 → **不享受**《传染病防治法》隔离期待遇。

### 1.2 停工停产期工资

- 停工停产**第一个工资支付周期内**：按劳动合同约定工资标准支付
- 超过一个工资支付周期：未提供劳动的，支付**生活费**（不低于当地最低工资 80%）

### 1.3 延迟复工期间工资

case 4.5.X 系列：政府防控措施导致延迟复工 → 按停工停产规则处理。

## 二、疫情期间用工管理

### 2.1 共享用工

case 4.5.10 张某诉某餐饮公司、某电商公司：

> 共享用工是指员工富余的用人单位将劳动者借调至员工稀缺的用人单位，**原劳动关系不发生改变**，由借入借出劳动力的用人单位之间签订协议明确权利义务关系的用工方式。
> 原用人单位受疫情影响与劳动者终止劳动合同，借用单位明知此情形仍然继续用工的，应认定劳动者在原劳动合同终止后与借用单位之间建立了劳动关系。

### 2.2 短期临时支援

case 4.5.12 王某诉某人力公司、某汽车公司：

> 用人单位因受疫情影响安排劳动者临时短期支援其他部门的，属于合理行使用工管理权的范畴，不属于劳动合同的变更。劳动者无正当理由拒绝安排，用人单位依照规章制度解除劳动后，劳动者主张违法解除劳动合同赔偿金的，人民法院不予支持。

### 2.3 隐瞒行程 / 违反防疫规定

case 4.5.11 郗某诉某人力公司、case 4.5.16 李某诉某通信公司：

> 劳动者在疫情防控期间擅自离岗并隐瞒行程，不遵守疫情防控相关规定，**严重违反用人单位相关规章制度的，用人单位可据此解除劳动关系**。

> 劳动者应当落实疫情防控要求，向用人单位如实报告行程，该如实报告义务不以对疫情防控产生重大后果为条件。

### 2.4 公交停运 / 实际无法返岗

case 4.5.14 张力娟诉上美塑胶：

> 劳动者因政府疫情防控措施导致的公交停运未能如期返岗，如果通过其他方式返岗耗费的精力远超其能够承受的范围，则用人单位不应将此情形认定为旷工。

## 三、疫情期间合同解除 / 履行

### 3.1 假借疫情逼离

case 4.5.17 咸某诉某针织公司：

> 用人单位假借疫情，利用放长假等形式变相逼迫劳动者离职的，属于劳动合同法 §38 规定的未按照劳动合同约定提供劳动保护或者劳动条件，劳动者有权解除劳动合同并主张经济补偿。

### 3.2 因疫情拖欠工资能否构成 §38(2)

case 4.5.15 张某诉某旅游公司、case 4.5.13 顾某诉某制药公司：

> 用人单位因受疫情影响出现资金困难，劳动者因用人单位未及时足额支付劳动报酬提出解除劳动合同并主张经济补偿的，应当考虑用人单位受疫情影响的实际情况，拖欠劳动报酬的主观恶意和违法程度，审慎认定。**用人单位不存在主观恶意，且经法定程序延期支付工资未超过 30 日的，劳动者不能以此为由主张经济补偿**。

实务推论：疫情期间欠薪 §38(2) 适用标准放宽（单位有客观困难 + 程序合规即可对抗）。

### 3.3 年休假统筹抵扣

case 4.5.8 + 4.5.9：单位受疫情影响停工停产期间 → 可与劳动者协商优先抵扣带薪年休假（协商是程序要件 + 不要求协商一致）。

## 四、操作要点

### employer

1. **疫情期间欠薪**：履行书面告知 + 法定程序延期（30 日内）→ 可对抗 §38(2)
2. **临时短期支援其他部门**：保持工资性质隶属不变 → 属合理用工管理
3. **共享用工**：原劳动关系保留 + 借调协议明确 → 借用单位不直接成为劳动关系主体
4. **疫情隔离 / 防控违纪**：员工隐瞒行程 / 擅自离岗 → §39 解除有效
5. **不得假借疫情逼离**（放长假、停薪留职等）→ 触发推定解雇

### employee

1. **被违法逼离**：留证 + 主张 §38(1) 被迫离职 + 经济补偿
2. **被强制临时调动**：评估是否短期 / 工资隶属是否变更 → 区分合理用工与变相调岗
3. **疫情期间欠薪**：主张支付时区分单位客观困难 vs 主观恶意
4. **隔离期工资**：明确自己属于法定隔离 / 医学观察人员 + 留证
