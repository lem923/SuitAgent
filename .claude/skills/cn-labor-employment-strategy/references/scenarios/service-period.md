# 服务期与培训费违约

> 涵盖单位出资培训后约定服务期、提前离职违约金问题。
> 判例支撑：汇编 3.5 服务期 9 案 + 7.1 事业单位 4 案，共 13 案。
> 详见 `case-database/` § 3.5 与 § 7.1。

## 一、法律依据

《劳动合同法》§22：

> 用人单位为劳动者提供专项培训费用，对其进行专业技术培训的，可以与该劳动者订立协议，约定服务期。
> 劳动者违反服务期约定的，应当向用人单位支付违约金。**违约金的数额不得超过用人单位提供的培训费用**。
> 用人单位要求劳动者支付的违约金不得超过服务期尚未履行部分所应分摊的培训费用。

§25：除 §22 服务期违约金 + §23 竞业限制违约金外，单位不得与劳动者约定由劳动者承担违约金。

## 二、关键认定

### 2.1 "专项培训费用"的范围

- 单位出资让劳动者参加的**外部培训**（学费、教材、差旅、培训期间工资）
- 普通入职培训、岗位培训、安全培训**不算**专项培训
- 出国留学、专业认证培训 → 典型专项培训

### 2.2 违约金封顶规则

```
违约金 ≤ 培训费用总额
违约金 ≤ 服务期未履行部分对应的培训费用
```

实务推论：劳动者服务期已履行一半 → 单位最多追索剩余一半培训费对应金额。

### 2.3 在职期间法定所得不属于违约金范围

**事业单位案例 case 7.1.4 汪某诉某区医院**：

> 工作人员在进修期间获得的基本工资、国家规定的福利待遇和社会保险待遇均系法定所得，**不应以返还上述所得作为违约责任承担方式**。

实务推论：单位与劳动者约定"违反服务期需返还培训期间工资"的条款，超出 §22 范围 → 无效。

### 2.4 服务期到期后保留服务义务条款

case 5.3.X 系列：服务期已届满的，单位无权追索违约金。

## 三、事业单位特殊规则

case 7.1.2 唐某诉某大学、7.1.3 苏某诉中医院、7.1.5 某医院诉贾某：

事业单位与工作人员约定服务期 + 违约金 → **不受 §22 限制**（事业单位人事关系不完全适用劳动合同法）。但仍需：

- 协议合法（不违反强制性规定）
- 违约金数额合理
- 工作人员违反约定时承担违约责任

实务推论：事业单位的服务期违约金可以**显著高于**企业的 §22 上限。

## 四、典型成本路径

### employer

| 操作 | 收益 |
|---|---|
| 完整培训记录 + 费用凭证 + 书面服务期协议 | 违约金 ≤ 培训费用 + 未履行部分对应 |
| 培训费证据不充分 | 违约金按合同约定打折或 0 |
| 在工资 / 福利上设违约金条款 | 超出 §22 范围 → 无效 |

### employee

| 操作 | 风险 |
|---|---|
| 服务期内辞职 | 按未履行部分对应培训费支付违约金 |
| 因 §38 法定情形辞职 | 多数地区认定免除违约金 |
| 服务期到期后辞职 | 0 |
| 拒绝单位的"专项培训" + 留证 | 避免触发服务期 |

## 五、操作要点

### employer

1. **培训前签订书面服务期协议**：明确培训内容、费用、期限、违约金计算
2. **保留完整培训费用凭证**：发票、银行流水、培训机构合同
3. **培训期间工资单独标注**（如纳入培训费）
4. **服务期超合理范围**（如 10 年起）→ 法院可能酌情调减
5. **违约金不要超过培训费实际支出**

### employee

1. **审查服务期协议**：培训内容是否专项？费用是否真实？服务期是否合理？
2. **保留培训实际参与的证据**（如不参与可主张服务期协议未生效）
3. **服务期内辞职前评估违约金**：剩余服务期 / 总服务期 × 培训费 = 应付违约金
4. **§38 法定情形辞职**：主张免除违约金（多数地区支持）
