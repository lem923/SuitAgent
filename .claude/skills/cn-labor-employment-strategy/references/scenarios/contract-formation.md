# 合同期限与效力

> 涵盖劳动合同的期限选择（固定 / 无固定 / 任务期限）、合同效力（欺诈 / 就业资格 / 其他无效情形）。
> 判例支撑：汇编 3.1 期限 4 案 + 3.2 效力 11 案，共 15 案。

## 一、合同期限的选择

### 1.1 三种期限类型（§12）

- 固定期限劳动合同
- 无固定期限劳动合同
- 以完成一定工作任务为期限的劳动合同

### 1.2 无固定期限合同的法定订立情形（§14）

详见 contract-renewal-playbook §一。三种情形：

1. 在本单位连续工作满 10 年
2. 用人单位初次实行劳动合同制或国有企业改制重新订立劳动合同时，连续工作满 10 年且距退休不足 10 年
3. 连续订立二次固定期限劳动合同 + 续订劳动合同

实务关键：第三项是争议高发点，详见 contract-renewal-playbook。

## 二、合同效力问题

### 2.1 §26 无效情形

1. 以欺诈、胁迫、乘人之危使对方违背真实意思订立或变更合同
2. 用人单位免除自己法定责任 / 排除劳动者权利
3. 违反法律、行政法规强制性规定

### 2.2 欺诈认定

**单位欺诈劳动者**：
- 虚假招聘信息
- 隐瞒重大事项（如违法生产环境、工资倒挂等）

**劳动者欺诈单位**：
- 学历造假 / 工作经验造假 / 简历造假
- 实务认定较严：必须与岗位履行**实质相关** + 单位**明确将该条件列为录用条件**

case 5.3.X 系列（劳动者欺诈）：劳动者隐瞒身体缺陷但能正常工作 + 未达严重程度 → 不构成欺诈（case 5.4.1）

### 2.3 就业资格

case 5.5.18 残疾人案：单位不应将"残疾"作为解除依据（除非残疾实质影响工作能力且劳动者故意隐瞒）。

### 2.4 合同的部分无效

case 6.3.1 李建平诉东方客运、case 6.3.2 新东旭公司：

> 用人单位与劳动者自行约定**减轻或者免除缴纳社会保险费义务**的条款，因违反法律法规的强制性规定而无效。
> 劳动合同**部分无效，不影响其他部分效力**的，其他部分仍然有效。

实务推论：合同中违法条款无效，但其余条款仍有效，劳动关系继续存在。

## 三、典型成本路径

### employer

| 情形 | 风险 |
|---|---|
| 入职 1 个月内未签合同 | 见 double-wage.md |
| 满 1 年未签合同 | 视为已订立无固定期限合同 + 11 个月二倍工资 |
| 第三次续签未订立无固定期限 | 见 contract-renewal-playbook |
| 单位欺诈员工 → 合同被撤销 | 单位承担赔偿责任 |
| 员工欺诈（学历造假等）→ 合同无效 | 可解除（§39(5)），但需证明实质相关 |
| 单位违法条款 | 部分无效，其他部分仍有效 |

### employee

| 操作 | 收益 |
|---|---|
| 未签合同主张 | 二倍工资 + 视为无固定期限 |
| 主张单位欺诈 | 撤销合同 + 赔偿损失 |
| 主张违法条款无效（如免除社保） | 单位补缴 + 可能 §38(3) 被迫离职 |

## 四、操作要点

### employer

1. **入职 1 个月内签订书面合同**
2. **如实陈述招聘信息**：避免后续欺诈撤销争议
3. **如有学历 / 经验要求**：列为明确的录用条件 + 入职时核实
4. **不要在合同中设违法条款**：免除社保 / 转嫁经营风险等均无效

### employee

1. **保留入职信息证据**：招聘信息、面试录音、offer letter
2. **核查合同条款**：免除社保 / 单方解除条件 / 违约金条款是否合法
3. **保留自己学历 / 经验的真实证据**：避免被反诉欺诈
