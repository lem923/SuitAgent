# 未签书面合同二倍工资（§82）

> 用人单位自用工之日起超过 1 个月不满 1 年未与劳动者订立书面劳动合同的，应当向劳动者每月支付二倍工资（《劳动合同法》§82）。
>
> 判例支撑：汇编 3.3 二倍工资 22 案。详见 `case-database/ch3-contract-formation-and-performance.md` § 3.3。

---

## 一、法律依据与基本规则

### 1.1 §82 规则

```
未签书面合同时间          二倍工资责任
└─ 1 个月以内               无（合理时间）
└─ 1 个月 ~ 1 年            支付二倍工资（最多 11 个月）
└─ 满 1 年                  视为已订立无固定期限劳动合同（§14）
```

### 1.2 时效问题

二倍工资中"二倍"部分属于赔偿性质，不是劳动报酬，**适用 1 年仲裁时效**（按月计算）。

实务推论：劳动者主张二倍工资，应在每个月差额发生后 1 年内主张。

---

## 二、不构成二倍工资的"替代性文件"

汇编 3.3(A) 子节系统整理了多种"替代性文件"的认定规则——这些情形下，单位虽未签《劳动合同》正式文本，仍可不支付二倍工资。

### 2.1 集体合同 / 框架文件 + 个别文件配套

判例倾向：单位与劳动者通过集体合同 + 入职登记表 + 岗位职责 + 工资确认等文件组合形成的实际意思表示，可视为已订立书面合同。

### 2.2 续订合同争议期间的处理

合同到期后双方继续履行 + 在续订过程中产生异议的，多数判例不支持二倍工资（劳动者已明知双方仍在协商）。

### 2.3 多次拒签合同的劳动者

case 3.3.X 系列（"劳动者原因"子节）：

> 用人单位已经主动提供书面劳动合同文本，劳动者拒绝签订或故意拖延签订的，单位无需支付二倍工资。

实务推论：单位提供合同 + 劳动者拒签的证据（如多次催签邮件、HR 谈话记录、拒签的书面证明）→ 可对抗二倍工资主张。

## 三、典型成本路径

### 3.1 employer 视角

| 情形 | 后果 |
|---|---|
| 用工 1 个月内签订书面合同 | 0 |
| 1 个月~1 年内未签 + 有替代性文件 | 0（视情况）|
| 1 个月~1 年内未签 + 劳动者拒签证据充分 | 0 |
| 1 个月~1 年内未签 + 无替代文件无拒签证据 | 1~11 个月工资差额 |
| 满 1 年未签 | **视为无固定期限合同** + 此前 11 个月二倍工资 |

### 3.2 employee 视角

| 操作 | 收益 |
|---|---|
| 入职后 1 个月主动催签 + 留证 | 锁定单位违法事实 |
| 满 1 年未签 | 主张无固定期限合同 + 11 个月二倍工资 |
| 时效内（按月 1 年）主张 | 可获月度差额累积 |
| 拒绝单位补签时（特别注意）| 可能被认定"劳动者原因" |

## 四、双视角操作要点

### 4.1 employer 操作清单

1. **用工 1 个月内必签**——无任何例外
2. **HR 流程严控**：入职登记 + 合同送达 + 双签 + 留存原件，全部书面化
3. **劳动者拒签时**：
   - 第一次书面催签
   - 第二次书面催签（明确告知后果）
   - 仍拒签 → 用工满 1 个月时**书面终止劳动关系**（§5(2)、§39 配合）
4. **续订合同时**：原合同到期前 1 个月发出续订要约（避免"超过 1 个月"陷阱）

### 4.2 employee 操作清单

1. **入职即催签**：未在 1 个月内签订的，留证（邮件 / 微信 / 书面）
2. **保留实际用工证据**：工资银行流水、考勤记录、工作证、对外身份证明、工作沟通记录
3. **时效注意**：差额按月发生，**按月计算 1 年时效**
4. **不要拒签真实条款**：避免落入"劳动者原因"陷阱；如条款显著不公，先签后维权
5. **满 1 年时**：可主张视为已订立无固定期限劳动合同（重大权利）

## 五、关键证据

### 5.1 employer 证据清单

| 证据 | 证明目的 |
|---|---|
| 入职登记表 / 录用通知 + 劳动者签字 | 用工起算日 |
| 已签订的劳动合同原件 | 履行 §10 义务 |
| 多次催签的邮件 / 微信 / 通知 + 送达证据 | 单位无过错 |
| 劳动者拒签的书面证明 / 谈话记录 | 劳动者原因抗辩 |
| 替代性文件（集体合同、入职文件、岗位说明书）| 双方已有实质合意 |

### 5.2 employee 证据清单

| 证据 | 证明目的 |
|---|---|
| 入职日期证据（offer 邮件、入职登记、工资发放起点）| 起算日 |
| 工资流水（月度发放）| 用工持续 |
| 工作记录（邮件、聊天、出勤）| 实际履行劳动 |
| 自己催签的证据（邮件 / 微信 / 谈话）| 单位过错 + 时效中断 |
