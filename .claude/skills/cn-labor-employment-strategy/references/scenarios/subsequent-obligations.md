# 附随义务（离职证明、社保转移、保密、不诋毁）

> 劳动合同解除 / 终止后单位与劳动者的附随义务。
> 判例支撑：汇编 5.9 附随义务 11 案。详见 `case-database/ch5-termination-and-exit.md` § 5.9。

## 一、单位的附随义务

### 1.1 出具离职证明（§50）

- 解除 / 终止时**应当**出具书面证明（不需经劳动者请求）
- 离职证明应载明：劳动合同期限、解除或终止日期、工作岗位、本单位工作年限
- **不应**载明：解除的具体原因、是否违纪、个人评价（除非劳动者要求）

### 1.2 社保 / 公积金转移

- 解除 / 终止后 **15 日内**为劳动者办理档案和社保关系转移手续
- 拖延办理给劳动者造成损失的，单位承担赔偿责任（如：影响新单位入职、影响购房资格）

### 1.3 工资 + 经济补偿结算

- 应在解除 / 终止时一次性付清
- 实务可在 15 日内办理（部分地区有具体期限）

### 1.4 工作交接的配合义务

- 单位应配合劳动者完成工作交接
- 不得借交接义务扣留工资 / 离职证明 / 个人物品

## 二、劳动者的附随义务

### 2.1 工作交接（§50(2)）

- 劳动者应当按双方约定办理工作交接
- 单位依本法规定应支付经济补偿的，应在办结交接时支付
- 拒不交接的，单位可拒付经济补偿 / 暂缓支付（合理期限内）

## 三、不诋毁义务

case 5.3.43 沈某诉某客车（过度维权解除）：

> 劳动者为迫使用人单位解决其转岗问题，利用互联网社交平台发表大量具有贬损、攻击用人单位词汇的文字或者影像，超越言论自由限度，引发公众对用人单位名誉的怀疑和社会评价降低，给用人单位造成重大损害，用人单位可以解除劳动合同。

实务推论：

- 在职期间：劳动者对单位负诚信履职 + 不诋毁义务（违反构成 §39(3) 严重失职）
- 离职后：原则上自由 + 但不得编造虚假事实诋毁

case 5.3.41 微信泄露内部邮件：泄露后及时删除 + 未造成重大损害 → 不构成 §39(3) 严重失职。

## 四、违反附随义务的责任

### 4.1 单位不出具离职证明 / 拖延社保转移

- 给劳动者造成实际损失（如失业救济不能领、新工作不能办手续）
- 单位承担赔偿责任（实际损失为限）

### 4.2 单位在离职证明中作不当评价

- 单位在离职证明中载明负面评价 → 可能构成名誉侵权
- 劳动者可主张消除影响 + 赔偿损失

### 4.3 劳动者拒不交接

- 单位可暂缓支付经济补偿（合理期限内）
- 单位可依 §90 追偿损失
- 但不得永久扣留 / 不得拒付**法定工资部分**

## 五、操作要点

### employer

1. **离职证明及时出具**：解除 / 终止时一并出具书面证明
2. **离职证明事实性表述**：仅载明法定要素，不作主观评价
3. **社保 / 档案转移 15 日内办理**：避免延误造成损失
4. **工作交接清单化**：物品、账号、资料逐项列明 + 双签
5. **经济补偿与交接挂钩**：可约定"完成交接后支付"（合理期限内）

### employee

1. **要求出具离职证明**：留证索取行为 + 单位拒绝的证据
2. **核查离职证明内容**：避免单位载入不当评价
3. **及时跟进社保 / 档案转移**：超过 15 日的可主张赔偿
4. **完整完成工作交接**：避免被扣付经济补偿
5. **不诋毁原单位**：避免被反诉名誉侵权
