# 职工破产债权

> 用人单位破产时职工债权的清偿顺序与认定规则。
> 判例支撑：汇编 5.10 职工破产债权 4 案。

## 一、清偿顺序（《企业破产法》§113）

```
破产费用 + 共益债务（最优先）
    ↓
第一顺位：职工债权
    · 工资、医疗、伤残补助、抚恤费用
    · 应划入职工个人账户的基本养老保险、基本医疗保险费用
    · 法律法规规定应支付给职工的补偿金
    ↓
第二顺位：社会保险费用 + 税款
    ↓
第三顺位：普通破产债权
```

## 二、可纳入职工债权的项目

- 工资（拖欠的劳动报酬，包括加班费、提成、奖金等）
- 医疗费 / 伤残补助 / 抚恤费用
- 应缴个人账户的社保（基本养老 + 基本医疗）
- **经济补偿** / 违法解除赔偿金（汇编案例确认纳入）
- 未休年休假折算工资
- 工伤待遇

## 三、不纳入职工债权的项目

- 应缴统筹账户的社保（属于第二顺位社保费）
- 公积金（实务有分歧，部分地区纳入第一顺位）
- 单位的损害赔偿请求（如劳动者履职过错导致单位损失）→ 反诉债权

## 四、实务操作

### 申报职工债权

- 破产管理人公告债权申报期
- 职工债权由破产管理人**主动统计调查**（《企业破产法》§48），无需职工逐一申报，但职工有异议可申报核对
- 异议可在债权人会议讨论时提出 / 向法院起诉

### 工资欠条与劳动争议

case 1.1.5 郑伟永诉鸿安电力：

> 劳动者以用人单位的工资欠条为证据起诉，只有在诉讼请求不涉及劳动关系其他争议时，才能视为拖欠劳动报酬争议，直接按照普通民事纠纷受理。

破产程序中：

- 单纯欠薪 → 可直接申报职工债权
- 涉及劳动关系认定、违法解除赔偿等争议 → 需经仲裁前置

### 虚假诉讼防范

case 1.2.1 ~ 1.2.5：破产程序中，劳动者大额欠薪主张 + 长期停业 / 资不抵债企业 → 法院应加强审查（详见 procedure-and-evidence.md）。

## 五、操作要点

### 职工

1. **及时关注破产公告 + 申报期**
2. **核对破产管理人统计的债权数额**：异议可提出
3. **保留完整证据**：劳动合同、工资流水、欠薪证据
4. **避免参与虚假诉讼**：与其他职工 / 单位串通虚增债权 → 自身承担虚假诉讼责任

### 单位 / 破产管理人

1. **主动统计调查职工债权**：避免遗漏或多算
2. **审查异常债权主张**：长期停业 / 资不抵债 + 大额欠薪 → 加强审查
3. **依法清偿优先顺序**：先职工债权 → 再社保税款 → 再普通债权
