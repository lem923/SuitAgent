# 试用期

> 试用期适用规则、不符合录用条件解除（§39(1)）。
> 判例支撑：汇编 3.4 试用期 2 案 + 5.3 / 5.7 相关案例。

## 一、试用期上限（§19）

| 合同期限 | 试用期上限 |
|---|---|
| 3 个月以上不满 1 年 | 1 个月 |
| 1 年以上不满 3 年 | 2 个月 |
| 3 年以上 / 无固定期限 | 6 个月 |
| 完成一定工作任务为期限 / 不满 3 个月 | 不得约定试用期 |

同一单位与同一劳动者只能约定一次试用期。

## 二、试用期工资（§20）

不得低于：
- 本单位相同岗位最低档工资 80%
- 或劳动合同约定工资 80%
- 不得低于当地最低工资标准

## 三、§39(1) 不符合录用条件

**要件**：
1. 录用条件**事先明确**且**可量化**
2. 录用条件**已告知劳动者**（书面 / 入职培训）
3. 试用期内的考核**实际进行**
4. 考核结论"不符合录用条件"

**实务陷阱**：
- 录用条件 ≠ 试用期满后的转正考核标准（录用条件指岗位胜任的基本条件）
- 录用条件未事先明确 → 不能援引 §39(1)
- "末位淘汰"不构成 §39(1)（参 dismissal-incompetence-playbook）
- 试用期满后才决定不符合录用条件 → 已超期，不能援引 §39(1)

case 5.3.9 张某诉某快递公司、case 5.3.10：违反法定加班上限的规章制度规定无效，**劳动者拒绝违法加班不构成"不符合录用条件"**。

case 5.7.19（恢复劳动关系）：试用期违法解除被认定，但因双方未建立互信，**不宜判决恢复劳动关系**。

## 四、典型成本路径

| 操作 | 单位成本 |
|---|---|
| 录用条件明确 + 已告知 + 考核实际 + §39(1) 解除 | 0 |
| 录用条件不明 / 未告知 → §39(1) 解除 | 2N |
| 试用期满后解除 | 转入 §39 其他项或 §40，需 0 / N+1 |
| 末位淘汰冒充不符合录用条件 | 2N |

## 五、操作要点

### employer

1. **入职时书面告知录用条件**：岗位说明书 + 员工签收
2. **试用期考核机制**：明确考核标准、考核期间、考核人
3. **试用期内决定**：考核结论形成于试用期内 + 解除通知送达于试用期内
4. **不要试用期满才决定**

### employee

1. **审查录用条件**：是否事先明确？是否已告知？
2. **试用期被解除**：要求单位出示录用条件 + 考核结论
3. **录用条件不明** → 主张违法解除 2N
