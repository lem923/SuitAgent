# 工资、奖金、同工同酬

> 涵盖工资克扣、农民工工资、奖金权利、同工同酬等争议。
> 判例支撑：汇编 4.1 工资刑事 3 案 + 4.2 工资民事 34 案，共约 37 案。
> 详见 `case-database/ch4-wages-and-benefits.md` § 4.1 + § 4.2。

## 一、工资构成与基数

### 1.1 工资 = 劳动报酬

包括：基本工资、绩效工资、奖金、津贴、补贴、加班费、特殊情况下支付的工资。

不包括：单位为员工承担的社保 / 公积金 / 福利、福利性补贴（如车补、餐补在某些情形）、劳保用品、劳动保护费。

### 1.2 经济补偿月工资 W 的计算

详见 severance-agreement-playbook §一。要点：

- 解除前 12 个月平均工资
- 含所有劳动报酬（奖金、加班费、津贴等）
- 待岗 / 病假 / 三期等非正常状态的工资**不计入**（case 5.7.10）
- 高薪员工（高于社平 3 倍）适用封顶规则

## 二、工资克扣的认定

### 2.1 合法扣减情形

- 个人所得税代扣代缴
- 应由劳动者承担的社保费用 / 住房公积金
- 法院判决、裁定的扶养费、赡养费
- 法律法规规定可以扣除的其他费用

### 2.2 违法克扣情形

case 4.2.X 系列：

- 单方降低工资标准未协商一致
- 以"绩效"等浮动方式架空原工资
- 转嫁经营风险（如回款风险）→ case 4.2.21 李某诉登跃公司
- 罚款超出合理范围

case 4.2.21 关键规则：

> 劳动关系的本质是劳动者提供劳动，用人单位支付报酬，企业风险与劳动者不直接相关。用人单位以规章制度或者离职协议等方式，将回款风险转嫁给劳动者的约定**无效**。

## 三、农民工工资特别保护

### 3.1 《保障农民工工资支付条例》

case 5.3.7 赵某诉某科技公司：

> 农民工应当遵守劳动纪律和职业道德，执行劳动安全卫生规程，完成劳动任务。农民工严重违反劳动纪律，用人单位解除劳动合同的理由和程序合法的，无需支付赔偿金。

实务推论：农民工享有工资支付的特别保护（拒不支付罪、欠薪人黑名单），但**遵守劳动纪律的义务与普通员工相同**。

### 3.2 拒不支付劳动报酬罪

汇编 4.1 工资刑事案件（3 案）：

- 拒不支付劳动报酬罪（《刑法》§276之一）
- 司法解释：欠薪金额达入罪标准 + 经政府主管部门责令支付仍不支付

## 四、奖金的权利义务

### 4.1 已计提奖金的发放义务

case 4.2.X 系列：

> 单位规章制度或劳动合同明确规定的奖金 + 已经计提 + 满足发放条件的 → 单位有支付义务。即使劳动者已离职，对其在职期间已经达成的部分仍应支付。

### 4.2 未离职为发放条件的条款

- 单位约定"奖金发放时仍在职"为发放条件的，多数判例**部分支持**
- 但单位违法解除导致劳动者无法满足"仍在职"条件的 → 仍应支付

### 4.3 销售人员的提成

case 5.2.8 陈某诉某公司：

> 业务提成是劳动报酬的一种形式，业务提成比例的约定是劳动合同的重要组成部分，经用人单位与劳动者协商一致方可变更。用人单位单方随意变更业务提成比例损害劳动者权益的，劳动者可以解除劳动合同并请求用人单位支付经济补偿。

## 五、同工同酬

### 5.1 同工同酬的认定

case 4.2.X 系列（D 子节）：

> 同工同酬 = 同一岗位 + 同一工作内容 + 同一工作量 + 同一工作业绩 → 应获得同等劳动报酬。

实务推论：

- 编制内 vs 编制外的差异不必然违反同工同酬（case 7.1.1）
- 劳务派遣人员与用工单位正式员工的同工同酬有特别规定
- 同岗位但岗位职责、工作经验、绩效不同的差异化薪酬不违反

### 5.2 薪酬保密的边界

case 3.6.3 数据公司诉沈某：

> 薪酬保密制度旨在防止员工之间相互攀比和恶性竞争，一般适用于工作成效难以具体量化考核的岗位和享受特殊待遇或者高薪引进的人才，**不能对依法享有同工同酬权利的基础性岗位"一刀切"适用**。

## 六、操作要点

### employer

1. **工资条款书面化**：基本工资 + 绩效 + 奖金 + 津贴的构成清晰
2. **变更工资必须协商一致 + 书面**：单方降薪几乎必败
3. **不要转嫁经营风险**：回款风险、客户拖欠风险等不得通过规章制度转嫁
4. **奖金发放条件设计**：明确发放时点、条件、计算公式
5. **薪酬保密**：仅适用于难以量化的岗位、特殊待遇岗位

### employee

1. **保留工资证据**：劳动合同、入职薪酬通知、银行流水、工资条
2. **质疑单方降薪**：书面提出异议 + 主张恢复原工资
3. **主张拖欠工资**：满足"恶意"条件时可援引 §38(2) 被迫离职
4. **奖金主张**：在职期间已达成 + 未发放的部分可追索
5. **同工同酬**：举证同岗位同业绩 + 薪酬差异
