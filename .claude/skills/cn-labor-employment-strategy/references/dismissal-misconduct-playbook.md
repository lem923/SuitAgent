# 违纪解除 Playbook（§39）

> **场景定位**：用人单位以"严重违反规章制度"或"严重失职、营私舞弊"为由依《劳动合同法》§39 解除劳动合同。
> 该场景司法争议高频，规章制度有效性是核心战场。
>
> **stance 适用**：employer / employee 双视角。
> **判例支撑**：汇编 5.3(A) 违纪 28 案 + 5.3(B) 渎职 14 案 + 5.3(C) 劳动者欺诈 1 案 + 5.3(D) 其他 1 案，共约 50 案。
> 详见 `case-database/ch5-termination-and-exit.md` § 5.3。

---

## 一、法理框架

### 1.1 法律依据

《劳动合同法》§39 列举六种过失性辞退情形：

| 款项 | 情形 | 关键认定难点 |
|---|---|---|
| §39(1) | 试用期不符合录用条件 | 录用条件须事先明确、可量化 |
| **§39(2)** | **严重违反规章制度** | 规章制度有效性 + "严重"的实质审查 |
| **§39(3)** | **严重失职、营私舞弊，给单位造成重大损害** | "重大损害"标准 + 主观故意要件 |
| §39(4) | 同时与其他单位建立劳动关系，对完成本单位工作造成严重影响 | 实务罕用 |
| §39(5) | 因 §26(1)(1) 致使合同无效（欺诈、胁迫） | 录用欺诈认定 |
| §39(6) | 被依法追究刑事责任 | 行政拘留 ≠ 刑事追究（参 case 5.3.27）|

§39 适用结果：**0 经济补偿**（合法解除）；适用错误：**2N**（违法解除）。

### 1.2 §39(2) 严重违纪 —— 三个累积要件

**要件 A：规章制度有效性**

→ 内容合法（不违反法律、行政法规强制性规定）<br>
→ 民主程序（经职代会或全体职工讨论；参 case 5.3.17、5.3.14）<br>
→ 公示告知（已向劳动者公示或签收；参 case 5.3.17、5.3.23）

任一要件缺失 → 规章制度对劳动者不发生效力 → 解除依据不成立 → **2N**。

**例外（汇编反映的特殊情形）**：
- 安全防火制度即便有制定程序瑕疵，岗位人员基本职责违反时仍可解除（case 5.3.23 配电室违规）
- 劳动合同法施行前的制度，内容合理、已告知的，可作为依据（case 5.3.14）

**要件 B：违纪事实清楚 + 证据充分**

证据应当涵盖：考勤、监控、邮件、聊天记录、证人证言、员工陈述等。证据合法性问题——**用人单位以严重侵害劳动者合法权益、违反法律禁止性规定或严重违背公序良俗的方法形成或取得的证据，不得作为认定案件事实的根据**（case 1.1.9）。

**要件 C："严重"的实质审查**

- 规章制度对"严重"的具体定义必须明确（如"旷工 3 天以上"、"接受供应商礼品超过 X 元"），不能用"情节严重的"等空白条款兜底
- 司法对"严重"做实质审查（case 5.3.8）：劳动者行为在制度中有所提及但情节显著轻微远未达到严重程度的，单位不得援引 §39(2)
- "故意促成解除条件"被识破：单位将劳动者正常投诉定性为违纪、累积升格为解除事由的，不具正当性（case 5.3.28）

### 1.3 §39(3) 严重失职、营私舞弊 —— 两个分支

**分支 A：严重失职 + 重大损害**（基本路径）

要件累积：
- 失职行为存在
- 给单位造成重大损害
- 因果关系成立

汇编重要细化（case 5.3.34 环境污染）：以严重失职、重大损害为由解除时，**法院可减轻用人单位对"损害发生"方面的举证责任**——因为某些违规行为（如违反污水处理规程）必然导致损害结果。

**分支 B：违反忠实义务 + 主观恶意**（可不以重大损害为前提）

case 5.3.35 王凯案确立的规则：
- 劳动者故意损坏设备工具、浪费原料、泄漏或出卖商业秘密，不仅违反忠实义务，更具主观恶意
- 此时再留用存在相当高的风险
- 不必等到造成重大损害后才可解除
- **行使即时解除权可以不以造成重大损害为前提**

这是 employer 在不易证明"重大损害"时的重要后备路径。

### 1.4 程序要件 —— §43 工会告知

单位单方解除应当事先将理由通知工会（§43）：
- 工会有权要求纠正（不强制采纳）
- 单位将处理结果书面通知工会
- 未通知工会的解除程序违法（case 5.3.2 徐杰案）

补正空间（case 5.7.12）：因未通知工会被法院判决恢复履行后，再补正通知程序**不产生法律效力**——补正对象已不存在。

## 二、典型违纪类型与判例分布

### 2.1 违反规章制度（§39(2)）

| 违纪类型 | 司法倾向 | 关键判例 |
|---|---|---|
| 旷工 / 未按制度请假 | 支持解除（前提：制度有效）| case 5.3.22、5.3.25、5.3.27 |
| 远程考勤异常无合理解释 | 支持解除 | case 5.3.24 |
| 高管擅自休假 | 支持解除（不定时工时不豁免考勤）| case 5.3.20 |
| 欺凌同事 | 支持解除（即使同事已谅解）| case 5.3.5 |
| 性骚扰 | 支持解除（民法典 §1010 联动）| case 5.3.11、5.3.12 |
| 拒绝违章 / 违法加班指令 | **不支持解除**（劳动者权利）| case 5.3.9、5.3.10、5.3.2 |
| 不良征信 | **不支持解除**（制度未列）| case 5.3.18 |
| 试用期拒绝违法加班 | **不支持**（不符合录用条件认定不当）| case 5.3.9 |
| 投诉行为被定性为违纪 | **不支持解除**（故意促成）| case 5.3.28、5.3.29 |
| 处罚程序瑕疵 | **不支持解除** | case 5.3.19 |
| 外勤员工考勤缺失 + 单位默许 | **不支持解除** | case 5.3.21 |
| 规章制度内部冲突 | 援引对劳动者有利条款 | case 5.3.13 |

### 2.2 严重失职 / 营私舞弊（§39(3)）

| 违纪类型 | 司法倾向 | 关键判例 |
|---|---|---|
| 未申报利益冲突 / 隐瞒关联关系 | 支持解除 | case 5.3.30、5.3.31 |
| 部门负责人放任全员请假致工作瘫痪 | 支持解除 | case 5.3.32 |
| 违规操作致环境污染 | 支持解除（减轻举证）| case 5.3.34 |
| 故意损坏设备 / 泄漏商业秘密 | 支持解除（**不需重大损害**）| case 5.3.35 |
| 高管利用职务谋取商业机会 | 支持解除 | case 5.3.17、5.3.36 |
| 兼职影响本职工作致重大损害 | 支持解除 | case 5.3.37 |
| 站点配送员私揽快件赚差价 | 支持解除（营私舞弊） | case 5.3.42 |
| 公交司机推介黑车被曝光 | 支持解除（严重失职） | case 5.3.39 |
| 过度维权致用人单位名誉受损 | 支持解除（case 5.3.43） | 但需达到"重大"程度 |
| 偶尔失误、损害有限 | **不支持解除** | case 5.3.40 |
| 微信泄露内部邮件后已删除、未造成损害 | **不支持解除** | case 5.3.41 |
| 不当处罚引发过度维权（无故意、未致重大损害）| **不支持解除** | case 5.3.29 |
| 研发阶段性成果不达后续目标 | **不支持解除** | case 5.3.38 |

## 三、典型成本路径

### 3.1 employer 视角

| 状态 | 法律构成 | 单位成本 |
|---|---|---|
| 规章制度三要件齐备 + 违纪事实清楚 + "严重"认定合理 + 已告知工会 | §39(2) 合法解除 | **0** |
| 同上但忠实义务路径（§39(3) 分支 B） | §39(3) 合法解除（无需重大损害）| **0** |
| 规章制度未公示 / 未经民主程序 | 违法解除 | **2N** |
| "严重"认定证据不足 | 违法解除 | **2N** |
| 未告知工会 | 程序违法 | **2N**（部分地区可补正失败）|
| 解除证据系非法取得 | 违法解除 | **2N** |
| 劳动者主张恢复劳动关系（依 §48）| 恢复关系 + 期间工资 | **2N 等价 + 工资** |

### 3.2 employee 视角（被违纪解除时）

| 路径 | 攻击点 | 收益 |
|---|---|---|
| **A 规章制度无效**（最常见胜诉点）| 未经民主程序 / 未公示 / 内容违法 | 2N |
| **B "严重"程度审查** | 行为与"严重"定义不匹配 / 制度无明确定义 / 援引内部冲突的有利条款 | 2N |
| **C 程序违法** | 未通知工会 / 处罚程序瑕疵 | 2N |
| **D 证据不合法** | 非法取证（侵犯隐私 / 录音录像非法）| 2N |
| **E 故意促成解除** | 将正常投诉 / 维权定性为违纪 / 累积升格 | 2N |
| **F 恢复劳动关系** | §48 选择恢复 + 期间工资 | 2N 等价 + 工资周期 |

## 四、双视角策略

### 4.1 employer 操作清单（pre-action）

1. **规章制度自检**
   - 通过职代会或全体职工讨论的会议纪要 / 签到 ✓
   - 公示证据：员工签收回执 / 内网公告截图 / 入职培训记录 ✓
   - "严重"条款具体化（避免空白兜底）✓
   - 内部条款无冲突 ✓
   - 内容不超越合理权限（case 5.3.1：超越合理权限设定义务无效）

2. **违纪事实证据链**
   - 客观证据（考勤、监控、系统日志、邮件记录）优先
   - 主观陈述（员工自述、谈话记录）作为辅助
   - 避免非法取证（不得侵犯隐私、不得诱骗）

3. **解除程序固定**
   - 调查谈话记录（员工有权陈述申辩）
   - 工会告知函 + 工会反馈记录
   - 解除通知书载明具体事实、违反的制度条款、解除依据（§39 具体项）
   - 送达留证（签收 / EMS 双发）

4. **离职后续**
   - 离职证明应注明"以严重违反规章制度被解除劳动合同"（事实性表述）
   - 不安排工作交接的，按 §90 可追偿损失
   - 注意：不得在离职证明中作贬损性评价（case 5.9 附随义务）

### 4.2 employee 操作清单（被解除时）

1. **第一时间索取材料**：解除通知书、规章制度文本、工会告知函、违纪事实证据材料
2. **核查规章制度三要件**：民主程序记录 / 公示证据 / 内容合法性
3. **分析"严重"定义**：制度是否对该行为有明确的"严重"定义？是否援引"情节严重的"等空白条款？
4. **审查证据合法性**：是否涉及侵犯隐私、违法监控？
5. **选择维权路径**：
   - 单位证据扎实、违纪事实清楚的：考虑协商谈和（N + 1~3 月）
   - 单位证据有瑕疵的：仲裁主张 2N 或恢复劳动关系
   - 涉及特殊保护期（孕期/医疗期/工伤）的：违法解除几乎必胜

## 五、关键证据策略

### 5.1 用人单位证据清单

| 文件 | 证明目的 | 留存期限 |
|---|---|---|
| 规章制度文本（含版本号、生效日期）| 制度依据 | 永久 |
| 民主程序记录（职代会决议 / 全员讨论签到）| 制度有效性 | 永久 |
| 公示证据（员工签收回执 / 培训记录 / 内网截图）| 已告知劳动者 | 永久 |
| 违纪事实证据（考勤、监控、邮件、聊天记录）| 事实清楚 | 至少 3 年（仲裁时效 + 上诉周期）|
| 调查谈话记录（双方签字）| 给予员工陈述申辩权 | 至少 3 年 |
| 工会告知函 + 工会反馈 | 程序合法 | 至少 3 年 |
| 解除通知书 + 送达证据 | 解除合法性 | 至少 3 年 |
| 离职证明（事实性表述）| 附随义务履行 | 至少 3 年 |

## 七、与其他 playbook 的衔接

- **失败后衔接**：如违纪解除被认定违法 → 转入 `severance-agreement-playbook` 走加码协商解除
- **替代方案**：如证据不足走 §39 → 考虑 `dismissal-incompetence-playbook`（§40(2) 不胜任，需 N+1）或 `contract-modification-playbook`（调岗博弈，可能 0 或 N）
- **特殊保护期**：触发 §42 时禁用 §40/§41 但 **§39 仍可使用**（参 5.5.14 孕期严重违纪解除成立、5.5.17 三期女职工伪造病假成立）—— 但司法审查会更严
