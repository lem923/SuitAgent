# 保密与竞业限制 Playbook

> **场景定位**：劳动者在职期间的保密义务、离职后的竞业限制义务的设立、履行、违约、解除全流程。
> 这是劳动法领域**判例最丰富**的子领域之一（汇编 38 案）。
>
> **stance 适用**：employer / employee 双视角。
> **判例支撑**：汇编 3.6 保密 4 案 + 3.7 竞业限制 38 案，共约 42 案。
> 详见 `case-database/ch3-contract-formation-and-performance.md` § 3.6 + § 3.7。

---

## 一、法理框架

### 1.1 法律依据

《劳动合同法》§23、§24 + 《最高人民法院关于审理劳动争议案件适用法律若干问题的解释（一）》（原司法解释四）：

- §23(1)：用人单位与劳动者可以在劳动合同中约定保守用人单位商业秘密和与知识产权相关的保密事项
- §23(2)：用人单位可以与负有保密义务的劳动者约定竞业限制 + 离职后按月支付经济补偿
- §24：竞业限制人员范围限于高级管理人员、高级技术人员和其他负有保密义务的人员；期限不超过 **2 年**

### 1.2 保密 vs 竞业限制的关键区别

| 维度 | 保密义务 | 竞业限制义务 |
|---|---|---|
| 期限 | 无明文限制，按合同约定 | 离职后不超过 2 年 |
| 人员范围 | 所有接触商业秘密的劳动者 | 仅 §24 规定的高管 / 高技 / 保密人员 |
| 对价 | 无（劳动报酬包含）| 离职后按月支付经济补偿（义务对价）|
| 违约责任 | 实际损失为主 | 违约金（兼具补偿与惩罚） |
| 在职阶段 | 当然存在 | 一般不约定（除非有特殊约定）|

## 二、竞业限制协议的效力（"effectiveness gate"）

### 2.1 主体资格要件 —— 必须是 §24 规定人员

case 3.7.9 实业公司诉赵某：

> 法律仅规定对负有保密义务等特定的劳动者，用人单位才可以与之订立竞业限制协议。用人单位不能证明劳动者属于保密人员或者能够接触、掌握商业秘密，其与劳动者订立的竞业限制协议应属**无效**。

**实务推论**：单位与普通劳动者签订竞业限制 → 无效。即便已支付经济补偿，劳动者**仍可不履行**且**不必返还**已收补偿。

### 2.2 协议形式要件 —— 必须个别协商

case 3.7.10 郭某诉资管北分：

> 竞业限制条款的本质是契约，应当由用人单位与劳动者在平等协商的基础上，建立真实的合意，**而不能通过规章制度等形式确定**。

实务推论：单位以"规章制度"或"员工手册"形式批量适用竞业限制 → 对未签个别协议的劳动者无约束力。

### 2.3 经济补偿对价要件 —— 法定基准 vs 约定基准

**法律规定**（司法解释一原四 §6）：约定未明确时按解除前 12 个月平均工资的 **30%** 按月支付（不得低于当地最低工资标准）。

**案例反映的地区分歧**：

| 案例 | 立场 | 备注 |
|---|---|---|
| case 3.7.7 夏某诉基金公司（扬州）| 经济补偿低于法定基准 → 协议对劳动者**不具有约束力** | 与南京立场不一致 |
| 其他地区主流 | 经济补偿低于法定基准 → 劳动者可要求**补足**，协议仍有效 | 主流 |

实务推论：扬州地区单位需特别注意补偿数额；其他地区可补足。

### 2.4 协议条款的法定边界

case 3.7.12 某科技公司诉李某：

> 竞业限制协议约定对外投资非竞争性公司也应支付违约金的条款，**扩大了竞业限制的法定范围，应属无效**。

实务推论：竞业限制协议条款超出"与本单位有竞争关系的单位 / 业务"范围的部分无效；其他部分仍可执行。

## 三、违约行为认定

### 3.1 直接违约形式

| 行为类型 | 是否违约 | 判例 |
|---|---|---|
| 直接入职竞争对手 | 是 | case 3.7.31、3.7.20 |
| 入职竞争对手的下属单位 | 是 | case 3.7.31 |
| 在竞争公司担任实际控制人 | 是 | case 3.7.19 |
| 同时担任两家公司高管经营类似业务 | 是 | case 3.7.25 |
| 在职期间设立竞争公司 | 是 | case 3.7.16 |
| 教育培训机构离职去同业机构 | 是 | case 3.7.15 |

### 3.2 变相 / 间接违约形式（重要判例）

case 3.7.18 刘某诉某化学公司：

> 负有竞业限制义务的劳动者，虽然没有与其他竞争单位签订劳动合同，但是以**承揽、承包、入伙、代理、顾问**等变相行为为竞争单位提供服务的，也属于违反竞业限制约定的行为，原用人单位有权请求劳动者承担违约责任。

case 3.7.11 某齿轮制造公司诉刘某：

> 劳动者通过**业务外包或者劳务派遣**等方式在新用工单位从事与原用人单位同类业务的，应认定其违反竞业限制义务。

实务推论：竞业限制规避的常见手法（顾问、外包、派遣、亲属代持）均被司法识破；劳动者不得通过形式手段规避实质义务。

### 3.3 在职期间竞业限制

case 3.7.13 陶香志诉创新包装、case 3.7.14、3.7.17、3.7.29：

> 用人单位可以与其高级管理人员、高级技术人员和其他负有保密义务的劳动者，在劳动合同或者保密协议中约定保密条款和竞业限制条款。负有保密义务的劳动者**在职期间**违反竞业限制约定的，用人单位有权请求劳动者按照约定支付违约金。

**特殊规则 —— 在职期间无需经济补偿**（case 3.7.14）：

> 劳动者在职期间本身已享有劳动报酬作为生存保障，其就业权和生存权并不因履行在职期间竞业限制义务而遭受损害，故在没有明确约定的情况下，用人单位无需支付劳动者在职期间竞业限制经济补偿。

### 3.4 高管的"忠实义务"叠加

case 3.7.17 徐某诉某环保公司、case 3.7.36 薛某诉某食品公司：

> 公司高管在用人单位具有特殊地位，属于"特殊的劳动者"。无论是在公司法律体系下，还是在劳动法律体系下，高管对公司均负有忠实义务。高管未遵守在职期间竞业限制约定，利用职务便利进行利益输送，损害了用人单位的合法利益，用人单位有权解除劳动合同。

case 3.7.12 某科技公司诉李某：在职期间对外投资第三方公司未披露 + 间接承接其用人单位订单 → 即便未损害竞争优势，也违反忠实义务 + 基本诚信原则。

## 四、违约责任

### 4.1 违约金的性质 —— 补偿 + 惩罚双重

case 3.7.25 刘某诉安迅公司：

> 竞业限制违约金兼具补偿和惩罚性质，目的在于预防商业秘密被泄露，**并不必然以用人单位遭受实际损失为前提**。

case 3.7.26 毕某诉培训学校：

> 竞业限制违约金兼具补偿和惩罚性质，故在补偿守约方的同时应当适当对违约方予以惩罚，但**一般不超过实际损失的 30%**。

实务推论：违约金 = 实际损失 + 适度惩罚（一般惩罚部分不超过损失的 30%）。

### 4.2 违约金调整规则 —— 综合考量

**调整因素**（case 3.7.20、3.7.22、3.7.31）：

1. 劳动者的主观恶意程度 / 过错程度
2. 违约行为持续时间
3. 给原用人单位造成的实际损失
4. 劳动者的工资标准 / 收入水平
5. 在原用人单位的从业时间
6. 竞业限制经济补偿标准
7. 用人单位有无采取减损措施
8. 劳动者有无采取弥补措施

**举证责任**（case 3.7.27 王某诉文化传媒）：

> 劳动者作为违约方主张竞业限制违约金约定标准过高的，应当承担相应的举证证明责任。

**调整幅度** —— 不应过低（case 3.7.28 潘某诉某公司）：

> 当事人主张竞业限制违约金约定标准过高的，人民法院可以依法调整，但调整幅度应当适度，**不应将违约金调整至过低**。

### 4.3 继续履行规则

case 3.7.21 某建材销售中心诉彭某、case 3.7.32 某精蜡公司诉刘某：

> 劳动者违反竞业限制约定的，应当按约向用人单位支付违约金。**劳动者支付违约金后，其剩余期限内的竞业限制义务并不因此而免除**，用人单位请求劳动者继续履行竞业限制约定的，应予支持。

实务推论：违约 → 既支付违约金 + 又继续履行剩余期限。这是 employer 维权的双重武器。

### 4.4 违约责任的多元形式

case 3.7.20、3.7.33（腾讯科技诉徐某）：

> 当事人可以约定违约责任的承担方式，**不以金钱给付为限**。用人单位及其关联企业与劳动者设立的竞争单位合作，**不能当然免除**劳动者因违反竞业限制义务而需承担的违约责任。

case 3.7.33 重要规则：

> 用人单位在负有竞业限制义务的劳动者**在职期间，通过第三方发放了竞业限制经济补偿**，可以在劳动者违约时主张违约责任。

## 五、竞业限制的解除

### 5.1 单位单方解除权

case 3.7.36 贺欣诉清控科创、case 3.7.37 北京法意科技：

> 用人单位在竞业限制期限内，向劳动者送达不再要求劳动者履行竞业限制义务的通知，应认定竞业限制协议已由用人单位提出解除，**该解除行为生效不以劳动者同意为前提**。

**劳动者额外补偿权**：单位行使单方解除权时，劳动者**有权主张额外 3 个月经济补偿**（司法解释一原四 §9），但无权要求继续履行。

case 3.7.34 赵育森诉必佳乐（江苏立场，规则有调整 → 已按司法解除处理）：

> 用人单位在竞业限制期限届满前有权单方解除竞业限制，但应在合理期限内提前通知劳动者，给予劳动者自由择业的准备期。对劳动者已履行的竞业限制期间，用人单位应按竞业限制条款约定的标准给予相应的经济补偿。

### 5.2 劳动者单方解除权（3 个月未付补偿）

case 3.7.35 乐某诉某银行、case 3.7.38 姜某诉博恩公司：

司法解释一原四 §8 规则：

> 当事人在劳动合同或者保密协议中约定了竞业限制和经济补偿，劳动合同解除或者终止后，因用人单位的原因导致**三个月未支付经济补偿**，劳动者请求解除竞业限制约定的，应予支持。

case 3.7.38 关键规则：

> 当事人未约定竞业限制经济补偿的数额和支付方式，不能成为劳动者免除竞业限制义务的事由。因用人单位原因导致 3 个月未支付经济补偿的，劳动者可以**不经催告**程序直接行使解除权。

实务推论：单位 3 个月未付补偿 → 劳动者**无需催告**直接突破竞业限制 → 单位无权主张违约责任。

### 5.3 默示解除规则

case 3.7.6（自动失效条款）：

> 双方签订了竞业限制协议，同时约定用人单位将在劳动者离职后 3 个月内通知劳动者是否需要履行竞业限制，如果未通知则视为无效。因合同效力不属于可由当事人约定的事项，为维护合同稳定并保护守约方利益，**应将无效理解为解除**。

case 3.7.8 蔡某诉麒麟公司：

> 用人单位在劳动者离职时根据劳动者自行填写的离职去向，决定不再要求劳动者履行竞业限制协议的，**竞业限制协议因此解除**。劳动者此后未按填写的离职去向执行，而是入职竞争单位的，不影响竞业限制协议已经解除的认定，用人单位无权请求劳动者承担违约责任。

实务推论：单位主动放弃 / 默示解除竞业限制后，**反悔无效**。

## 六、保密义务专题

### 6.1 保密协议的有效性

case 3.6.3 数据公司诉沈某（薪酬保密案）：

> 薪酬保密制度旨在防止员工之间相互攀比和恶性竞争，一般适用于工作成效难以具体量化考核的岗位和享受特殊待遇或者高薪引进的人才，**不能对依法享有同工同酬权利的基础性岗位"一刀切"适用**。

实务推论：保密制度需要与岗位 / 内容性质相匹配，超出合理范围的部分无效。

### 6.2 在职期间保密义务

是劳动者的**固有义务**（基于诚信原则 + 忠实义务），不需要额外约定。违反时单位可主张：

- 解除劳动合同（依 §39(3) 严重失职、营私舞弊）
- 损害赔偿（依《反不正当竞争法》§9 / 《民法典》侵权责任编）
- 违约金（如有书面约定）

### 6.3 离职后保密义务

- 期限：按合同约定，但商业秘密本身的法定保护期延续至公开为止
- 范围：限于**与履职直接相关**的商业秘密 + 知识产权
- 不能扩大到与履职无关的事项

## 七、典型成本路径

### 7.1 employer 视角

**追究劳动者违约责任**：

| 操作 | 收益 |
|---|---|
| 严格按 §24 主体范围 + 个别协商 + 法定补偿对价 → 协议有效 | 违约金 + 继续履行 |
| 主体不适格 / 形式不当 / 补偿不足 → 协议无效 | 损失 + 协议无效率 ≈ 50%+ |
| 在职期间违约（高管 / 高技 / 保密人员）| 违约金 + 解除劳动合同（不需补偿）|

### 7.2 employee 视角

**对抗竞业限制主张**：

| 攻击点 | 胜诉率 |
|---|---|
| 主体不适格（普通员工）| 高 |
| 范围超出法定（如限制非竞争性业务）| 高 |
| 单位 3 个月未付补偿 → 直接突破 | 高 |
| 单位默示解除（如根据离职去向决定不要求履行）| 高 |
| 补偿过低（扬州 / 部分地区）| 中 |
| 违约金过高，主张调整 | 中 |

**已违约后的补救**：

| 情形 | 后果 |
|---|---|
| 直接入职竞争对手 | 违约金 + 继续履行 |
| 通过承揽 / 顾问 / 派遣等变相方式 | 被识破，违约金 + 继续履行 |
| 已支付部分违约金后想免除剩余期限 | 不能（case 3.7.21、3.7.32）|
| 用人单位已采取减损措施 | 违约金可调低 |
| 自身主动采取弥补措施（停止竞争行为）| 违约金可调低 |

## 八、关键策略

### 8.1 employer 操作清单

**协议签订阶段**：

1. **限定主体**：仅与 §24 规定人员签订（高管 / 高技 / 保密人员），普通员工不签
2. **个别协商**：必须书面签订独立协议或劳动合同中明确条款，不通过规章制度推定
3. **明确范围**：竞业限制范围限于**与本单位有竞争关系的单位 / 业务**，不扩大到非竞争性投资
4. **法定补偿**：按月支付不低于解除前 12 个月平均工资 30%（或更高）
5. **违约金合理化**：综合考量薪酬、岗位、竞争风险确定数额（不要漫天要价）

**履行阶段**：

1. **按时按额支付补偿**（避免 3 个月未付的解除风险）
2. **监控履行情况**（关注劳动者新就业去向、关联企业、第三方关系）
3. **必要时单方解除**（业务调整、商业秘密公开等）：书面通知 + 支付额外 3 个月

**违约救济**：

1. **证据准备**：劳动者就业证据（社保查询、工资流水、对外公告）、新单位的竞争关系证据、关联关系证据
2. **请求权设计**：违约金 + 继续履行（剩余期限）+ 损失赔偿（超出违约金的部分）
3. **诉前禁令**（部分地区可申请）

### 8.2 employee 操作清单

**入职时**：

1. **审查竞业限制条款**：主体适格？范围是否过宽？补偿是否充足？
2. **拒绝过宽条款**：限制范围超出与本单位有竞争关系的部分 → 提出修改
3. **避免规章制度推定**：要求单独签订书面协议或劳动合同中明确条款

**离职时**：

1. **明确单位态度**：是否要求履行竞业限制？补偿数额？支付方式？
2. **取得书面确认**：单位明示要求履行的，索取书面通知；单位放弃的，索取书面放弃声明
3. **保留离职去向证据**：避免后续争议（case 3.7.8）

**离职后**：

1. **按时收取补偿**：未按时收到 3 个月 → 直接突破，无需催告
2. **就业选择**：避开直接竞争对手；间接竞争 / 顾问 / 派遣同样被识破；上下游不构成竞争
3. **争议出现时**：主张主体不适格 / 范围过宽 / 补偿过低 / 单位默示解除 / 单位违约在先

## 九、关键证据策略

### 9.1 employer 证据清单

| 证据 | 证明目的 |
|---|---|
| 劳动者岗位职责书 / 工作内容 | 主体适格（接触商业秘密）|
| 单独签订的竞业限制协议 | 形式要件 |
| 经济补偿支付凭证（按月）| 履行义务 |

| 新单位 vs 原单位的业务关系证据 | 竞争关系 |
| 关联关系 / 实控关系证据 | 变相违约 |
| 单位的损失证据 | 违约金对应损失 |
