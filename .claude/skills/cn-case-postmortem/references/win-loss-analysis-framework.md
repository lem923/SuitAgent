# 胜败原因分析框架（5 维度）

## 总原则

胜败原因分析的目的是**归因系统化经验**，不是事后诸葛亮，不是责任追究。

每维度评估遵循 3 步：
1. 客观描述事实
2. 评估对结果的贡献度
3. 提取可复用经验

## 维度 1：法律层

**评估问题**：

| 子问题 | 评估 |
|-------|------|
| 1. 我方请求权基础是否被法庭 / 仲裁庭采纳？ | 是 / 否 / 部分 |
| 2. 我方援引法条是否准确无误？ | 是 / 否 |
| 3. 法庭对法律的解释是否符合主流观点？ | 是 / 否 |
| 4. 是否存在法律层面的盲点（未援引的法条 / 司法解释 / 判例）？ | 是 / 否 + 具体 |
| 5. 法律层面的不确定性（如新法 / 罕见案件 / 地方差异）如何处理？ | 充分 / 不足 |

**贡献度评估**：
- 法律层是核心胜诉驱动 / 核心败诉驱动？
- 法律层的胜势 / 劣势对最终结果的影响百分比（粗略估计 0-100%）

**可复用经验**：
- 类案中**确定性的法律基础**有哪些
- 类案中**易出现争议的法条解释**有哪些
- 该法域 / 该案由的**法庭倾向**

## 维度 2：事实层

**评估问题**：

| 子问题 | 评估 |
|-------|------|
| 1. 核心事实是否被法庭查明？ | 是 / 否 |
| 2. 我方核心事实是否有证据支撑？ | 是 / 否 / 部分 |
| 3. 我方证据三性（真实 / 合法 / 关联）是否充分？ | 是 / 否 |
| 4. 证据组合策略是否有效？ | 是 / 否 |
| 5. 是否存在事实盲点（未取得 / 未质证的关键证据）？ | 是 / 否 + 具体 |

**贡献度评估**：
- 事实层是核心驱动？
- 哪些事实最影响结果？

**可复用经验**：
- 类案中**最关键的事实类型**
- 类案中**易缺失的证据**及其取得路径
- **证据保全 / 公证 / 区块链**等加固手段的使用经验

## 维度 3：程序层

**评估问题**：

| 子问题 | 评估 |
|-------|------|
| 1. 我方是否充分运用了程序权利（管辖异议 / 回避申请 / 证据保全申请等）？ | 是 / 否 |
| 2. 我方是否完整履行了程序义务（举证期限 / 答辩期限）？ | 是 / 否 |
| 3. 程序瑕疵（如有）是否被及时纠正？ | 是 / 否 / 不适用 |
| 4. 关键时点是否管理到位？ | 是 / 否 |
| 5. 程序对手的动作（对方申请保全 / 调查取证）是否被有效应对？ | 是 / 否 |

**贡献度评估**：
- 程序层是否影响实体结果？

**可复用经验**：
- 类案中**程序权利运用清单**
- 类案中**易错过的程序节点**

## 维度 4：策略层

**评估问题**：

| 子问题 | 评估 |
|-------|------|
| 1. 诉讼策略（进攻 / 防守 / 折中）选择是否正确？ | 是 / 否 |
| 2. 调解 / 和解时机选择是否正确？ | 是 / 否 / 不适用 |
| 3. 庭审策略（证据出示顺序 / 辩论重点）是否有效？ | 是 / 否 |
| 4. 关键决策（如反诉 / 上诉 / 申请再审）是否正确？ | 是 / 否 |
| 5. 与对方律师的攻防节奏是否合理？ | 是 / 否 |

**贡献度评估**：
- 策略层是否决定结果？

**可复用经验**：
- 类案中**最优策略路径**
- 类案中**避免的策略陷阱**

## 维度 5：资源层

**评估问题**：

| 子问题 | 评估 |
|-------|------|
| 1. 律师投入工时是否充分？ | 是 / 否 + 具体（参考工时记录.md） |
| 2. 客户配合度（提供材料 / 决策时效）如何？ | 优 / 良 / 中 / 差 |
| 3. 第三方资源（鉴定 / 证人 / 翻译 / 公证 / 调查取证）是否到位？ | 是 / 否 / 不适用 |
| 4. 律所内部协作（合伙人审阅 / 同事协助）是否充分？ | 是 / 否 |
| 5. 客户方资源（关联文件 / 内部证人 / 行业知识）是否被利用？ | 是 / 否 |

**贡献度评估**：
- 资源层是否影响结果？

**可复用经验**：
- 类案的**最低工时投入**
- 类案的**关键第三方资源**

## 综合归纳模板

```markdown
## 综合归纳

本案胜负的核心驱动因素（按贡献度降序）：

| 排名 | 维度 | 因素描述 | 贡献度估计 | 性质 |
|-----|------|---------|----------|------|
| 1 | [法律 / 事实 / 程序 / 策略 / 资源] | [简明描述] | XX% | [我方胜势 / 对方胜势 / 中性] |
| 2 | ... | ... | ... | ... |

**结论**：本案以 [描述结果] 结案，主要因 [核心驱动因素]。
[Bonus：如果时间倒流，律师团队会改变 X / Y / Z]。
```

## 反事实推演

复盘的关键技巧——**反事实推演**：

针对 2-3 个最关键的决策点，假设当时选了不同选项，推演可能结果：

```markdown
### 反事实：如果决策点 X 选了 [其他选项]

- 直接后果：[案件走向变化]
- 二次后果：[随后衍生影响]
- 最终结果：[案件结果如何不同]
- 概率估计：[反事实结果的概率，如"60%-70%"]
```

反事实推演有助于：
- 验证决策合理性（即使当时选错，事后可能也是错的，说明信息盲点）
- 提取教训（避免在同类决策点犯错）

## 禁忌

- ❌ "如果当时再努力一点就会赢" —— 缺乏可操作的归因
- ❌ "对方律师不专业" —— 推卸性归因，且无客观证据时不成立
- ❌ "法官有偏见" —— 同上，且涉及职业伦理边界
- ❌ "客户没听律师的" —— 复盘的目标不是评判客户，而是改进律师工作流
- ❌ "都是运气问题" —— 复盘失败，说明分析不到位
