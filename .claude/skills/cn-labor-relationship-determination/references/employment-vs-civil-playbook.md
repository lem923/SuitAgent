# 劳动关系 vs 民事关系（劳务 / 承揽 / 合作）Playbook

> 最常见的认定争议：单位与个人之间是劳动关系还是劳务 / 承揽 / 合作？
>
> 判例支撑：汇编第二章 2.2 + 2.5 共约 80 案。详见 `case-database/ch2-relationship-determination.md`。

## 一、典型情形 vs 认定结论

| 情形 | 司法倾向 | 关键事实 |
|---|---|---|
| 长期月薪 + 考勤管理 + 业务核心岗位 | 劳动关系 | 三要素齐备 |
| 项目结算 + 自主时间 + 一次性工作 | 民事承揽 | 弱从属性 + 独立完成 |
| 短期劳务 + 按时 / 按件付费 | 劳务关系 | 临时性 + 独立性 |
| 公司高管 + 持股 | 视具体情形 | 区分股东身份 vs 雇员身份 |
| 加盟商 / 经销商 | 民事合作 | 自主经营 + 自负盈亏 |
| 平台从业者 | 阶梯认定 | 详见 platform-economy-playbook |
| 退休返聘 | 劳务关系 | 主体资格 |
| 在校学生（勤工俭学）| 一般劳务 | 主体资格 |
| 在校学生（毕业实习）| 视实习性质 | 区分顶岗实习 vs 教学实习 |

## 二、典型判例

### 2.1 长期合作但合同标签为"劳务"

**案例特征**：

- 双方签订《劳务协议》
- 实际履行：接受考勤、加班审批、绩效考核
- 报酬按月发放 + 包含奖金 + 由单位代扣个税
- 工作内容为单位核心业务岗位（如销售、客服、技术）

**司法认定**：劳动关系（事实优于形式）。

**实务推论**：单位用"劳务"标签规避劳动法义务的做法在司法上失败率极高。

### 2.2 强从属性的承包人

**案例特征**：

- 承包合同载明"独立承包，自负盈亏"
- 实际履行：受单位严格管理 / 考勤 / 考核
- 报酬实质为月薪而非承包收益
- 承包风险实质由单位承担

**司法认定**：劳动关系（穿透形式审查实质）。

**实务推论**：班组承包、生产线承包等内部承包安排，如未实质转移经营自主权 + 风险承担 → 仍构成劳动关系。

### 2.3 真正的独立劳务

**案例特征**：

- 双方签订《承揽合同》或《劳务协议》
- 自主决定工作时间、地点、方法
- 按项目 / 工时结算
- 可同时承接其他单位业务
- 不接受考勤管理

**司法认定**：劳务 / 承揽关系。

**实务推论**：真正的独立咨询师、自由职业者、专业服务提供者属于民事关系。

## 三、典型成本路径

### 3.1 employer 视角

| 现状 | 风险 |
|---|---|
| 签"劳务合同" + 事实是劳动关系 | 补缴社保 + 经济补偿 + 二倍工资（未签劳动合同）+ 工伤 / 病假责任 |
| 签"承包合同" + 事实是劳动关系 | 同上 |
| 真正独立劳务 + 合同条款规范 | 无劳动法责任 |
| 派遣 + 用工不规范 | 详见 labor-dispatch-playbook |

### 3.2 employee 视角

| 主张 | 收益 |
|---|---|
| 主张存在劳动关系（实际是劳务）| 工伤保险 / 经济补偿 / 二倍工资 |
| 主张不存在劳动关系（实际是劳动）| 适用诉讼时效短 + 普通民事程序 |

## 四、操作要点

### 4.1 employer

**如想避免劳动关系认定**：

1. 合同条款规范：明确独立性、风险承担、自主性
2. 实际履行匹配合同：不施加考勤、考核、规章管理
3. 报酬方式：按项目 / 工时 / 成果结算，开具发票
4. 不要将"劳务"人员纳入员工管理体系
5. 提供工具 / 设备需明确为必要性而非身份性

**如要追究"个人劳动者"责任**：

1. 主张劳动关系不成立 → 走民事程序
2. 关键证据：合同明确独立性 + 报酬支付方式 + 自主性证据

### 4.2 employee

**主张劳动关系存在**：

1. 收集初步证据：工资流水、工作证、考勤、招聘记录、证人证言
2. 主张单位掌握的证据未提供 → 不利后果
3. 时效注意：1 年仲裁时效（争议发生日）

**主张劳务关系**：

1. 证据：合同明确独立性 + 报酬按项目结算 + 自主性
2. 适用普通民事时效（一般 3 年）
3. 走民事程序（劳务报酬纠纷 / 服务合同纠纷）

## 五、关键证据

### employer 证据清单

| 证据 | 证明目的 |
|---|---|
| 合同文本 | 关系性质 |
| 报酬支付凭证（含发票 / 银行流水）| 支付方式（项目 vs 工资）|
| 工作时间安排证据 | 自主性 |
| 业务关联性证据 | 是否单位业务组成 |
| 劳动者同时承接其他业务证据 | 非专属性 |

### employee 证据清单

| 证据 | 证明目的 |
|---|---|
| 工资银行流水 + 工资条 | 按月定额 + 包含社保 / 福利 |
| 工作证 / 工牌 / 名片 | 身份关联 |
| 考勤记录 | 管理从属性 |
| 招工登记表 / 入职表 | 入职程序 |
| 工作沟通记录（邮件、微信、钉钉）| 接受工作安排 |
| 同事证言 | 业务组成 |
| 单位规章制度（员工手册）适用于劳动者 | 接受管理 |
