# 平等就业权与就业歧视

> 涵盖性别歧视、地域歧视、健康歧视等就业歧视的认定与救济。
> 判例支撑：汇编 2.1(A)(B) 平等就业权 + 缔约过失。

## 一、法律依据

- 《劳动法》§3 第 2 款（平等就业权）
- 《妇女权益保障法》§22-§43
- 《就业促进法》§3、§25-§30
- 《残疾人保障法》

## 二、就业歧视的类型

### 2.1 性别歧视

case 2.1.1 邓某诉某速递公司、某劳务公司：

性别歧视典型情形：

- 招聘条件限制性别
- 拒绝录用 / 提供较差待遇
- 怀孕女职工辞退
- 婚育状况提问

### 2.2 地域歧视

招聘公告或实际录用中限制户籍地、居住地的歧视行为。

### 2.3 健康歧视

- 乙肝歧视（《就业促进法》§30 明确禁止）
- 残疾歧视（case 5.5.18）
- 其他基于健康的歧视

### 2.4 其他歧视

- 年龄歧视
- 学历歧视（依法允许的招聘条件除外）
- 民族 / 宗教歧视

## 三、平等就业权侵害的救济

### 3.1 缔约过失责任

case 2.1(B)：

特征：

- 招聘单位已发出录用通知 / 已达成实质合意
- 劳动者已为入职做准备（辞职、搬迁、放弃其他机会等）
- 单位无正当理由撤回录用 / 不予录用

司法救济：

- 信赖利益损失（如已辞职而新工作落空的损失）
- 准备成本（搬迁费、培训费等）

### 3.2 就业歧视救济

- 平等就业权侵权诉讼（民事程序）
- 赔偿损失 + 精神损害抚慰金
- 申请人社部门调查处理（行政程序）

## 四、操作要点

### 4.1 用人单位

1. **招聘条件合法化**：性别、户籍、健康等限制必须有法律依据
2. **录用程序规范化**：录用通知发出后慎重撤回（已构成实质合意）
3. **入职审查程序化**：体检等审查程序与招聘脱钩

### 4.2 求职者 / 劳动者

1. **保留歧视证据**：招聘公告、面试录音、邮件、聊天记录
2. **保留入职准备证据**：辞职证明、搬迁费票据、其他放弃机会的证据
3. **维权路径选择**：
   - 直接起诉平等就业权侵权（民事）
   - 申请人社部门调查
   - 主张缔约过失（如已发录用通知后撤回）
