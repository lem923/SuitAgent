# 特殊主体认定

> 处理超龄、境外、在校学生、股东高管、承包挂靠等特殊主体的关系性质认定。
> 判例支撑：汇编 2.2(A)(B)(C)(D)(E) + 2.5(B)(D) 系列。

## 一、超龄就业（退休返聘）

### 1.1 基本规则

- 达到法定退休年龄 + 已享受养老保险待遇 → **劳务关系**（《劳动合同法实施条例》§21）
- 达到法定退休年龄 + 未享受养老保险待遇 → **司法分歧**：
  - 部分地区（如江苏）：仍可成立劳动关系
  - 部分地区：劳务关系

### 1.2 法定退休年龄

- 女工人 50 周岁、女干部 55 周岁、男 60 周岁
- 特殊工种可提前
- 高级专家可延迟

### 1.3 退休返聘的特别问题

- 工伤认定不适用《工伤保险条例》（按一般人身损害民事赔偿处理）
- 不缴纳社保
- 不能主张二倍工资、经济补偿
- 但仍享有报酬权 / 休息权（基础人身权）

## 二、境外劳动者

### 2.1 外籍劳动者

- 必须取得《外国人就业许可证》《外国人就业证》 + 居留证件
- 无合法证件的就业 → 劳务关系或不法行为
- 已获证件 → 适用劳动法（部分地区在涉外用工上有特别规定）

### 2.2 港澳台劳动者

- 简化手续后多按内地劳动法适用
- 部分地区给予就业便利

## 三、承包、合作、挂靠

### 3.1 内部承包

特征：单位将本单位的部分工作发包给本单位员工（如班组承包、生产线承包）。

司法认定：

- 形式上承包，实质上仍是劳动 → 劳动关系
- 真正独立承包（自负盈亏 / 自主经营）→ 民事承包

### 3.2 业务外包

特征：单位将业务承包给独立的第三方公司或个人。

司法认定：

- 外包对象是合法独立的公司 → 不构成劳动关系
- 外包对象是个人（无独立法人资格） → 视为单位用工责任

### 3.3 挂靠

特征：个人借用单位资质或营业执照从事经营。

司法认定：

- 挂靠人是真正的经营者 + 挂靠单位仅收取管理费 → 不构成劳动关系
- 挂靠人受单位管理 + 实质从事单位业务 → 劳动关系

## 四、股东、高管、法定代表人

### 4.1 自然人股东

- 股东持有股权 ≠ 排除劳动关系
- 关键看是否提供劳动 + 是否接受公司管理

### 4.2 法定代表人

case 2.2.25：

> 法定代表人与用人单位签订了劳动合同，参与公司管理并接受公司约束，双方之间符合劳动关系特征的，应认定双方之间形成劳动关系。

实务推论：法定代表人可同时是劳动者。

### 4.3 公司高管

- 普通高管（总经理、副总、部门负责人）→ 一般构成劳动关系
- 兼任董事的高管 → 区分董事职务（公司法）vs 经营职务（劳动法）

### 4.4 兼任董事

- 仅任董事 + 不参与日常经营 → 委任关系（公司法），非劳动关系
- 兼任董事 + 同时担任经营管理职务 → 二重身份，劳动法保护经营职务部分

## 五、实习生 / 勤工俭学

### 5.1 在校学生勤工俭学

- 在校全日制学生（含本科、研究生、博士生）→ 通说为劳务关系
- 教育部《关于加强普通高等学校学生勤工助学活动管理的若干意见》明确：勤工助学不属于就业

### 5.2 毕业实习

- 临近毕业 + 顶岗实习（与正式员工同岗位 / 同工作）→ 部分地区认定为劳动关系
- 教学实习（学校组织 / 短期）→ 不构成劳动关系

### 5.3 试用期 vs 实习期

- "试用期"是劳动关系内的概念 → 适用劳动法
- "实习期"通常是学生身份 → 劳务关系

## 六、其他特殊情形

### 6.1 受聘律师

- 律师事务所与受聘律师 → 多数地区认定劳动关系
- 提成律师 / 独立律师 → 部分地区认定为合作关系

### 6.2 出租车司机

- 公司聘用模式 → 劳动关系
- 单车承包 → 司法分歧
- 真正个体工商户 → 民事关系

### 6.3 保险代理人

- 通常不构成劳动关系（视为代理合同）
- 但实质上接受公司严格考核 + 排他性 + 培训管理 → 可主张劳动关系

### 6.4 物业管理员

- 通常构成劳动关系

### 6.5 个人 vs 包工头

- 包工头实质为农民工的"中间人" → 单位仍承担用工责任（《建设工程司法解释》）
