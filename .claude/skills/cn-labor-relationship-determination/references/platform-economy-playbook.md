# 平台经济 / 新就业形态 Playbook

> 处理外卖骑手、网约车司机、平台主播、众包从业者等平台经济从业人员的关系认定。
> 判例支撑：汇编 2.2(D) + 2.5(C) 新就业形态共约 15-20 案。

## 一、政策背景

### 1.1 主要法规

- 《关于维护新就业形态劳动者劳动保障权益的指导意见》（人社部发〔2021〕56号）
- 多地试点 "不完全劳动关系" 认定标准（北京 / 广东等）
- 平台从业者职业伤害保障试点

### 1.2 三阶梯认定（人社部 56 号指导）

```
完全劳动关系
    · 算法强管理（接单 / 定价 / 惩罚均由平台控制）
    · 长期全时 + 业务为平台核心
    · 平台为唯一收入来源
    · 须签订劳动合同 + 适用劳动法全部保护

不完全劳动关系
    · 灵活就业 + 部分算法管理
    · 兼职性质 + 多平台并存
    · 接单自主权部分保留
    · 适用：休息休假 + 最低工资 + 职业伤害保障（部分地区试点）

民事合作关系
    · 完全自主接单 + 自主定价
    · 真正个体工商户 / 灵活就业者
    · 平台仅撮合服务
    · 适用民事法律保护
```

## 二、典型从业者认定

### 2.1 外卖骑手

| 模式 | 认定倾向 |
|---|---|
| 与外卖公司直接签订劳动合同（直营骑手）| 劳动关系 |
| 与外卖公司签订劳务 / 合作协议 + 实质强管理 | 部分认劳动 / 部分认不完全劳动关系 |
| 与外卖公司无任何合同 + 通过 App 接单 | 民事 / 不完全劳动关系（视情）|
| 与劳务公司签劳动合同 + 派遣到外卖公司 | 劳务派遣 |
| 与众包合作公司签协议 + 接单 | 民事合作 |
| 个人完全自主接单（如部分平台模式）| 民事合作 |

### 2.2 网约车司机

| 模式 | 认定倾向 |
|---|---|
| 与网约车平台公司直接签劳动合同（出租车公司模式）| 劳动关系 |
| 司机自购车 + 平台接单 + 抽成 | 民事合作（多数）|
| 司机租赁平台车 + 平台严格管理 | 视实质 |

### 2.3 直播主播 / 网红

| 模式 | 认定倾向 |
|---|---|
| MCN 机构直接签劳动合同 | 劳动关系 |
| MCN 签合作协议 + 强排他性 + 强管理 | 部分认劳动 |
| 个人独立运营 + 平台仅技术支持 | 民事合作 |

### 2.4 众包人员

特征：通过 App 接收单次任务，完成后获得报酬，不固定。

通常认定：民事关系。

## 三、典型成本路径

### 3.1 employer / 平台视角

| 风险 | 后果 |
|---|---|
| 被认定为完全劳动关系 | 补缴社保 + 未签合同二倍工资 + 经济补偿等 |
| 被认定为不完全劳动关系（试点地区）| 部分劳动保护（休假 / 最低工资 / 职业伤害）|
| 维持民事合作关系 | 仅承担合同 / 侵权责任 |

### 3.2 employee 视角

| 主张 | 收益 |
|---|---|
| 完全劳动关系成立 | 全部劳动法保护（包括经济补偿、工伤等）|
| 不完全劳动关系（试点地区）| 职业伤害保障 + 部分劳动保护 |
| 民事关系 | 仅人身损害赔偿 + 合同违约责任 |

## 四、关键证据 / 事实

### 强劳动关系倾向的事实

- 排他性条款（不得为其他平台服务）
- 强算法管理（接单率、好评率、拒单惩罚）
- 强培训管理（必须参加培训、考试）
- 工装 / 装备由平台提供
- 报酬结构含基础保障（最低收入保障）
- 工作时长由平台决定（如必须在线时长）

### 弱劳动关系倾向的事实

- 完全自主接单
- 可同时为多平台服务
- 收入完全按完成订单结算
- 自购工具 / 设备
- 无任何排他性约束
- 平台仅提供技术撮合

## 五、操作要点

### 5.1 平台 / 用工方

**如想避免完全劳动关系认定**：

1. 合同条款规范：明确合作性质 / 独立性 / 自主性
2. 算法管理控制：避免过度算法管控（接单率不超过合理范围 / 惩罚机制合理化）
3. 不施加排他性约束（允许多平台并存）
4. 报酬结构纯订单制（不设最低收入保障）
5. 不提供工具 / 装备（或仅作为可选）
6. 不进行强制培训

**如适用不完全劳动关系**：

1. 按当地试点要求 + 缴纳职业伤害保障
2. 保障最低劳动报酬
3. 保障基本休息休假

### 5.2 从业者

**主张完全劳动关系**：

1. 证据：排他性、强算法管理、必要培训、报酬基础保障、工装设备等
2. 时效：1 年仲裁时效
3. 收益：劳动法全部保护

**主张不完全劳动关系**（试点地区）：

1. 证据：长期持续 + 业务核心 + 部分管理
2. 收益：职业伤害保障 + 部分劳动保护

**主张工伤 / 职业伤害**：

1. 与关系认定并行处理
2. 详见 cn-labor-insurance-and-injury

## 六、地区分歧

| 地区 | 立场 |
|---|---|
| 北京 | 严格审查 + 多数案件不认定完全劳动关系 |
| 上海 | 中等 + 部分案件认定 |
| 广东 | 平台经济发达 + 案件多 + 立场分化 |
| 江苏 | 严格审查实质从属性 |
| 浙江 | 试点不完全劳动关系认定 |
