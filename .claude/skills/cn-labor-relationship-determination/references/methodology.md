# 核心方法论

## 一、劳动关系三要素详解

### 1.1 要素 A：主体资格

#### 1.1.1 用人单位的合格主体

《劳动合同法》§2 + §93 + 《劳动合同法实施条例》§4：

- 企业、个体经济组织、民办非企业单位、其他组织
- 国家机关、事业单位、社会团体（以聘用合同形式与工作人员建立劳动关系的部分）
- 不具备合法经营资格的用人单位（如未注册个体工商户）— 仍承担责任，由发包人或挂靠人承担

#### 1.1.2 劳动者的合格主体

- **年龄要件**：年满 16 周岁（特殊行业经批准可招用未成年人，如文艺、体育、特种工艺）
- **年龄上限**：未达法定退休年龄（女 50/55、男 60，特殊岗位 / 高级专家可延迟）
- **就业资格**：
  - 在校全日制学生 — 通说为劳务关系（部分地区例外）
  - 外籍劳动者 — 需取得就业证 + 居留证
  - 已退休返聘人员 — 劳务关系（除特殊情形）

### 1.2 要素 B：管理从属性（核心要素）

#### 1.2.1 强从属性指标（满足任一即倾向劳动关系）

- 接受单位规章制度管理（考勤、请假、违纪处分等）
- 服从工作安排、岗位调配
- 接受绩效考核、纪律处分
- 工作时间由单位决定
- 工作地点由单位决定
- 必须穿单位工装 / 佩戴工牌
- 必须使用单位提供的设备 / 工具

#### 1.2.2 弱从属性指标（多个同时存在倾向民事合作）

- 自主决定工作时间
- 自主决定工作地点
- 自主决定工作方法
- 可自由承接其他业务
- 不接受单位考核 / 培训
- 自主提供工具 / 设备
- 报酬按项目 / 成果 / 工时结算

### 1.3 要素 C：业务组成

#### 1.3.1 业务组成的判断

- 劳动是用人单位**主营业务**的组成部分（如外卖配送之于外卖平台、客户服务之于通信公司）
- 劳动是用人单位**辅助业务**但**长期持续**（如某公司的保洁、保安长期由同一人提供）
- 区分于"一次性"劳务（如装修工、临时搬运工）

#### 1.3.2 报酬支付方式

- **工资性**：按月定额 / 含奖金、加班费、社保 / 福利
- **报酬性**：按项目 / 成果 / 工时 / 一次性给付，不含社保 / 福利

## 二、"事实优于形式"原则的应用

### 2.1 适用情形

| 形式 | 事实 | 认定 |
|---|---|---|
| 签订《劳务合同》 | 接受考勤管理 + 月薪 + 业务核心岗位 | **劳动关系** |
| 签订《劳动合同》 | 实际无管理从属 + 项目结算 + 兼职多家 | 可能**名实不符**（但单位仍承担用工责任）|
| 无任何书面合同 | 三要素齐备 | **事实劳动关系** |
| 签订《合作协议》 | 强管理从属 + 月薪 + 核心岗位 | **劳动关系** |
| 签订《承包合同》 | 实质是个人劳动而非独立承包人 | **劳动关系** |

### 2.2 三个常见伪装合同的识别

#### 2.2.1 "劳务合同"伪装

特征：单位与个人签订"劳务"协议，但事实接受考勤、规章管理、长期月薪等。

司法对策：按事实认定为劳动关系（汇编 ch2 系列案例）。

#### 2.2.2 "合作协议"伪装

特征：单位与个人签订"合作"协议，但个人实质从事单位主营业务的常规岗位工作。

司法对策：识别"合作"标签下的劳动关系实质。

#### 2.2.3 "承包合同"伪装

特征：内部承包合同（如班组承包、生产线承包），但承包人实际仍是单位员工身份。

司法对策：审查是否有独立的经营自主权 + 风险承担。

## 三、举证责任分配（关键）

### 3.1 劳动者主张劳动关系成立

劳动者提供初步证据 → 单位反驳举证。

劳动者初步证据范围（劳社部发〔2005〕12号 §2）：

1. 工资支付凭证 / 缴纳社保记录
2. 用人单位向劳动者发放的"工作证"、"服务证"等能够证明身份的证件
3. 劳动者填写的用人单位招用记录，如"招工登记表"、"报名表"等
4. 考勤记录
5. 其他劳动者的证言

其中第 1、3、4 项由单位掌握 → 单位拒不提供承担不利后果。

### 3.2 单位主张不构成劳动关系

单位需证明：

- 劳动者主体资格不合格（超龄、在校学生等）
- 业务关系是劳务 / 承揽 / 合作（无管理从属）
- 已签订其他性质的书面合同 + 实际履行符合合同性质

### 3.3 时效

劳动关系存在确认的仲裁时效：1 年（自争议发生 / 知道或应当知道权利受侵害之日）。

实务陷阱：劳动关系存续期间的确认请求 → 通常不适用一般时效（一般可以随时提起）。

## 四、新就业形态的三阶梯认定

人社部发〔2021〕56号 + 平台经济相关判例：

```
完全劳动关系（适用劳动法全部保护）
    ↑
    · 算法强管理（接单、定价、惩罚均由平台控制）
    · 长期持续 + 全时工作
    · 业务为平台核心业务
    · 平台为唯一收入来源
    ↑
不完全劳动关系（适用部分劳动保护：休息休假 + 基本工资 + 职业伤害保障）
    ↑
    · 灵活就业 + 部分算法管理
    · 兼职性质 + 多平台并存
    · 接单自主权部分保留
    ↑
民事合作关系（仅适用民事法律保护）
    · 完全自主接单 + 自主定价
    · 真正的个体工商户 / 灵活就业者
    · 平台仅提供撮合服务
```

实务判断：

- 外卖骑手 / 网约车司机的"完全劳动关系"主张通常被驳回（多数判例）
- "不完全劳动关系"是新发展方向（多地试点）
- 单纯的灵活就业者（如自由职业者用平台揽客）→ 民事合作

## 五、双重劳动关系的处理

### 5.1 双重劳动关系不被法律明文禁止

但实务认定较严：

- 第一份关系处于停薪留职 / 协保 / 内退状态 → 第二份关系可成立
- 第一份关系正常存续 + 第二份"全职" → 第二份多被认定劳务（除部分例外）

### 5.2 劳务派遣的三方关系

- 派遣单位 + 用工单位 + 劳动者
- 劳动关系：派遣单位与劳动者
- 用工关系：用工单位与劳动者
- 责任划分：详见 labor-dispatch-playbook

### 5.3 混同用工

特征：劳动者表面上与公司 A 签订劳动合同，实际为公司 A、B、C 关联企业混同提供劳动。

司法对策：

- 关联企业共同承担用工责任
- 工作年限合并计算（详见 cn-labor-employment-strategy / severance-agreement-playbook §1.2）

## 六、地区敏感性

| 地区 | 立场 |
|---|---|
| 北京 | 严格三要素审查 + 对新就业形态相对保守（多数仍认定为民事关系）|
| 上海 | 中等 + 协保制度发达 + 双重劳动关系认定相对宽松 |
| 广东 | 平台经济发达 + 对新就业形态有判例突破 |
| 江苏 | 严格管理从属性审查 + 对承包 / 挂靠的实质审查 |
