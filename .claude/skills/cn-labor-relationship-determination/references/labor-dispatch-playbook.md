# 劳务派遣 Playbook

> 处理劳务派遣三方关系（派遣单位 + 用工单位 + 被派遣劳动者）的认定与责任划分。
> 判例支撑：汇编 2.4 劳务派遣相关案例。

## 一、法律依据

- 《劳动合同法》§57-§67
- 《劳务派遣暂行规定》（人社部令第 22 号）
- 各地补充规定

## 二、基本规则

### 2.1 三方关系

```
派遣单位（用人单位）
    ↓ 劳动关系（劳动合同）
    ↓ 工资支付 + 社保缴纳
    ↓
被派遣劳动者 ←-------→ 用工单位
                 用工关系（实际劳动）
                 接受管理 + 工作安排
```

### 2.2 派遣单位的法定义务

- 与劳动者签订两年以上固定期限劳动合同
- 按月支付劳动报酬
- 缴纳社会保险费
- 告知劳动者派遣岗位、被退回的安置等

### 2.3 用工单位的法定义务

- 提供安全的劳动条件
- 告知工作要求和劳动报酬
- 支付加班费、绩效奖金、岗位补贴
- 对在岗被派遣劳动者进行培训
- 连续用工 → 实行正常工资调整机制

### 2.4 三性岗位限制

劳务派遣**只能**在 临时性、辅助性、替代性 岗位上实施：

- 临时性：存续时间不超过 6 个月
- 辅助性：为主营业务岗位提供服务
- 替代性：劳动者因脱产学习、休假等原因暂时无法工作的可由其他劳动者替代

### 2.5 10% 比例限制

用工单位被派遣劳动者数量 ≤ 用工总量的 10%。

## 三、被派遣劳动者的权益保护

### 3.1 同工同酬

被派遣劳动者享有与用工单位相同岗位的劳动者**同工同酬**的权利。

### 3.2 工伤责任

- 工伤认定：以派遣单位为主体
- 工伤待遇：派遣单位承担（用工单位连带）
- 详见 cn-labor-insurance-and-injury

### 3.3 退回机制

用工单位可在以下情形将被派遣劳动者退回派遣单位：

- §40 第 1 项 / 第 2 项情形（医疗期满 / 不胜任）
- §41(1) 情形
- 用工单位被宣告破产 / 吊销营业执照 / 撤销 / 解散等
- 劳务派遣协议期满终止
- 劳动者违反规章制度严重（详见汇编 5.3.15、5.3.16）

退回后的处理：

- 派遣单位重新派遣 / 解除合同
- 派遣单位无新岗位的，按 §40(3) / §41 处理
- 经济补偿由派遣单位承担

## 四、违法派遣的认定与后果

### 4.1 违法派遣的情形

- 超出三性岗位
- 超出 10% 比例
- 派遣单位无资质（未取得劳务派遣经营许可证）
- 用工单位将派遣员工再派遣到其他单位

### 4.2 违法派遣的后果

case 5.3.16 上海永久自行车诉陈某：

> 被派遣劳动者因严重违反用工单位的规章制度而被退回后，劳务派遣单位在无规章制度明确规定的情形下直接解除被派遣劳动者的劳动合同，属于违法解除，被派遣劳动者有权请求劳务派遣单位支付赔偿金。

实务推论：派遣单位不能仅凭"被用工单位退回"直接解除 → 需有自身规章制度依据。

### 4.3 拒绝重新派遣

case 5.2.4 刘明贺诉某派遣 / 启航：

> 被派遣劳动者因劳务派遣协议期满终止等原因被退工后，因不同意接受劳务派遣单位的重新派遣而提出解除劳动合同，如果劳动合同履行方式的变化程度明显未达到导致劳动合同无法继续履行的程度，则该情形不能成为被派遣劳动者依照劳动合同法第三十八条主张解除劳动合同经济补偿的合法理由。

实务推论：被退回后拒绝重新派遣 → 通常不构成 §38 被迫离职。

## 五、典型成本路径

### 5.1 派遣单位视角

| 现状 | 风险 |
|---|---|
| 合规派遣 + 三性 + 10% 内 | 正常运营 |
| 超出三性 / 超 10% | 行政处罚 + 用工单位连带责任 |
| 退回后直接解除 + 无规章依据 | 违法解除 2N |
| 派遣员工社保 / 工资问题 | 派遣单位主要责任 |

### 5.2 用工单位视角

| 现状 | 风险 |
|---|---|
| 同工不同酬 | 被派遣劳动者主张差额赔偿 |
| 退回程序违法 | 连带承担派遣单位违法解除责任 |
| 用工单位违法（如不安全工作环境）| 连带承担派遣单位的劳动法责任 |

### 5.3 被派遣劳动者视角

| 主张 | 收益 |
|---|---|
| 同工同酬差额 | 工资差额追溯 |
| 工伤认定 + 待遇 | 派遣单位为主体 |
| 违法派遣 → 主张事实劳动关系 | 视个案 |
| 用工单位违法 → 选择起诉主体 | 派遣单位 + 用工单位连带 |

## 六、操作要点

### 6.1 派遣单位

1. **取得劳务派遣经营许可证**
2. **严控三性岗位 + 10% 比例**
3. **规章制度规范**：明确处分 / 解除程序
4. **派遣协议条款规范**：与用工单位明确责任划分
5. **同工同酬协调**：与用工单位明确薪酬调整机制

### 6.2 用工单位

1. **岗位审查**：确认派遣岗位符合三性
2. **同工同酬**：与正式员工岗位薪酬保持一致
3. **退回程序**：明确退回原因 + 书面通知
4. **不得违法解除**：退回 ≠ 解除，派遣单位仍需履行劳动法义务

### 6.3 被派遣劳动者

1. **保留劳动合同**（与派遣单位）
2. **保留同岗位正式员工薪酬证据**（同工同酬主张）
3. **退回时关注派遣单位的后续安置**
4. **工伤 / 社保问题 → 找派遣单位主张**
