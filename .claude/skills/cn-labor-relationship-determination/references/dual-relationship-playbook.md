# 双重劳动关系 / 混同用工 Playbook

> 涉及一人多份工作、关联企业混同用工的关系性质认定。
> 判例支撑：汇编 2.3 双重劳动关系 + 关联企业相关案例。

## 一、双重劳动关系的法律地位

### 1.1 不被法律明文禁止

《劳动合同法》§39(4) 仅规定：劳动者同时与其他单位建立劳动关系，对完成本单位的工作任务造成严重影响，或者经用人单位提出，拒不改正的，用人单位可以解除合同。

→ 双重劳动关系不必然违法，但单位可在特定情形下解除。

### 1.2 司法认定的严格性

- 实务认定较严：仅在第一份关系特殊情形下，第二份关系才被认定为劳动关系
- 通常情形下：第一份关系正常存续 + 第二份"全职"工作 → 第二份多被认定劳务

## 二、特殊情形下的双重劳动关系

### 2.1 协保 / 内退 / 停薪留职人员

- 第一份关系：仍在原单位（享受协保 / 内退待遇 / 停薪留职）
- 第二份关系：可成立完整的劳动关系
- 司法立场：明确支持双重劳动关系

### 2.2 退休返聘 + 新单位用工

- 第一份关系：已退休（领取养老金）→ 劳务关系
- 第二份关系：新单位 → 视主体资格（一般为劳务）

### 2.3 多重劳动关系

特征：一个人同时与两家或多家单位实质性建立劳动关系。

司法立场：

- 第一份正常存续 + 第二份"兼职" → 第二份多认定为劳务
- 第一份处于特殊状态（协保 / 内退）+ 第二份"全职" → 第二份可认定为劳动关系
- 两份均"全职"且互不知情 → 一般认定其中一份为主，另一份为劳务

## 三、混同用工的认定

### 3.1 典型情形

特征：劳动者表面上与公司 A 签订劳动合同，实际为公司 A、B、C 等关联企业混同提供劳动。

常见模式：

- 集团内多家子公司共用员工
- 母子公司之间频繁调用员工
- 关联企业之间人员、业务、财产混同

### 3.2 司法对策

**关联企业认定**（case 5.7.4 等）：

> 关联企业的认定可从业务、人事、财产方面的关联性上审查，包括是否从事同一业务、人员是否相互交叉、财产是否明确区分等要素。

**责任承担**：

- 关联企业共同承担用工责任
- 工作年限合并计算
- 劳动者可起诉任一关联企业
- 实际履行劳动的企业承担主要责任

### 3.3 关键证据

| 证据 | 证明目的 |
|---|---|
| 工资发放主体（多家公司轮流）| 财产混同 |
| 工作地点 / 业务跨多家公司 | 业务混同 |
| 工作邮箱 / 名片 / 工作证显示多家公司身份 | 身份混同 |
| 多家公司的劳动合同（先后或同时签订）| 主体混同 |
| HR 管理由单一部门承担多家公司用工 | 人事混同 |

## 四、典型成本路径

### 4.1 employer 视角

| 现状 | 风险 |
|---|---|
| 关联企业混同用工 | 共同承担用工责任 + 工龄合并 + 经济补偿增加 |
| 劳动者拒绝改正二重就业（§39(4)）| 可解除（合法 + 0 补偿）|
| 单位拒绝认可二重就业（如协保人员）| 若被认定，承担用工责任 |

### 4.2 employee 视角

| 主张 | 收益 |
|---|---|
| 主张二重劳动关系成立（协保 / 内退）| 第二份关系全部劳动法保护 |
| 主张关联企业混同 + 共同承担 | 工龄合并 + 选择起诉主体 |
| 主张工龄连续计算 | 经济补偿基数增加 |

## 五、操作要点

### 5.1 employer

**避免混同认定**：

1. 关联企业之间业务、人事、财产明确区分
2. 员工身份明确归属一家公司 + 不要跨家工作
3. 关联企业之间用工调整 → 走正式的劳动关系转移程序（包括协商解除 + 重新签约）

**应对二重就业**：

1. 在规章制度中明确"全职就业"要求
2. 发现员工二重就业 → 书面要求改正 + 给予合理期限
3. 拒不改正 → §39(4) 解除（合法）

### 5.2 employee

**主张双重劳动关系**：

1. 第一份关系特殊状态证据（协保 / 内退证明）
2. 第二份关系三要素证据（详见 employment-vs-civil-playbook）

**主张混同用工**：

1. 收集多家关联企业用工证据（工资、工作记录、身份证明）
2. 主张工龄合并 + 选择对自己有利的主体起诉
