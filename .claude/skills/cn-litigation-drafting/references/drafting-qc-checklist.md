## 1. 通用 8 项共享 QC（所有模板 A-K 均必须通过）

执行该模板专属 QC 前，必须先逐项核查以下 8 项共享 QC。每项 Y/N 必须显式给出。

### 共享 1：当事人主体完整且统一

- 全篇当事人姓名 / 公司全称一致（不混用"甲""乙公司""被告"等指代而无对照表）
- 公司主体已注明统一社会信用代码（如有）
- 个人主体已注明身份证号 / 护照号末 4 位（出于保密硬约束，全文不出现完整号码）
- 多原告 / 多被告时已注明诉讼地位（共同原告 / 共同被告 / 普通共同诉讼 / 必要共同诉讼）

### 共享 2：法律依据现行有效（search-first 强制）

- 引用的法律 / 行政法规 / 司法解释 / 部门规章 / 规范性文件均已 web_search 核对**当前版本与施行日期**
- 引用旧版本者已显式标注"已被 XX 修订"（如"《合同法》[已被 2021 民法典编入]"）
- PRC 司法解释附完整文号（如"法释〔2020〕17 号"）
- PRC 部门规章 / 规范性文件附完整文号（如"银发〔2026〕42 号"）
- 引用层级不混淆（区分法律 / 行政法规 / 部门规章 / 规范性文件 / 司法解释）

### 共享 3：法条引用准确到条款项

- 引用条文精确到"第 X 条第 Y 款第 Z 项"
- 不模糊到"《民法典》若干条""相关法条"等
- 多个条文同时引用时，先主条文，后辅助条文，顺序明确

### 共享 4：事实陈述有证据对应

- 每个事实主张挂证据编号（如"原告于 2025 年 3 月 1 日向被告交付货物（证 1）"）
- 无证据支撑的事实主张已移入"待核查"备注，不进文书正文
- 间接证据使用时已说明证明链条（"证 3 + 证 4 共同证明被告知悉"）

### 共享 5：损失金额列式计算

- 损失主张必须附计算公式（如"利息损失 = 本金 100 万 × LPR 3.45% × 90 天 / 365 = 8,506.85 元"）
- 计算依据明确（LPR 适用何时何版本、利息起算日依据何条款）
- 不报整数（除非合同明确约定为整数金额）
- 涉外案件已注明货币种类与汇率换算依据

### 共享 6：程序时限准确

- 诉讼时效起算日 + 届满日已具体计算并 web_search 核对相关条款（如《民法典》第 188 条 + 司法解释）
- 上诉期 / 再审申请期 / 检察监督期 / 举证期 / 仲裁裁决履行期相关时点已具体核对
- 涉外延长期已主动评估（涉外当事人 30 日 vs. 国内 15 日）
- 节假日顺延规则已考虑（最后一日为节假日的顺延至次工作日）

### 共享 7：客户标识符未泄露（保密硬约束 zero tolerance）

- 草稿全文不出现完整客户姓名（替换为"[原告]""[被告]""[当事人]"等工程性表述）
- 草稿全文不出现完整案号（替换为"[案号]"）
- 草稿全文不出现完整公司名称（替换为"[XX 公司]"）
- 草稿全文不出现身份证号 / 护照号 / 联系方式 / 地址
- 草稿全文不出现合同金额具体数字（替换为"[金额]"或区间词）
- 最终交付当事人副本时才填回真名

### 共享 8：法院 / 仲裁机构全称准确

- 法院全称使用法定全称（如"北京市朝阳区人民法院"，不简写为"朝阳区法院"）
- 仲裁机构全称使用机构正式名称（如"中国国际经济贸易仲裁委员会"，不简写为"贸仲"或"CIETAC"——除非附 CIETAC 作为括注）
- 跨境仲裁机构注明所在地（如"香港国际仲裁中心 / Hong Kong International Arbitration Centre"）
- 管辖法院级别（基层 / 中级 / 高级 / 最高）已核对（依案件性质 + 标的额）

## 2. 模板专属 QC 项详解

## 3. 失败处理流程（max_skill_iter=1）

### 3.1 单次自检失败处理

1. 模板专属 QC 任一项答 N → 进入 1 次修订循环
2. 修订针对 fail 项 → 重检该项 → 转 Y 后继续核查其他项
3. 修订仅修订 fail 项相关段落，不重写未受影响段落（避免引入新错误）

### 3.2 修订后仍 fail 处理

1. max_skill_iter=1 已耗尽，仍存在 N 项
2. 在文书输出末尾"## QC 自检结果"段显式列出：
   - 通用 8 项 Y/N 矩阵
   - 模板专属 N 项 Y/N 矩阵
   - 未通过项清单（编号 + fail 理由）
   - 修订尝试摘要（修订了什么 / 仍 fail 的原因）
   - 建议处理路径（升级 Writer agent / 升级用户裁定 / 该 fail 项是否本案不适用）
3. **不得偷偷修改 QC 项答 Y**（强制合规规则 §0.1）

### 3.3 共享 QC fail 的特别处理

- **共享 7 客户标识符未泄露** 答 N → **stop, do not output**。立即返工脱敏后重检；这是 zero tolerance 项。
- **共享 2 法律依据现行有效** 答 N（即未 web_search 核对）→ 必须先 web_search 核对再答 Y，不接受"暂时使用训练数据"。
