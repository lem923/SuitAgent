# 中国民事诉讼文书起草技能

## 0. 强制合规规则（最高优先级，不得违反）

> **任何"案件简单不需要 QC 自检"的判断都是错误的。诉讼文书的代价是当事人的实体权益与程序权利，QC 自检的价值恰恰在于强制完成机械性结构化核查，避免凭直觉跳跃。简化、合并、跳过 QC 任何一项均构成质量缺陷。**

**强制规则**：

1. **每次起草任何模板（A-K）输出前，必须执行该模板的"QC 自检（强制）"清单**。每项 Y/N 必须显式给出（不得留空、不得"暂不评估"、不得"另行处理"）。
2. **任一专属 QC 项答 N → 必须先修订草稿、再重检该项，直至全部 Y 才落盘**。修订次数上限 = 1（max_skill_iter=1）；仍存在 N 项时，必须在输出末尾显式列出"未通过 QC 项"清单 + 修订说明，交 orchestrator agent（Writer）决定是否升级用户裁定。
3. **通用 8 项共享 QC 适用于所有模板**（见 `references/drafting-qc-checklist.md` 第 1 节），除模板专属 QC 外必须同步执行。
4. **可硬核对项必须 web_search 核对**：法律 / 行政法规 / 司法解释 / 部门规章的现行有效版本与文号、法院/仲裁机构全称、当事人主体登记信息（如已提供）必须先 search-first 核对，不凭训练数据直接写入文书。
5. **保密硬约束 zero tolerance**：QC 自检的最后一项是"客户标识符未泄露"——任何当事人姓名 / 案号 / 公司全称 / 身份证号 / 联系方式以"工程性表述"留存（如"[原告]""[案号]"），起草过程中只在最终交付给当事人的副本内填回真名。
6. **启动读经验库（v1.12.0 闭环读侧）**：起草任何模板前，先读取本 skill 目录下 `memory.md`。若其中存在**非"（暂无条目）"的真实条目**，按当前文书类型（A-K 对应 section）筛选**最相关 top-3** 纳入起草参考；若 `memory.md` 不存在或对应 section 全为"（暂无条目）"，**跳过本步（no-op，不得因此阻断起草、不得把空占位塞入 context）**。本步**只读不写**；经验写入由 cn-case-postmortem 结案复盘统一负责。

**完成标识**（输出末尾必须包含）：

```
## QC 自检结果
通用 8 项：[Y/Y/Y/Y/Y/Y/Y/Y]（全部 Y 才落盘）
模板专属 X 项（[A-K]）：[Y/Y/Y/Y/Y/Y]（全部 Y 才落盘）
修订次数：[0 / 1]
未通过项（如有）：[列出 + 修订说明 + 是否升级用户]
```

详见 `references/drafting-qc-checklist.md`。

## 核心原则

**说理优于堆砌**：文书的说服力来自逻辑链完整、事实精准、法条适配，而非条文堆砌。
**对抗性思维**：起草时，同步预判对方可能提出的反驳，并在文书中预设应对。
**证据先行**：无证据支撑的事实主张不进文书正文，降入"待核查"备注。

## 文书类型与结构模板

### A. 起诉状

```
原告：[基本信息]
被告：[基本信息]
第三人：[如有]

诉讼请求：
  一、...
  二、...
  三、诉讼费用由被告承担

事实与理由：

  （一）基本事实
      [时间线叙事，精准到日，所有节点对应证据编号]

  （二）被告违约/侵权事实
      [具体行为 + 法律后果]

  （三）法律依据
      依据《民法典》第XXX条……被告应承担XXX责任。
      [逐条对应，构成要件逐项满足]

  （四）损失计算
      [列式计算，每项损失注明计算依据]

综上，依据《民事诉讼法》第XXX条，向贵院提起诉讼，请依法裁判。

证据清单：
  证据1：...（证明目的：...）
  证据2：...

                            原告（签名/盖章）：
                            日期：
```

**QC 自检（强制，6 项）**：
- [ ] A1 诉讼请求可执行（法院能裁判，非"谴责""赞扬"等情绪性主张）
- [ ] A2 诉讼请求金额与（四）损失计算列式一致（不舍入、不夹带未列示项目）
- [ ] A3 管辖法院（级别 + 地域）已 web_search 核对（民诉法 + 司法解释配套）
- [ ] A4 请求权基础唯一明确（主请求 + 至多 2 备选；不模糊"违约 / 侵权择一主张"）
- [ ] A5 配套证据清单（I 模板）已同步生成并编号一致
- [ ] A6 送达地址确认书已在"待核查事项"中提示当事人补交

---

### B. 答辩状

```
答辩人：[基本信息]
就原告XXX诉答辩人XXX一案，提出答辩如下：

一、答辩意见概述
    [一句话：原告请求不能成立，理由如下]

二、事实部分答辩
    （一）对原告陈述第X段的异议
        [逐段回应，区分"不认可""有异议""部分认可"]

三、法律部分答辩
    （一）原告援引XXX条文适用有误
        [说明理由]
    （二）本案应适用XXX
        [说明依据]

四、关于原告证据的质证意见
    [逐份证据表态：真实性/合法性/关联性]

综上，请求法院驳回原告全部（或部分）诉讼请求。
```

**QC 自检（强制，5 项）**：
- [ ] B1 对原告每段诉求 / 事实陈述均已逐段回应（无遗漏；用"段号对照表"核查）
- [ ] B2 对每份原告证据均明确质证立场（认可 / 不认可 / 部分认可）
- [ ] B3 反驳层面至少有 2 处具体法条引用（非仅事实层面抗辩）
- [ ] B4 至少有 1 项抗辩权基础（如时效届满 / 不安抗辩 / 同时履行 / 合同无效 / 主体不适格）
- [ ] B5 不构成"自认陷阱"——关键事实承认前已评估对己方主张的不利影响

---

### C. 上诉状

```
上诉人：[基本信息]（一审原告/被告）
被上诉人：[基本信息]

上诉请求：
  一、撤销/变更（一审法院名称）（年度）XXX号民事判决；
  二、改判...；
  三、一、二审诉讼费用由被上诉人承担。

上诉理由：

  一、一审认定事实错误
      [具体指出哪项事实认定有误 + 证据支撑]

  二、一审适用法律错误
      [具体指出条文适用问题]

  三、一审程序存在瑕疵（如有）
      [送达 / 合议庭 / 质证程序]

综上，依据《民事诉讼法》第177条，提起上诉。

                            上诉人：
                            日期：
```

**QC 自检（强制，6 项）**：
- [ ] C1 上诉期未届满（国内当事人 15 日 / 涉外 30 日，自判决书送达之次日起算；已 web_search 核对民诉法现行条款）
- [ ] C2 上诉请求与一审请求权基础对应（不擅自扩张诉讼请求）
- [ ] C3 二审新主张限制已评估（一审未主张原则上不准在二审提出，例外情形已注明）
- [ ] C4 明确区分"事实认定错误"与"适用法律错误"两类上诉理由（不混合）
- [ ] C5 上诉费预交（按一审受理费同额）已在"时限提醒"中标注
- [ ] C6 文书不使用"再审"措辞（审级混淆）

### D. 再审申请书

```
申请人：[基本信息]（原审原告/被告）
被申请人：[基本信息]

申请事项：
  请求依法撤销XXX法院XXX号民事判决，对本案进行再审。

申请再审的法定事由（对应《民事诉讼法》第211条）：
  □ 第(一)项：有新的证据，足以推翻原判决
  □ 第(二)项：原判决认定的基本事实缺乏证据证明
  □ 第(三)项：原判决认定事实的主要证据是伪造的
  □ 第(四)项：原判决认定事实的主要证据未经质证
  □ 第(五)项：对审理案件需要的主要证据，申请调查未获准许
  □ 第(六)项：原判决适用法律确有错误

具体事实与理由：
  [逐项展开，与法条要件精确对应]

证据目录：
  [新证据需说明"新"的原因——客观上新发现/原审无法获取]
```

**QC 自检（强制，7 项）**：
- [ ] D1 再审申请期限未届满（判决/裁定生效后 6 个月内，已 web_search 核对现行民诉法第 209 条）
- [ ] D2 211 条法定事由具体勾选（至少 1 项；不留空、不全部勾选）
- [ ] D3 每项勾选事由有具体事实 + 法律论证（不止勾选符号）
- [ ] D4 如以"新证据"为由：已说明"新"的合理理由（客观上新发现 / 原审无法获取，对照《民诉法解释》第 388 条）
- [ ] D5 文书不使用"上诉"措辞（审级混淆）
- [ ] D6 已评估再审前置：普通案件需经过二审（一审未上诉直接再审有受理障碍）
- [ ] D7 已将检察监督（2 年期限）作为备选路径主动评估并告知当事人

### E. 检察监督申请书

```
申请人：[基本信息]
申请监督的裁判文书：[案号]

申请监督的具体事由：
  一、[裁判错误类型]
      [事实 + 法律依据]

  二、...

申请人认为，上述情形符合《人民检察院民事诉讼监督规则》第XX条规定的监督条件，
恳请检察机关依法予以监督。
```

**QC 自检（强制，6 项）**：
- [ ] E1 检察监督申请期限未届满（裁判生效之日起 2 年内，已 web_search 核对《民诉监督规则》现行条款）
- [ ] E2 已说明"再审被驳回 / 再审未启动"前置情况（监督次于再审）
- [ ] E3 监督事由对照《人民检察院民事诉讼监督规则》具体条款（不只引"违法情形"概括用语）
- [ ] E4 检察机关层级与原裁判法院对应（不向不当然受理的检察院递交）
- [ ] E5 文书不使用"上诉 / 再审"措辞
- [ ] E6 已评估抗诉 vs. 检察建议两种监督方式的适用差别（参《监督规则》）

### F. 代理词

```
代理人（律师姓名/律师事务所）：[基本信息]
当事人：[基本信息]
本案案号：[案号]

代理意见：

  一、本案争议焦点
      [核心争议点 1-3 项，按重要性排序]

  二、关于事实认定
      （一）已查明事实
          [庭审中对方未实质性否认的事实，附证据编号]
      （二）有争议事实及我方主张
          [对方否认或有歧义的关键事实，附证据支撑]
      （三）需法庭进一步认定的事实
          [如需法庭依职权调查或合议庭裁量的事实]

  三、关于法律适用
      （一）案由准确性
          [对法庭确定的案由是否认同；不同则提出明确意见]
      （二）请求权基础
          [我方主张的请求权基础逐条对应构成要件]
      （三）对方援引法条之异议（如适用）
          [指出对方援引条款不适用本案的具体理由]

  四、关于证据采信
      [对庭审中关键证据采信问题的总结性意见，重点针对对方核心证据的质证回应]

  五、综合代理意见
      [一句话核心立场 + 具体诉求/抗辩主张]

  此致
  [法院全称]

                            代理律师：
                            [律师事务所名称]
                            日期：
```

**QC 自检（强制，6 项）**：
- [ ] F1 争议焦点 1-3 项排序合理（按对裁判结果的影响排序）
- [ ] F2 已查明事实 vs. 争议事实区分清晰（边界明确，不混合）
- [ ] F3 请求权基础逐条对应构成要件（不口号化）
- [ ] F4 对方援引法条之异议有具体论证（不止"不适用本案"）
- [ ] F5 文书不使用辩论赛风格（"对方辩友""请贵院明察"等情绪化或文学化表述）
- [ ] F6 综合代理意见有明确诉求（非笼统"驳回原告诉求"，须具体到诉项编号）

### G. 质证意见书

```
质证人：[当事人姓名]
质证对象：[原告/被告/第三人] 提交的证据

针对[原告/被告/第三人] 提交的证据，质证意见如下：

  证据 1：[证据名称]
      证明目的（对方主张）：[简述]

      真实性：[认可 / 不认可 / 部分认可]
      理由：[如：系复印件无法核对原件、形成时间存疑、有篡改痕迹等]

      合法性：[认可 / 不认可]
      理由：[如：取证程序违法、违反《个人信息保护法》、缺乏取证授权等]

      关联性：[认可 / 不认可]
      理由：[如：与本案争议事实无直接关联、与拟证明的诉讼请求不对应等]

      证明力：[强 / 中 / 弱 / 无]
      综合质证意见：[结论性陈述]

  证据 2：...

综合质证结论：
  [一句话总结：对方证据整体能否证明其主张；如不能，简述关键漏洞]

  此致
  [法院全称]

                            质证人：
                            日期：
```

**QC 自检（强制，6 项）**：
- [ ] G1 三性逐项独立质证（真实性 / 合法性 / 关联性 分别表态，不混合）
- [ ] G2 每份证据有具体不认可理由（非笼统"不予认可"或"无法核实"）
- [ ] G3 证明力评估（强 / 中 / 弱 / 无）已给出
- [ ] G4 合法性质证已关注取证程序（含《个人信息保护法》合规、电子取证授权等）
- [ ] G5 已注意区分书证 / 物证 / 电子数据 / 视听资料 / 证人证言适用规则差异
- [ ] G6 对鉴定意见的质证有具体方法（鉴定机构资质 / 鉴定程序 / 鉴定方法 / 鉴定结论的论证逻辑）

### H. 财产保全申请书

```
申请人：[基本信息]
被申请人：[基本信息]

请求事项：
  请求依法对被申请人下列财产采取保全措施：
  一、查封/扣押/冻结被申请人 [财产具体描述+所在地+登记号/账号]，价值人民币[X]元
  二、...

事实与理由：

  一、申请人与被申请人之间存在 [合同/侵权/不当得利等] 法律关系
      [简述基础事实，附证据编号]

  二、被申请人有以下转移/隐匿/挥霍财产的现实危险
      [具体行为线索 + 线索性证据；这是保全成立的关键事由，必须具体]

  三、不立即保全将使申请人合法权益受到难以弥补的损害
      [说明损害后果的不可逆性]

  四、本案保全请求金额与申请人主张的债权数额相当
      [列出对应金额，避免超额保全风险]

担保情况：
  □ 提供现金担保 [金额]
  □ 提供保证人担保 [保证人信息]
  □ 提供保险公司担保函 [保单号]

依据《民事诉讼法》第103条（诉前保全）/第104条（诉中保全），特此申请。

  此致
  [法院全称]

                            申请人：
                            日期：

附：财产线索清单
```

**QC 自检（强制，7 项）**：
- [ ] H1 "现实危险"事实具体且有线索性证据（关键事由——缺则法院通常不予保全）
- [ ] H2 保全财产标的明确（账号 / 不动产登记号 / 股权登记机关；不写"被申请人名下所有财产"等模糊表述）
- [ ] H3 保全金额不超过债权数额（防超额保全引起反赔）
- [ ] H4 担保方式已选定（现金 / 保证 / 保函；金额不少于保全请求额，已 web_search 核对最新司法解释比例）
- [ ] H5 区分诉前 103 / 诉中 104 准确（条文与时点配套；诉前保全 30 日内必须起诉）
- [ ] H6 不立即保全的不可逆损害已具体说明
- [ ] H7 错误保全反赔风险已主动评估并告知当事人

### I. 证据清单

```
证据清单（[原告/被告/第三人] 提交）

| 编号 | 证据名称 | 证据形式 | 证据来源 | 证明目的 |
|-----|---------|---------|---------|---------|
| 证 1 | [名称] | [原件/复印件/电子数据/物证/视听资料/证人证言/鉴定意见/勘验笔录] | [取得方式] | [拟证明的事实+对应诉讼请求或事实主张编号] |
| 证 2 | ... | ... | ... | ... |

---

证据组别（如适用）：
  组 1：[组名，如"履约证据组"]
    包含：证 1、证 2、证 3
    组合证明目的：[整体证明的事实]

证据形式与原件核对：
  - 原件递交情况：[已携带原件 / 未持原件且说明合理理由]
  - 电子数据是否已固化：[已申请公证 / 区块链固化 / 律师见证 / 未固化]
  - 视听资料原始载体：[U盘 / 光盘 / 原设备]

提交方式：
  □ 庭前提交（举证期限届满日：[日期]）
  □ 庭审当庭出示
  □ 申请法院调查取证（依据《民事诉讼法》第67条）

                            提交人：
                            日期：
```

**QC 自检（强制，6 项）**：
- [ ] I1 证据编号与配套文书正文（A 起诉状 / B 答辩状 / J 仲裁 / K 反诉 等）的引用编号完全一致
- [ ] I2 每份证据有具体证明目的（指向具体诉请项或事实主张编号；非笼统"证明被告违约"）
- [ ] I3 证据形式准确分类（原件 / 复印件 / 电子数据 / 物证 / 视听 / 证人 / 鉴定 / 勘验）
- [ ] I4 电子数据已说明固化方式（公证 / 区块链固化 / 律师见证 / 未固化——后者要警示证明力风险）
- [ ] I5 提交方式明确（庭前 / 当庭 / 申请调取；申请调取应另附调查取证申请书）
- [ ] I6 举证期限届满日已明确注明（按本案举证期限通知书 / 法院指定）

## 起草工作流程

收到起草任务后：

```
Step 1：信息核查
  → 确认当事人全称、证件号、联系方式（用于文书首部）
  → 确认事实时间线（要求用户提供关键节点）
  → 确认诉讼/仲裁请求（金额/行为/确认之诉）
  → 确认现有证据清单
  → 文书类型对应程序场景（一审/二审/再审/仲裁/财产保全等）

Step 2：法律依据检索（search-first 强制）
  → 确定请求权基础（一个主请求，最多两个备选）
  → 检索构成要件（逐条）
  → 确认诉讼时效/仲裁时效（从哪天起算，何时届满）
  → 确认管辖法院 / 仲裁机构
  → 法律 / 司法解释 / 部门规章必须 web_search 核对现行版本与文号

Step 3：对抗性预演
  → 对方最可能的三个反驳是什么？
  → 己方如何在文书中预设应对？

Step 4：起草
  → 按对应模板（A-K）起草
  → 证据清单（I 模板）同步生成（每份证据附证明目的）
  → 模板间存在配套关系：起诉状 A 必须配 I；仲裁 J 必须配 I；反诉 K 必须配 I
  → 财产保全 H 单独提交，但财产线索清单作为附件

Step 5：QC 自检（强制，不可跳过）
  → 通用 8 项共享 QC：当事人主体 / 法律依据现行有效 / 法条精确到款项 /
    事实附证据编号 / 损失列式 / 程序时限 / 客户标识符未泄露 / 法院全称
    （详见 references/drafting-qc-checklist.md 第 1 节）
  → 模板专属 QC：执行该模板"QC 自检（强制）"段全部条目
  → 任一项 N → 修订草稿、重检；max_skill_iter=1
  → 仍存在 N 项时，输出末尾显式列出"未通过 QC 项" + 升级 Writer agent 决策
  → 全部 Y → 落盘 + 在输出末尾附"## QC 自检结果"段

Step 6：交付配套
  → 填充说明（标注哪些 `[括号内容]` 需用户补充）
  → 待核查事项（不影响起草但需在提交前确认）
  → 时限提醒（上诉期/再审申请期/举证期限/仲裁裁决履行期/检察监督期）
  → 配套文书提示（如 A → I；J → I；K → I）
```

## 质量红线

- ❌ 不得在无证据支撑的情况下将事实写入文书正文
- ❌ 不得提出法院/仲裁庭无法裁判的请求（如"请法院谴责被告"）
- ❌ 不得在再审申请中使用"上诉"措辞（混淆审级）
- ❌ 反诉状不得遗漏"与本诉的牵连性"论证
- ❌ 仲裁申请书不得遗漏仲裁条款援引（仲裁庭以此确认管辖）
- ❌ 财产保全申请不得遗漏"现实危险"事实（缺此项法院通常不予保全）
- ❌ **不得跳过 QC 自检直接落盘**（违反 §0 强制合规规则第 1-3 条）
- ❌ **不得对法律 / 司法解释 / 部门规章 / 规章版本凭训练数据直接引用**（违反 §0 第 4 条 search-first 要求）
- ❌ **不得在文书内泄露客户标识符**（违反 §0 第 5 条保密硬约束）
- ✅ 损失主张必须附计算公式
- ✅ 时效风险必须主动提示
- ✅ 提交前必须核查法院/仲裁机构立案/受理要求（格式/份数/附件）
- ✅ 证据清单必须与文书正文中证据编号一致
- ✅ 输出末尾必须附"## QC 自检结果"段（Y/N 矩阵 + 修订记录）

---

## 输出格式

文书主体输出为可直接使用的纯文本，同时附：
1. **填充说明**（标注哪些 `[括号内容]` 需用户补充）
2. **证据清单模板**（如适用，使用 I 模板）
3. **待核查事项**（不影响起草但需在提交前确认）
4. **时限提醒**（如上诉期/再审申请期/举证期限/仲裁裁决履行期）
5. **配套文书提示**（如起诉状 A → 提示同步生成 I；仲裁 J → 提示同步生成 I 与适用法律协议）
6. **QC 自检结果**（§0 强制要求；Y/N 矩阵 + 修订记录 + 未通过项处理）
