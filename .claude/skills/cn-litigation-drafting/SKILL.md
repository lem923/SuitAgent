# 中国民事诉讼文书起草技能

## 核心原则

**说理优于堆砌**：文书的说服力来自逻辑链完整、事实精准、法条适配，而非条文堆砌。
**对抗性思维**：起草时，同步预判对方可能提出的反驳，并在文书中预设应对。
**证据先行**：无证据支撑的事实主张不进文书正文，降入"待核查"备注。

---

## 文书类型与结构模板

### A. 起诉状

```
原告：[基本信息]
被告：[基本信息]
第三人：[如有]

诉讼请求：
  一、...
  二、...
  三、诉讼费用由被告承担

事实与理由：

  （一）基本事实
      [时间线叙事，精准到日，所有节点对应证据编号]

  （二）被告违约/侵权事实
      [具体行为 + 法律后果]

  （三）法律依据
      依据《民法典》第XXX条……被告应承担XXX责任。
      [逐条对应，构成要件逐项满足]

  （四）损失计算
      [列式计算，每项损失注明计算依据]

综上，依据《民事诉讼法》第XXX条，向贵院提起诉讼，请依法裁判。

证据清单：
  证据1：...（证明目的：...）
  证据2：...

                            原告（签名/盖章）：
                            日期：
```

---

### B. 答辩状

```
答辩人：[基本信息]
就原告XXX诉答辩人XXX一案，提出答辩如下：

一、答辩意见概述
    [一句话：原告请求不能成立，理由如下]

二、事实部分答辩
    （一）对原告陈述第X段的异议
        [逐段回应，区分"不认可""有异议""部分认可"]

三、法律部分答辩
    （一）原告援引XXX条文适用有误
        [说明理由]
    （二）本案应适用XXX
        [说明依据]

四、关于原告证据的质证意见
    [逐份证据表态：真实性/合法性/关联性]

综上，请求法院驳回原告全部（或部分）诉讼请求。
```

### C. 上诉状

```
上诉人：[基本信息]（一审原告/被告）
被上诉人：[基本信息]

上诉请求：
  一、撤销/变更（一审法院名称）（年度）XXX号民事判决；
  二、改判...；
  三、一、二审诉讼费用由被上诉人承担。

上诉理由：

  一、一审认定事实错误
      [具体指出哪项事实认定有误 + 证据支撑]

  二、一审适用法律错误
      [具体指出条文适用问题]

  三、一审程序存在瑕疵（如有）
      [送达 / 合议庭 / 质证程序]

综上，依据《民事诉讼法》第177条，提起上诉。

                            上诉人：
                            日期：
```

### D. 再审申请书

```
申请人：[基本信息]（原审原告/被告）
被申请人：[基本信息]

申请事项：
  请求依法撤销XXX法院XXX号民事判决，对本案进行再审。

申请再审的法定事由（对应《民事诉讼法》第211条）：
  □ 第(一)项：有新的证据，足以推翻原判决
  □ 第(二)项：原判决认定的基本事实缺乏证据证明
  □ 第(三)项：原判决认定事实的主要证据是伪造的
  □ 第(四)项：原判决认定事实的主要证据未经质证
  □ 第(五)项：对审理案件需要的主要证据，申请调查未获准许
  □ 第(六)项：原判决适用法律确有错误

具体事实与理由：
  [逐项展开，与法条要件精确对应]

证据目录：
  [新证据需说明"新"的原因——客观上新发现/原审无法获取]
```

### E. 检察监督申请书

```
申请人：[基本信息]
申请监督的裁判文书：[案号]

申请监督的具体事由：
  一、[裁判错误类型]
      [事实 + 法律依据]

  二、...

申请人认为，上述情形符合《人民检察院民事诉讼监督规则》第XX条规定的监督条件，
恳请检察机关依法予以监督。
```

### F. 代理词

```
代理人（律师姓名/律师事务所）：[基本信息]
当事人：[基本信息]
本案案号：[案号]

代理意见：

  一、本案争议焦点
      [核心争议点 1-3 项，按重要性排序]

  二、关于事实认定
      （一）已查明事实
          [庭审中对方未实质性否认的事实，附证据编号]
      （二）有争议事实及我方主张
          [对方否认或有歧义的关键事实，附证据支撑]
      （三）需法庭进一步认定的事实
          [如需法庭依职权调查或合议庭裁量的事实]

  三、关于法律适用
      （一）案由准确性
          [对法庭确定的案由是否认同；不同则提出明确意见]
      （二）请求权基础
          [我方主张的请求权基础逐条对应构成要件]
      （三）对方援引法条之异议（如适用）
          [指出对方援引条款不适用本案的具体理由]

  四、关于证据采信
      [对庭审中关键证据采信问题的总结性意见，重点针对对方核心证据的质证回应]

  五、综合代理意见
      [一句话核心立场 + 具体诉求/抗辩主张]

  此致
  [法院全称]

                            代理律师：
                            [律师事务所名称]
                            日期：
```

### G. 质证意见书

```
质证人：[当事人姓名]
质证对象：[原告/被告/第三人] 提交的证据

针对[原告/被告/第三人] 提交的证据，质证意见如下：

  证据 1：[证据名称]
      证明目的（对方主张）：[简述]

      真实性：[认可 / 不认可 / 部分认可]
      理由：[如：系复印件无法核对原件、形成时间存疑、有篡改痕迹等]

      合法性：[认可 / 不认可]
      理由：[如：取证程序违法、违反《个人信息保护法》、缺乏取证授权等]

      关联性：[认可 / 不认可]
      理由：[如：与本案争议事实无直接关联、与拟证明的诉讼请求不对应等]

      证明力：[强 / 中 / 弱 / 无]
      综合质证意见：[结论性陈述]

  证据 2：...

综合质证结论：
  [一句话总结：对方证据整体能否证明其主张；如不能，简述关键漏洞]

  此致
  [法院全称]

                            质证人：
                            日期：
```

### H. 财产保全申请书

```
申请人：[基本信息]
被申请人：[基本信息]

请求事项：
  请求依法对被申请人下列财产采取保全措施：
  一、查封/扣押/冻结被申请人 [财产具体描述+所在地+登记号/账号]，价值人民币[X]元
  二、...

事实与理由：

  一、申请人与被申请人之间存在 [合同/侵权/不当得利等] 法律关系
      [简述基础事实，附证据编号]

  二、被申请人有以下转移/隐匿/挥霍财产的现实危险
      [具体行为线索 + 线索性证据；这是保全成立的关键事由，必须具体]

  三、不立即保全将使申请人合法权益受到难以弥补的损害
      [说明损害后果的不可逆性]

  四、本案保全请求金额与申请人主张的债权数额相当
      [列出对应金额，避免超额保全风险]

担保情况：
  □ 提供现金担保 [金额]
  □ 提供保证人担保 [保证人信息]
  □ 提供保险公司担保函 [保单号]

依据《民事诉讼法》第103条（诉前保全）/第104条（诉中保全），特此申请。

  此致
  [法院全称]

                            申请人：
                            日期：

附：财产线索清单
```

### I. 证据清单

```
证据清单（[原告/被告/第三人] 提交）

| 编号 | 证据名称 | 证据形式 | 证据来源 | 证明目的 |
|-----|---------|---------|---------|---------|
| 证 1 | [名称] | [原件/复印件/电子数据/物证/视听资料/证人证言/鉴定意见/勘验笔录] | [取得方式] | [拟证明的事实+对应诉讼请求或事实主张编号] |
| 证 2 | ... | ... | ... | ... |

---

证据组别（如适用）：
  组 1：[组名，如"履约证据组"]
    包含：证 1、证 2、证 3
    组合证明目的：[整体证明的事实]

证据形式与原件核对：
  - 原件递交情况：[已携带原件 / 未持原件且说明合理理由]
  - 电子数据是否已固化：[已申请公证 / 区块链固化 / 律师见证 / 未固化]
  - 视听资料原始载体：[U盘 / 光盘 / 原设备]

提交方式：
  □ 庭前提交（举证期限届满日：[日期]）
  □ 庭审当庭出示
  □ 申请法院调查取证（依据《民事诉讼法》第67条）

                            提交人：
                            日期：
```

## 起草工作流程

收到起草任务后：

```
Step 1：信息核查
  → 确认当事人全称、证件号、联系方式（用于文书首部）
  → 确认事实时间线（要求用户提供关键节点）
  → 确认诉讼/仲裁请求（金额/行为/确认之诉）
  → 确认现有证据清单
  → 文书类型对应程序场景（一审/二审/再审/仲裁/财产保全等）

Step 2：法律依据检索
  → 确定请求权基础（一个主请求，最多两个备选）
  → 检索构成要件（逐条）
  → 确认诉讼时效/仲裁时效（从哪天起算，何时届满）
  → 确认管辖法院 / 仲裁机构

Step 3：对抗性预演
  → 对方最可能的三个反驳是什么？
  → 己方如何在文书中预设应对？

Step 4：起草
  → 按对应模板（A-K）起草
  → 证据清单（I 模板）同步生成（每份证据附证明目的）
  → 模板间存在配套关系：起诉状 A 必须配 I；仲裁 J 必须配 I；反诉 K 必须配 I
  → 财产保全 H 单独提交，但财产线索清单作为附件

Step 5：自查清单
  [ ] 诉讼/仲裁请求可执行（法院/仲裁庭能裁判）
  [ ] 事实叙述有证据对应
  [ ] 法条引用准确到款项
  [ ] 损失金额列式计算
  [ ] 诉讼/仲裁费预算（争议金额对照收费标准）
  [ ] 送达地址确认书提示（诉讼）/ 仲裁通知地址确认（仲裁）
  [ ] 程序性时限提醒（举证期限/上诉期/再审申请期）
```

## 质量红线

- ❌ 不得在无证据支撑的情况下将事实写入文书正文
- ❌ 不得提出法院/仲裁庭无法裁判的请求（如"请法院谴责被告"）
- ❌ 不得在再审申请中使用"上诉"措辞（混淆审级）
- ❌ 反诉状不得遗漏"与本诉的牵连性"论证
- ❌ 仲裁申请书不得遗漏仲裁条款援引（仲裁庭以此确认管辖）
- ❌ 财产保全申请不得遗漏"现实危险"事实（缺此项法院通常不予保全）
- ✅ 损失主张必须附计算公式
- ✅ 时效风险必须主动提示
- ✅ 提交前必须核查法院/仲裁机构立案/受理要求（格式/份数/附件）
- ✅ 证据清单必须与文书正文中证据编号一致

## 输出格式

文书主体输出为可直接使用的纯文本，同时附：
1. **填充说明**（标注哪些 `[括号内容]` 需用户补充）
2. **证据清单模板**（如适用，使用 I 模板）
3. **待核查事项**（不影响起草但需在提交前确认）
4. **时限提醒**（如上诉期/再审申请期/举证期限/仲裁裁决履行期）
5. **配套文书提示**（如起诉状 A → 提示同步生成 I；仲裁 J → 提示同步生成 I 与适用法律协议）
