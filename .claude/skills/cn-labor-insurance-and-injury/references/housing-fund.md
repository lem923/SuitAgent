# 住房公积金 Reference

> **场景定位**：住房公积金缴存争议（补缴 / 提取 / 差额）。
> **法律依据**：《住房公积金管理条例》+ 最高院公报 2020 年第 11 期典型案例
> **判例支撑**：汇编 6.4 住房公积金（2 案）
> **案例索引**：`case-database/ch6-4-housing-fund.md`

---

## 一、住房公积金的法律性质

### 1.1 强制性 + 专属性

case 6.4.1 镇江市鸿兴磁选公司案（最高院公报 2020 年第 11 期）：

> 住房公积金是用人单位和劳动者**必须依法缴存的长期住房储金**，其缴存具有**强制性和专属性**。
>
> 《住房公积金管理条例》对缴存范围、对象、数额方式、期限及提取、使用、管理、监督等方面均作出了明确规定。住房公积金实行**强制储蓄、专户存储**的制度，用人单位应当按照法定方式和数额及时为劳动者缴存，**不得通过协商改变缴存方式或者减免缴存义务**。

### 1.2 与社保的对比

| 维度 | 社会保险 | 住房公积金 |
|---|---|---|
| 法律性质 | 公法义务 | 公法义务 |
| 缴存主体 | 用人单位 + 劳动者 | 用人单位 + 劳动者（同比例 5-12%）|
| 适用范围 | 法定 | 法定（含进城务工人员）|
| 管理部门 | 社保经办机构 | 住房公积金管理中心 |
| 争议程序 | 行政复议 / 行政诉讼 | 行政复议 / 行政诉讼 |
| 协议放弃 | 无效 | 无效 |

## 二、争议类型与处理路径

### 2.1 补缴争议

```
劳动者发现单位未缴 / 少缴公积金
            ↓
向住房公积金管理中心投诉 / 申请
            ↓
住房公积金管理中心责令单位补缴
            ↓
单位不补缴 → 申请强制执行
```

**不属于民事诉讼受案范围**——按行政程序处理。

### 2.2 单位与公积金管理中心的行政争议

case 6.4.1 镇江市案：单位认为不应补缴 → **可以提起行政复议 / 行政诉讼**。

但司法立场对补缴义务认定较严：**不得以协议方式减免**。

### 2.3 进城务工人员公积金

case 6.4.2 南京中欣公司案：

> 为在职职工缴纳住房公积金是用人单位的**法定义务**，包括**劳务派遣人员和进城务工人员**。职能机关区分农民工和城镇居民而在补缴认定上采取不同执法标准，**不仅不具有可操作性，更损害了劳动者的平等就业、平等获得劳动待遇的基本权利**。

**实务推论**：

- 进城务工人员的公积金补缴义务与城镇职工**完全相同**
- 单位不能以"农民工不缴公积金"等地方习惯抗辩
- 派遣员工公积金缴存义务在派遣单位

## 三、操作策略

### 3.1 employee

**主张路径**：

1. **不能直接起诉**单位主张公积金 → 向**住房公积金管理中心投诉 / 申请**
2. 公积金管理中心责令补缴 → 单位补缴 → 实际损失消除
3. 单位拒不补缴 → 公积金管理中心申请**法院强制执行**
4. 因离职 / 退休等原因公积金无法补缴的特殊情形 → 可参照"养老待遇损失"思路考虑能否民事追偿（地区分歧大）

**注意**：

- 公积金的缴存是按月义务，**仲裁时效不明确**（不属于劳动争议）
- 可投诉的时效限制较少
- 但实际能补缴的年限通常受地方政策限制

### 3.2 employer

**合规底线**：

- 全员缴存（含派遣、农民工、临时工）
- 按法定基数 + 比例缴存（5-12%，单位与劳动者同比例）
- 不签订"自愿不缴"协议（无效）

**应对补缴争议**：

- 收到公积金管理中心责令补缴通知 → 评估是否提起行政复议
- 一般情形下补缴义务难以抗辩 → 直接补缴 + 内部追责
- 涉及历史问题 / 集体性补缴 → 可与公积金管理中心协商分期缴付

## 四、与社保差异的关键点

| 争议类型 | 社保受案路径 | 公积金受案路径 |
|---|---|---|
| 单位未办理手续 / 不能补办 → 待遇损失 | 民事可受理 | 民事**不**受理 |
| 单位欠缴 / 少缴 | 行政程序 | 行政程序 |
| 待遇支付争议（如医疗费、生育津贴）| 民事可受理（部分）| 不存在（公积金本身无"待遇"概念）|
| 协议放弃 | 无效 | 无效 |

**核心区别**：

- 社保有"待遇损失"概念（如养老金 / 医疗费），单位过错致损失可民事追偿
- 公积金是"储金"，不存在"待遇损失"——只能要求补缴 + 强制执行
- 因此**民事可受理范围更窄**

## 五、关键证据

| 证据 | 用途 |
|---|---|
| 劳动合同 / 入职登记表 | 证明劳动关系 + 缴存义务起始 |
| 工资条 / 银行流水 | 确定缴存基数 |
| 公积金缴存查询记录 | 证明欠缴 / 少缴事实 |
| 公积金管理中心补缴通知 | 行政认定证据 |
