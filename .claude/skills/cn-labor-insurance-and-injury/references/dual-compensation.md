# 双重赔付 Reference（民事侵权 + 工伤保险）

> **场景定位**：工伤事故由第三人侵权造成时，劳动者能否同时获得工伤保险待遇 + 民事侵权赔偿。
> **法律依据**：《社会保险法》§42 + 最高院相关司法解释
> **判例支撑**：汇编 6.1(C) 双重赔付（约 8 案）

---

## 一、双重赔付的法理框架

### 1.1 核心问题

劳动者因第三人侵权遭受工伤（如下班路上被车撞），其享有：

```
[A] 民事侵权赔偿（侵权人 / 侵权人责任保险）
       +
[B] 工伤保险待遇（工伤保险基金 / 用人单位）
```

两者能否兼得？

### 1.2 主流司法立场（差额补偿 vs 双重赔付）

| 项目 | 立场 | 适用范围 |
|---|---|---|
| **医疗费** | **差额补偿**（不重复）| 全国统一 |
| **误工费** vs **停工留薪期工资** | **差额补偿**（仅一方承担）| 多数地区 |
| **残疾赔偿金** vs **一次性伤残补助** | **可双重赔付** | 主流（最高院公报案例支持）|
| **死亡赔偿金** vs **一次性工亡补助** | **可双重赔付** | 主流 |
| **精神损害抚慰金** | **仅民事方主张** | 工伤保险无此项 |
| **被抚养人生活费 / 供养亲属抚恤** | **差额补偿** | 多数地区 |

### 1.3 主流规则总结

**实物补偿型（医疗费、误工费）**：以一方为限填补实际损失，不双重赔付。

**精神补偿型 / 法定补偿型**（残疾赔偿、死亡赔偿、伤残补助、工亡补助）：性质不同，可双重赔付。

**关键判例**：

- case 6.1.X 系列：最高院明确医疗费由先行获赔方承担，另一方在实际损失范围内补差；一次性伤残补助与残疾赔偿金性质不同，可同时主张
- case 6.1.X：先行支付制度——劳动者可直接向工伤保险基金主张医疗费，**不以已向第三人主张为前提**

## 二、操作策略

### 2.1 双重赔付适用阶梯

```
Step 1：先去申请工伤认定 + 劳动能力鉴定
       （行政程序，时效 1 年，必须及时启动）

Step 2：同步起诉第三人民事赔偿
       （民事程序，时效 3 年）

Step 3：两线并行
       · 工伤保险基金 / 单位：医疗费、停工留薪期工资、伤残补助 / 工亡补助
       · 第三人 / 保险公司：医疗费（与工伤保险方差额）、残疾赔偿金、精神损害抚慰金

Step 4：项目分类核算
       · 实物补偿型：取高方足额，低方补差额
       · 法定补偿型：可双重主张
```

### 2.2 工伤保险先行支付

case 6.X.X：职工因第三人受到伤害，社会保险行政部门已经作出工伤认定，职工或其近亲属未对第三人提起民事诉讼或者尚未获得民事赔偿的，**直接要求社会保险经办机构支付工伤医疗费，社会保险经办机构应予支付**。

- 不得以"未向第三人先行主张医疗费"为由拒绝支付
- 不得以侵权中的责任划分比例进行工伤保险待遇审核（工伤保险适用**无过错责任**）

### 2.3 先行支付后的追偿

社保经办机构先行支付医疗费后 → 由社保经办机构向第三人追偿（行政追偿）。

劳动者**不需要等第三人民事案件结束**即可获得工伤待遇。

## 三、不同事故类型的处理

### 3.1 上下班途中交通事故

最常见的双重赔付情形：

```
工伤认定（§14(6)）：上下班途中 + 非本人主要责任的交通事故 → 工伤
       +
民事侵权（《民法典》§1208）：交通事故侵权人 / 保险公司
```

**操作要点**：

1. **公安交警事故认定书**——确定责任比例（关键文件）
2. **非本人主要责任** → 工伤认定要件（如本人主要责任 → 不能认定工伤）
3. **同时起诉侵权人** + 申请工伤认定（两条线并行）

### 3.2 工作时间内第三人侵害

如工作中被供应商车辆撞伤、办公场所内被他人伤害等：

- 直接构成 §14(1) 工伤
- 民事侵权独立成立
- 双重赔付适用

### 3.3 因履行工作职责受暴力侵害（§14(3)）

如银行职员被劫匪伤害、客服被客户殴打：

- 工伤认定明确（§14(3)）
- 侵权人（劫匪 / 客户）民事侵权
- 双重赔付适用

## 四、双视角策略

### 4.1 employee（受害劳动者）

**最大化主张原则**：

- 双线并行（工伤行政 + 民事诉讼）
- 实物补偿项选择支付能力强的一方先行；获赔不足时向另一方追补差额
- 法定补偿项**全部主张**：残疾赔偿金 + 一次性伤残补助；死亡赔偿金 + 工亡补助
- 精神损害抚慰金仅向民事侵权方主张

**陷阱避免**：

- 不要被单位"我们赔了，工伤就别申请了"误导 → 双重赔付权益丧失
- 不要在工伤认定时承认"主要责任" → 影响工伤认定
- 不要在调解中签订"概括了结"放弃工伤待遇

### 4.2 employer

**风险敞口**：

- 单位已缴工伤保险时，工伤待遇由基金支付，单位负担有限
- 单位未缴工伤保险时，单位承担工伤待遇 + 第三人侵权与单位无关 → 单位双重承担风险

**操作要点**：

- 及时申报工伤（30 日内）
- 积极配合工伤认定 + 鉴定程序
- 第三人侵权情形下，单位无追偿权（基金代位行使）

### 4.3 family（工亡职工家属）

**双重主张**：

- 一次性工亡补助金（基金支付，约 100 万左右，2024 年标准）
- 死亡赔偿金（第三人 / 保险公司，按当地标准 × 20 倍）
- 丧葬补助 + 供养亲属抚恤（基金支付）
- 精神损害抚慰金（仅向第三人主张）

通勤事故工亡的家属往往可获得总额 200-400 万元的综合赔偿。

## 五、关键证据

| 证据 | 用途 |
|---|---|
| 公安交警事故认定书 | 确定责任划分 + 工伤认定要件 |
| 工伤认定决定书 | 工伤待遇主张前提 |
| 劳动能力鉴定结论 | 待遇计算依据 |
| 医疗费发票 + 病历 | 实际损失证据 |
| 工资条 + 银行流水 | 停工留薪期工资基数 |
| 第三人民事判决书 | 双重赔付证据 |
| 保险公司理赔记录 | 差额计算 |
