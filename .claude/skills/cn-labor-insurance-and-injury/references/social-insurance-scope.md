# 社保受案范围 Reference（其他社会保险）

> **场景定位**：除工伤之外的社会保险争议（养老、医疗、生育、失业、住房公积金）的受案范围划分及待遇争议处理。
> **法律依据**：《社会保险法》+ 《住房公积金管理条例》+ 最高院相关司法解释
> **判例支撑**：汇编 6.3 其他社会保险（25 案）+ 6.4 住房公积金（2 案）
> **案例索引**：`case-database/ch6-3-other-insurance.md` + `ch6-4-housing-fund.md`

---

## 一、受案范围的核心划分

### 1.1 行政管理范畴 vs 劳动争议范畴

```
[行政管理范畴]（劳动行政部门 → 行政复议 / 行政诉讼）
  · 用人单位欠缴 / 拒缴社保费
  · 缴费基数争议
  · 缴费年限争议
  · 多缴 / 少缴退费争议
  · 社保登记 / 变更 / 险种选择
  · 进城务工人员社保 / 公积金的具体补缴执行

[劳动争议范畴]（劳动仲裁 → 民事诉讼）
  · 用人单位未办理社保手续 AND 经办机构不能补办
    → 待遇损失赔偿
  · 工伤保险待遇争议（详见 work-injury-compensation.md）
  · 生育津贴 / 产假工资差额（区分险种）
```

**关键判例（最高院 / 江苏高院系列）**：

- case 6.3.3 杜焕珍案：人民法院受理社会保险待遇案件应具备两项前提：①用人单位没有为劳动者办理社保手续；②社保经办机构不能补办手续。**已办理登记开户的，按时足额缴费争议不属于受案范围**
- case 6.3.4 孙永志案：单位欠缴 / 拒缴 / 缴费年限 / 缴费基数争议 → **不属于劳动争议**
- case 6.3.7 溧阳市恒正案：单位多缴社保 → **不当得利返还不属民事案件受理范围**（应向社保机构申请退费 → 行政程序）

## 二、各险种争议处理

### 2.1 养老保险

#### 待遇损失赔偿（民事可受理）

case 6.3.11 杜某案：用人单位过错未办理社保手续 → 劳动者达法定退休年龄后**无法办理退休**→ **可主张养老保险待遇损失赔偿**。

**计算方式**：

- 江苏：**定额赔偿**，不考虑过错（case 6.3.5 备注）
- 海南：根据工作年限、退休时间、缴费金额、政策变化等因素**参照人均养老金 × 平均寿命**测算（case 6.3.12）
- 实务建议：各地标准不一，需检索本地裁判口径

#### 仲裁时效

case 6.3.14 + 6.3.15：

- 仲裁时效从**达到法定退休年龄之日**起算
- 如劳动者继续工作 → 从**双方解除 / 终止劳动合同之日**起算

#### 延迟退休

case 6.3.13：用人单位缴费年限缺失导致延迟退休 → 劳动者自行续缴后 → 可主张**因延迟退休造成的待遇损失**。

### 2.2 医疗保险

#### 待遇损失赔偿

case 6.3.17 ~ 6.3.21 系列：

- 单位未参保职工基本医疗保险 → 劳动者产生医疗费损失
- 单位应承担**职工基本医疗保险标准下可报销范围内的费用**
- 劳动者自行参加新农合 / 城镇居民医保已报销部分 → 应扣除
- **不可重复享受**

#### 险种选择差异（不属受案范围）

case 6.3.16 李某案：单位因历史 / 政策原因为农民工缴纳了特殊医疗保险（与职工医保不同）→ 后续待遇差别 → **不属劳动争议受案范围**。

### 2.3 生育保险（女职工产假待遇）

#### 产假工资 / 生育津贴

case 6.3.22 ~ 6.3.25 系列：

- 用人单位**不得在产假期间降低工资待遇**
- 生育津贴**低于**产假前工资 → 用人单位**补足差额**
- 生育津贴**高于**产假前工资 → 用人单位不得截留

#### 江苏特殊规定

case 6.3.22 + 6.3.23：

- 《江苏省职工生育保险规定》§18(4)：津贴低于产假前工资标准 → 单位补足
- 《江苏省人口与计划生育条例》§27：法定产假 98 天基础上 + 延长 30 天，该期间津贴低于产假前工资 → 单位补足差额

#### 产假期间违法解除

case 6.3.25 朱某案：单位在产假期间**违法解除** → 劳动者只能领取解除前的生育津贴。

- 如劳动者选择**赔偿金**（2N）→ 单位无需补足解除后剩余产假期间的津贴
- 如劳动者选择**恢复劳动关系** → 单位需补足

### 2.4 失业保险

通常不进入劳动争议程序。失业人员领取失业保险金属于行政管理，由社保经办机构办理。

## 三、社保协议无效条款

case 6.3.1 + 6.3.2 + 6.3.6：

- **用人单位与劳动者约定减轻 / 免除社保义务**的条款 → **无效**（违反法律强制性规定）
- 劳动者"自愿放弃社保 + 工资折算" → 无效
- 单位以现金补贴代替参保 → 无效

**核心命题**：缴纳社保是**公法义务**，不能通过私法协议免除。

case 6.3.6 康辉旅行社案：劳动者应聘时承诺自愿承担**全部**社保费 → 因违反强制性规定无效。劳动者**有权请求用人单位返还应由单位负担的部分**。

case 5.2.13 何某案：但劳动者**自愿不参保**情形下，事后以"未参保"为由主张 §38 解除经济补偿 → **不予支持**。但补缴义务仍存在。

## 四、自行参保后的追偿

case 6.3.8 吴某案：劳动者自行缴纳社保后向用人单位**追偿已缴费用** → **不属于民事案件受理范围**（应通过行政程序处理）。

case 6.3.9 王张怀案：劳动者**无权直接请求用人单位向其支付社保费**——应由社保征收机构责令补缴。

**实务推论**：劳动者**不能跳过社保机构直接起诉单位**主张已缴或应缴金额。

## 五、双视角策略

### 5.1 employer

**合规底线**：

- 全员参保（不允许"自愿放弃"协议）
- 缴费基数与实际工资匹配（避免少缴争议）
- 不以现金 / 补贴代替参保

**应对争议**：

- 欠缴 / 缴费基数争议 → 不属劳动争议，主导行政方式处理
- 待遇损失赔偿 → 审查是否符合受理条件（未办手续 + 不能补办）
- 协助开具相关证明（如收入证明、工龄证明）

### 5.2 employee

**主张路径**：

- 单位**未办理社保手续**且**不能补办** → 直接起诉待遇损失赔偿
- 单位**已办手续但欠缴 / 少缴** → 向**社保稽核部门投诉**（不走民事）
- **单位多缴退费** → 由单位向社保机构申请退费（劳动者无权直接主张）

**重点：仲裁时效**：

- 养老待遇损失：达法定退休年龄之日起算
- 医疗待遇损失：实际发生医疗费用之日起算
- 生育津贴差额：产假结束之日起算
