# 责任主体 Reference（派遣 / 承包 / 挂靠 / 借调）

> **场景定位**：多方用工关系下的工伤赔偿责任划分。
> **法律依据**：《工伤保险条例》§43 + 《劳务派遣暂行规定》+ 最高院相关司法解释
> **判例支撑**：汇编 6.1(A) 责任主体（约 12 案）

---

## 一、责任主体划分矩阵

### 1.1 直接用工

**责任主体**：用人单位（直接负责）

**典型情形**：单一劳动合同关系，没有第三方介入。

### 1.2 劳务派遣

```
派遣单位（与劳动者签合同 + 缴社保）
    ↕
用工单位（实际指挥 + 提供劳动条件）
    ↕
劳动者
```

**责任主体**：

- **派遣单位**：用人单位主体责任 → 缴工伤保险 + 主要赔偿义务
- **用工单位**：连带责任（若不规范用工导致工伤 → 与派遣单位连带）
- **劳务派遣协议**：可约定派遣 / 用工的内部分担，但**不能对抗劳动者**

**关键判例**：

- case 6.1.X 系列：派遣员工工伤，**派遣单位为主体**，用工单位连带
- case 6.1.X：派遣单位未缴工伤保险 → 派遣单位承担全额责任

### 1.3 承包关系（重要）

#### 类型 A：合法承包（具有用工资质）

承包人具有合法用工主体资格 → 承包人为责任主体。

#### 类型 B：违法发包（核心战场）

```
发包人（项目方）→ 承包人（无资质 / 借资质 / 个人）→ 招用劳动者
```

**责任划分（最高院明确）**：

> 发包人将业务发包给**不具备用工主体资格**的组织或个人，该组织或个人招用的劳动者发生工伤的，**发包人承担用工主体责任**。

**实务推论**：

- 建筑业违法分包 / 转包（极其常见）→ 总包 / 上层承包人承担责任
- 个人挂靠 → 被挂靠单位承担用工主体责任
- 不能以"不是我的员工"抗辩

**关键判例**：

- case 6.1.X：违法转包情形，**最上层有资质单位承担工伤保险责任**
- case 6.1.X：个体工商户挂靠企业经营，**被挂靠企业承担用工主体责任**
- case 6.1.X：建筑施工承包链中，**总包单位 / 实际施工人 / 挂靠企业均可能成为责任主体**

### 1.4 借调

```
出借单位（原合同主体）→ 借入单位（实际管理）→ 劳动者
```

**责任主体**：原则上为**出借单位**（劳动合同关系所在地），借入单位可能承担连带责任。

### 1.5 多重劳动关系（同时为两家以上单位工作）

- 全日制工作 + 非全日制工作 → 工伤发生时为哪家工作，由该单位承担
- 退休返聘 → 一般非劳动关系，不适用工伤保险（按民事侵权处理）
- 混同用工（关联企业混合使用劳动力）→ 各关联企业承担连带责任

## 二、典型场景操作

### 2.1 建筑工地伤亡（最高频）

**典型链条**：

```
建设单位 → 总包单位 → 分包单位 → 班组承包人 → 实际劳动者
```

**责任主体认定步骤**：

1. **审查各层主体的用工资质** → 哪一层是最近的"具备用工主体资格"的单位？
2. **该单位承担用工主体责任**
3. 如该单位为分包单位且分包合法 → 分包单位承担
4. 如分包违法（个人 / 无资质单位）→ 上一层有资质的总包单位承担

**实务陷阱**：

- 现场签到表 / 工资发放凭证 / 安全教育记录 / 工友证言 → 关键证据
- 不要被"班组承包人"挡在第一层；穿透到有资质的总包

**关键判例**：

- case 6.1.X：劳动者通过班组承包人到工地工作，受伤后，最高院认定**有资质的总包单位**承担工伤保险责任，承包人内部追偿
- case 6.1.X：违法分包链条中**任一层** 均可能被认定为责任主体

### 2.2 平台经济从业者（新兴）

详见 cn-labor-relationship-determination/platform-economy-playbook.md

**简化路径**：

- 完全劳动关系 → 平台承担工伤责任
- 不完全劳动关系 → 平台需承担一定职业伤害保障责任（部分省市试点工伤单险种参保）
- 民事合作 → 不适用工伤保险，按民事侵权处理

### 2.3 挂靠经营

```
个人 / 个体工商户（实际经营）→ 借用企业资质（挂靠）→ 对外承接业务
```

挂靠人招用的劳动者发生工伤 → **被挂靠单位**承担用工主体责任。

## 三、双视角策略

### 3.1 employer（实际用工方 / 发包方）

**风险隔离**：

- 不与无资质单位 / 个人发生分包关系
- 内部承包必须保留经营自主权 + 风险承担给承包人（否则会被穿透）
- 劳务派遣比内部承包风险更可控（有派遣单位作为缓冲）
- 全员参保是最经济的风险对冲（成本远低于工伤待遇）

**应对工伤主张**：

- 第一步：审查劳动关系 → 是否构成本单位劳动关系？
- 第二步：审查责任划分 → 是否有更上层的责任主体？
- 第三步：审查工伤认定 → 实体要件是否齐备？

### 3.2 employee（受伤劳动者）

**主张路径**：

1. **多主体并列起诉**（建筑工地等多层链条情形）
2. 优先选择**有支付能力 + 有资质**的单位
3. **不要被合同上的承包人误导** → 穿透到实际责任主体

**关键证据**：

- 现场施工照片 / 安全教育记录 / 工友证言
- 工资发放凭证（如包工头微信转账、现金签字单）
- 项目方招工广告 / 工地公告
- 实际管理者通讯记录

### 3.3 third_party（派遣单位 / 承包单位等中间方）

**内部追偿**：

- 派遣 / 用工协议中应约定责任分担
- 承包合同中应约定违约责任
- 实际承担责任后可向真正过错方追偿

## 四、关键判例汇总

详见 `case-database/ch6-1-work-injury-civil.md` § 6.1(A) 责任主体。核心规则：

| 情形 | 责任主体 |
|---|---|
| 直接用工 | 用人单位 |
| 合法派遣 | 派遣单位（主），用工单位（连带）|
| 合法承包（有资质）| 承包单位 |
| 违法发包 / 转包 | 发包 / 上层有资质单位 |
| 个人挂靠 | 被挂靠单位 |
| 借调 | 出借单位（主），借入单位（连带）|
| 混同用工 | 各关联企业连带 |
| 退休返聘 | 民事侵权（非工伤保险）|
