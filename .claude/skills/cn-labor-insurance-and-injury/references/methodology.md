# 核心方法论

## 一、工伤认定基础框架

### 1.1 工伤认定的程序性质

工伤认定是**行政程序**：

- 由劳动行政部门（社保局工伤认定部门）作出
- 当事人不服认定决定 → 行政复议 / 行政诉讼
- **不属于劳动争议范畴 → 不能仲裁**

### 1.2 工伤认定主体

- 用人单位：自事故伤害发生之日或职业病诊断之日起 **30 日内**应当提出工伤认定申请
- 工伤职工或其近亲属、工会组织：自事故伤害发生之日或职业病诊断之日起 **1 年内**可以提出工伤认定申请（用人单位未在 30 日内申请的）

### 1.3 工伤认定的核心三要素

```
工作时间 + 工作场所 + 工作原因
（适用 §14(1)）

或

§14(2)~(7) 的其他情形

或

§15 视同工伤情形
```

## 二、§14 七情形详解

### 2.1 工作时间和工作场所内 + 因工作原因（§14(1)）

最常见情形。判断要点：

- **工作时间**：合同约定 + 实际加班 + 工作时间前后预备 / 收尾（§14(2)）
- **工作场所**：办公地点 + 工作设施 + 必要的通行区域（如卫生间、电梯、楼梯）
- **工作原因**：因履行工作职责（核心要件）

### 2.2 工作时间前后预备 / 收尾工作（§14(2)）

包括：

- 上班前的准备工作（换工装、调试设备）
- 下班后的清理工作（关闭设备、整理工具）

### 2.3 因履行职责受暴力伤害（§14(3)）

包括：

- 客户冲突
- 同事冲突（因工作引起）
- 第三人寻衅滋事（因履行职责引起）

### 2.4 职业病（§14(4)）

特殊路径：

- 需先经职业病诊断（职业病诊断机构）
- 取得职业病诊断证明书 → 工伤认定无需"工作时间 + 工作场所 + 工作原因"三要素
- 详见 work-injury-recognition.md § 职业病

### 2.5 因工外出（§14(5)）

包括：

- 出差期间
- 公派学习期间
- 工作派遣期间

注意：因工外出期间下落不明 → 也认定工伤。

### 2.6 上下班途中（§14(6)）

**严格限制条件**：

1. 上下班途中（合理时间 + 合理路线）
2. 受到**非本人主要责任**的交通事故 / 城市轨道交通 / 客运轮渡 / 火车事故
3. 必须有公安交警的事故责任认定书（证明非本人主要责任）

司法严审：

- 步行 / 自行车 / 电动车与机动车事故 → 交警认定
- 同等责任 / 次要责任 / 无责 → 可认定工伤
- 主要责任 / 全部责任 → 不能认定工伤

### 2.7 其他法定情形（§14(7)）

兜底条款，目前主要包括：

- 因履行工会职责受伤
- 部分地方性法规规定的其他情形

## 三、§15 视同工伤详解

### 3.1 48 小时内突发疾病死亡（§15(1)）

**关键要件**：

- 工作时间 + 工作岗位
- 突发疾病死亡，或在 48 小时之内经抢救无效死亡

司法争议：

- "48 小时"的起算（开始抢救时间 vs 临床死亡时间）
- 不同地区认定标准略有差异
- 家属放弃治疗能否突破 48 小时限制 → 司法分歧

### 3.2 抢险救灾受伤（§15(2)）

为维护国家利益、公共利益（如：救火、救灾、见义勇为）受伤的。

### 3.3 旧伤复发（§15(3)）

军队革命伤残军人到用人单位后旧伤复发的。

## 四、责任主体认定

### 4.1 直接用工

- 用人单位直接承担工伤保险责任
- 工伤保险费由用人单位缴纳

### 4.2 劳务派遣

- 工伤认定主体：派遣单位（用人单位）
- 工伤保险费：派遣单位缴纳
- 工伤待遇：派遣单位承担（用工单位连带）
- 详见 liability-subjects.md

### 4.3 承包 / 转包关系

《最高人民法院关于审理工伤保险行政案件若干问题的规定》§3：

> 承包人将工程发包给不具备用工主体资格的组织或者自然人，该组织或者自然人聘用的劳动者从事承包业务时因工伤亡的，承包人为承担工伤保险责任的单位。

实务推论：

- 承包人是有资质的合法用人单位 → 工伤保险责任在承包人
- 承包人是无资质的个人 / 包工头 → 工伤保险责任在发包人 / 转包人

### 4.4 挂靠关系

挂靠人因工伤亡 → 被挂靠单位承担工伤保险责任。

### 4.5 借调关系

- 借出单位与借入单位约定 → 按约定
- 无约定 → 借出单位承担（劳动关系在借出单位）

## 五、双重赔付规则

### 5.1 第三人侵权 + 工伤的双重赔付

case 6.1（双重赔付子节）系列：

**基本规则**：劳动者因第三人侵权同时构成工伤的，可以同时获得：

- 工伤保险待遇（无过错责任 + 不考虑第三人责任）
- 第三人民事侵权赔偿

**例外项目**（不可重复赔付）：

- 医疗费：先获得侵权赔偿的，工伤保险扣减；先获得工伤的，社保经办机构向第三人追偿

### 5.2 工伤保险与商业保险的关系

- 工伤保险（社会保险）与商业意外险（商业保险）→ 可以叠加
- 但部分商业保险条款可能有"工伤保险已赔付的不再赔付"条款 → 看具体合同

### 5.3 工伤保险待遇支付主体

- 工伤保险基金 + 用人单位**分项**承担：
  - 医疗费、康复费、辅助器具费 → 基金
  - 停工留薪期工资、住院伙食补助、五级 / 六级伤残津贴 → 用人单位
  - 一次性伤残补助 → 基金
  - 一次性工伤医疗补助 → 基金
  - 一次性伤残就业补助 → 用人单位

## 六、社保受案范围划分（关键）

### 6.1 劳动争议受案范围

**核心规则**（case 6.3.3、6.3.4、6.3.5）：

> 人民法院受理社会保险待遇案件应具备两项前提：
> 一是用人单位**没有为劳动者办理社会保险手续**
> 二是**社会保险经办机构不能补办手续**
> 导致劳动者无法享受社会保险待遇

实务推论：

- 已办理登记 + 缴费争议 → **不属于**劳动争议受案范围（转劳动行政部门处理）
- 未办理登记 + 不能补办 → 劳动者可主张待遇损失赔偿（劳动争议）

### 6.2 行政管理范畴

case 6.3.4、6.3.7、6.3.8：

> 用人单位已经为劳动者办理了社会保险手续，因用人单位欠缴、拒缴社会保险费或者劳动者对缴费年限、缴费基数等发生的争议，**不属于劳动争议受案范围**。

属于行政管理范畴：

- 社保登记 / 补办手续
- 缴费基数 / 缴费年限争议
- 多缴 / 少缴 / 退费
- 险种选择
- 自行参保后追偿
- 变更参保地

→ 由社保费征收部门处理（行政复议 / 行政诉讼）

### 6.3 例外：协议免除参保 / 以补贴代替参保

case 6.3.1、6.3.2、6.3.6 等：

> 用人单位与劳动者自行约定**减轻或者免除**缴纳社会保险费义务的条款 → 无效
> 给劳动者造成损失的，由用人单位承担

此情形可走劳动争议程序主张赔偿。

## 七、地区敏感性

| 地区 | 特殊立场 |
|---|---|
| 江苏 | 养老保险待遇损失定额（不考虑过错）/ 仲裁时效从退休日起算 |
| 北京 | 严格审查工伤认定要件 + 通勤事故责任认定从严 |
| 上海 | 协保制度发达 + 双重劳动关系下工伤认定较多 |
| 广东 | 派遣派工工伤认定案例多 |

详见各 reference 文件中的地区注解。
