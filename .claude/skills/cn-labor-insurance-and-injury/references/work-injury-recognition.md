# 工伤认定 Playbook

> 涵盖工伤认定的全部七情形（§14）+ 视同工伤三情形（§15）+ 程序要点。
> 判例支撑：汇编 6.2 工伤行政案件 40 案。

## 一、§14(1) 工作时间 + 工作场所 + 工作原因

### 1.1 工作时间认定

| 情形 | 是否认定 |
|---|---|
| 合同约定时间内 | 是 |
| 实际加班时间内 | 是 |
| 上班前提早 / 下班后延迟（合理范围）| 是（§14(2)）|
| 工作日午休（在单位）| 视情（部分认定）|
| 非工作日（如周末加班）| 视加班实际发生 |
| 出差期间 | 是（§14(5)）|

### 1.2 工作场所认定

| 情形 | 是否认定 |
|---|---|
| 办公场所内 | 是 |
| 工厂车间内 | 是 |
| 单位提供的食堂 / 休息室 | 视情 |
| 单位提供的通勤工具内 | 视情（如班车）|
| 工作中外出的目的地 | 是 |
| 单位组织的活动地点 | 是 |

### 1.3 工作原因认定（核心要件）

- 直接履行工作职责 → 是
- 与工作相关的协助行为 → 是
- 因工作产生的纠纷引起伤害 → 是（§14(3)）
- 自身原因（如自杀、自残、酒后逞强）→ 否
- 违反规章制度的行为 → 视具体情节（部分仍认定）

## 二、§14(6) 通勤事故工伤

### 2.1 严格限制条件

```
上下班途中 + 合理时间 + 合理路线
+ 受非本人主要责任的事故
+ 事故类型：交通事故 / 城市轨道交通 / 客运轮渡 / 火车事故
```

### 2.2 关键证据：交警事故责任认定书

case 6.2 通勤事故子节：

- 事故责任：无责 / 同等责任 / 次要责任 → 可认定工伤
- 事故责任：主要责任 / 全部责任 → 不能认定工伤
- 同事故未涉责任划分 → 视情（如未涉及机动车的事故）

### 2.3 合理时间 + 合理路线

- 上下班的固定路线 + 顺道的合理拐弯（如买菜、接孩子）
- 临时性的偏离路线（如吃饭、办事）→ 视情
- 长时间 / 远距离的偏离 → 通常不认定

## 三、§14(4) + 14(5) 职业病和因工外出

### 3.1 职业病

case 6.2(D) 职业病子节：

特殊路径：

- 必须由**职业病诊断机构**作出职业病诊断
- 诊断证明书 → 工伤认定无需"工作时间 + 场所 + 原因"三要素
- 用人单位不安排离岗前职业健康检查 + 直接解除合同 → 违法解除（case 5.5.9、5.5.10、5.5.11）

### 3.2 因工外出

- 出差期间发生意外（含交通事故）→ 工伤
- 公派学习期间因工作原因受伤 → 工伤
- 因工外出下落不明 → 视同工伤

## 四、§15 视同工伤

### 4.1 48 小时内突发疾病死亡

case 6.2(C) 视同工伤系列：

关键要件审查：

- 工作时间 + 工作岗位（严格）
- 突发疾病（包含病情突发恶化）
- 在 48 小时内经抢救无效死亡

司法争议（地区差异）：

- "48 小时"起算时点：开始抢救 vs 临床死亡判定
- 家属放弃治疗：部分地区不认定（视为放弃即终止）/ 部分地区认定（已实际尽力抢救）
- 在工作场所突发疾病 + 送医后死亡 → 通常认定

### 4.2 抢险救灾

为维护国家利益、公共利益（救火、救灾、见义勇为）受伤。

实务认定通常较宽松，但要求行为属于"维护国家 / 公共利益"。

### 4.3 旧伤复发

军队革命伤残军人 → 到用人单位后旧伤复发 → 视同工伤。

## 五、工伤认定程序

### 5.1 申请时效

| 主体 | 时效 |
|---|---|
| 用人单位 | 30 日（自事故 / 职业病诊断日）|
| 工伤职工 / 近亲属 / 工会 | 1 年（自事故 / 职业病诊断日，单位未在 30 日内申请的）|

### 5.2 申请材料

- 工伤认定申请表
- 劳动关系证明（劳动合同 / 工资流水 / 工作证等）
- 医疗诊断证明 / 职业病诊断证明书
- 受伤经过证明（同事证言 / 监控录像 / 报警记录）
- 通勤事故 → 公安交警事故责任认定书
- §15(1) → 抢救记录 + 死亡医学证明

### 5.3 程序

```
申请 → 受理 → 调查核实 → 作出工伤认定决定 → 送达
        ↓                                    ↓
     不予受理                          不服 → 行政复议（60 日内）
        ↓                                    ↓
     行政复议 / 起诉                      行政诉讼（15 日内）
```

### 5.4 工伤认定决定的法律效力

- 工伤认定决定 → 行政确认行为
- 不服决定 → 行政复议（向上一级劳动行政部门）+ 行政诉讼
- 不能仲裁

## 六、典型成本路径

### 6.1 劳动者视角

| 情形 | 后果 |
|---|---|
| 工伤认定成立 | 享受工伤待遇（详见 work-injury-compensation.md）|
| 工伤认定不成立 | 走民事侵权或自行承担 |
| 工伤认定决定不服 → 行政复议 / 诉讼 | 推翻原决定的可能 |

### 6.2 用人单位视角

| 操作 | 风险 |
|---|---|
| 在 30 日内申请工伤认定 | 履行法定义务 |
| 拒不申请 + 阻碍劳动者申请 | 行政处罚 + 可能承担全部待遇 |
| 申请后被认定工伤 | 承担工伤保险责任（已参保的转工伤保险基金）|
| 不参保 + 被认定工伤 | 自行承担全部工伤待遇 |

## 七、操作要点

### 7.1 劳动者

1. **第一时间报警 / 报告**：留证事故发生 + 时间 / 地点 / 经过
2. **及时就医 + 保留病历**：诊断证明 + 治疗记录
3. **督促单位 30 日内申请**：单位不申请的 → 自己 1 年内申请
4. **职业病 → 先做职业病诊断**：取得诊断证明书
5. **通勤事故 → 优先取得交警事故认定书**

### 7.2 用人单位

1. **30 日内申请工伤认定**：履行法定义务（即使认为不构成工伤）
2. **配合调查**：提供事故经过 / 劳动关系证明 / 工作记录
3. **不服认定 → 申请行政复议**（60 日内）/ 行政诉讼（15 日内）
4. **未参保 → 准备承担工伤待遇** + 协商解决
